# 밤길 원정대 승인된 1차 완성 범위와 인수표

- 작성일: 2026-10-03 UTC
- 상태: IN_PROGRESS — 사용자가 1차 완성까지 진행하도록 승인함. 전체 완성 판정 전.
- 기준: [현재 구현](../CURRENT_IMPLEMENTATION.md), [v0.13 테스트 인계](2026-10-03_main-v13-test-handoff-report.md)
- 2차 방향은 [별도 제안](2026-10-03_phase2-mission-proposal.md)이며 구현 확정이 아니다.

## 2026-10-04 검수 중 발견한 UI 수정

Android v0.14는 작은 중앙 UI를 독립 재현해 Android 전용390논리 단위 scale로 수정했다. 소스30suite·APK8suite와 시작/입력·desktop격리·Webscale 회귀를 통과했으며 [인계 보고](2026-10-04_android-v14-ui-scale-handoff.md)에 파일·배포 영수증을 기록한다. Web v0.13은 변경하지 않았다. 아래 v0.13 빌드 증거는 당시 이력이며, 실제 Android 업데이트·이어하기와 나머지 인수 문턱은 계속 열린다. 재미있다는 사용자 반응은 긍정 피드백이며 설치/완주/전체 합격 증거로 확대하지 않는다. [능력 구매·합성 실험](2026-10-04_approved-hero-ability-merge-experiment.md)은 이후 사용자 승인으로 별도 격리 후보에서 IN_PROGRESS다. 안정판 인수·배포 완료와는 분리한다.

## 이후 승인된 격리 실험

2026-10-04 능력 구매·다중 배치·수동3→2성 합성 실험이 승인됐다. 최신 규칙은 위 승인 문서를 따르며 안정판 새 기능 동결의 범위 밖에서 별도 저장으로 검증한다. 이 예외는 기존 실제 기기·웹 저장·청취·사람 인수 항목을 완료 처리하지 않는다.3성은 후속 방향으로만 남긴다.

## 결론

1차는 기존 한 판을 끝낼 수 있고, 선택 이유와 보스 목표를 이해하며, Android에 설치해 재개할 수 있는 작은 완성 게임이다. 맵·영웅·영구 경제를 늘리는 작업은 포함하지 않는다. 현재 기능의 상당 부분과 네이티브 검증은 이미 있다. 남은 핵심은 실제 플랫폼 검증, 잘못된 안내 수정, 보스전 목표 전달, 자연 성장에서의 배치·선택 검증, 3–5명 테스트다.

**v0.13은 동결 v0.12 기반 기존 10웨이브 보스 목표·진행 안내와 필수 문구 정합성을 반영했다.** 모델·수치·저장 형식은 보존했다. 소스/PCK·네이티브 검증 완료와 실제 휴대폰/웹·사람 인수는 구분한다. 이제 새 기능 추가를 멈추고 아래 플랫폼·밸런스·사람 검수 문턱을 닫는다. 검수 차단을 새 기능 개발로 대신하지 않는다.

## 고정 범위

- 사각 맵 1개, 비비·탄코·로코 각 2갈래
- 10웨이브, 마지막 보스, 약 7분의 1배속 활동 시간 목표
- 영입 → 첫 중복 승급 선택 → XP 카드 → 배치 → 승리/패배 → 재시작
- 모바일 UI, 음향·옵션, 짧고 정확한 안내, 같은 기기 이어하기
- 설치 가능한 Android 시험 빌드와 실제 기기 검수
- 3–5명 친구 테스트 결과를 반영한 뒤 1차 완성 판정
- 새로운 목표 시간·승률이나 출시일은 이 계획에서 확정하지 않음

## Done — 구현과 확인된 증거

- 기본 순환과 3영웅·6갈래: 모델/화면에 구현. v0.11 집중 회귀 20회와 소스·동결 PCK 각 16쌍 원정 비교가 통과했다. 이것은 동일한 모델 결과 보존의 증거다.
- 저장·복구·새 원정 확인: RunState/RunStore와 화면 흐름 구현, 네이티브 StoreTests/ResumeUI 통과. 웹 IndexedDB 합격을 뜻하지 않는다.
- 음향·반응형·적 HP/장갑·보스 표식·배치 사거리·처치 잔상·승급별 공격 표현: 구현 및 네이티브/정적 증거 있음. 물리 기기의 터치·청취·가독성 증거와 구분한다.
- 기존 최종 보스: 10웨이브의 마지막 출현 적. HP3000, 장갑25%, 이동속도22, 경로1200, 누수 피해20. 약28초에 출현하며 무저항 이동은 약54.55초. 보스를 처치하고 남은 적을 정리해야 승리한다. 보스 미처치면 웨이브 종료 때 패배하므로 HP를 강화해 누수20을 버텨도 클리어가 아니다.
- 기존 보스의 화면 표식은 큰 스프라이트·HP바·왕관형 표식이다. 이미 있는 표시를 없는 기능처럼 재제안하지 않는다.
- 배치가 결과를 바꾼 통제 실험은 있음: 과거 v0.3에서 탄코2→4만 바꾼 한 조합이 패배→승리. 현재 자연 영입/카드 플레이의 전략성 검증으로 승계하지 않는다.

## Blocked / 외부 입력이 필요한 문턱

- 브라우저 검수: 현재 공개 문서상 미검증이며 이전 접근 차단 기록이 있다. 실제 지금의 승인된 접근 상태를 확인해야 한다. 인증/권한 거절을 다른 경로로 우회하지 않는다. 허용된 현재 실행 환경이 있으면 검사 가능하므로 영구 불가능으로 쓰지 않는다.
- Android: 빌드 도구 준비는 구현 작업, 실제 소유 기기 설치·플레이는 기기 접근 의존이다. 설치 허용, 필요한 컴퓨터/기기 경로와 최소 지원 기기를 확인한다. 새로운 서명 자격증명이나 권한이 필요하면 해당 단계만 별도 확인한다. 스토어 출시/계정 생성은 이번 범위가 아니다.
- 친구 테스트: 시험할 3–5명과 전달 방법·접근 권한이 필요하다. 사용자 전용 비공개 Site를 임의 공개하거나 친구에게 자동 초대하지 않는다. 사용자가 공유할 설치 파일/검수지를 준비할 수 있다.
- 이 문턱이 남으면 '개발 후보 완료, 플랫폼/사람 검수 대기'로 보고한다. 1차 전체 완성이라고 선언하지 않는다.

## 완료한 UI 범위: 기존 보스전의 목표·진행 안내

아래는 v0.13 구현의 원래 인수 범위이며 추가 기능 지시가 아니다. 범위: v0.12 통합 이후 화면·문구의 작은 별도 변경. 기존 모델, RNG, 적 수/HP/속도, 경제, 배치 규칙, 저장 형식을 유지한다.

1. 10웨이브 준비 화면에 최종 목표와 한 줄 안내. 예: '최종 웨이브 · 마지막 보스를 처치하세요. 보스를 놓치면 원정 실패.' HP20 감소만 설명해 최대HP 강화로 클리어할 수 있는 것처럼 쓰지 않는다.
2. 실제 보스 등장 후 이름/남은HP를 기존 화면의 충돌 없는 공간에 노출. 값은 보스 Dictionary에서 읽고, 등장 연출을 위해 적을 멈추거나 새 피해를 만들지 않는다. 별도의 컷신·새 음원·패턴은 필수 아님.
3. 보스 처치 후 잔여 적이 있으면 '보스 격파 · 남은 적 정리', 보스 유출 실패는 실제 종료 판정에 맞춘 문구. UI만의 승리 판정을 만들지 않는다.
4. 도움말의 첫 중복·공용 카드·현재 배속·낡은 아트/버전 문장을 정리하고 맨 앞에 짧은 조작 요약. 상세 설명을 강제 온보딩 여러 장으로 확대하지 않는다.

인수: 1/2/3배속, 320/390폭과 가로 화면; 등장 직전 저장→복원, 살아 있는 보스 복원, 모달/일시정지, 보스 처치와 마지막 적 동시 처리, HP20 초과에서 보스 유출, 승패→새 원정. 변경 전후 상태/RNG/결과 동일. 통제 fixture와 자연 진행 캡처를 각각 남긴다. 현재 병행 편집 중인 화면 파일에 덮어쓰지 않고 동결된 통합본에서 시작한다.

이 작업 후 새로운 기능 추가를 멈추고 남은 플랫폼·밸런스·사람 인수표를 닫는다. 사람 테스트가 보스를 여전히 인식하지 못할 때만 추가 연출을 검토한다.
