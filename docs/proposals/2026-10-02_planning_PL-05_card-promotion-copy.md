## 승급·갈래 문구
23번 문구팩의 영입 비용, 런 한정 성장, 다시 도전 안내는 유지한다.

| 상황 | 제목 또는 한 줄 | 상세 보충 |
|---|---|---|
| 첫 중복 선택창 | {hero}의 갈래 선택 | 중복 영입이 확정되었습니다. 두 갈래 중 하나를 고르면 승급 1이 적용됩니다. |
| 첫 중복 확정 버튼 | {branch} 선택 | 선택한 갈래는 이번 원정 동안 유지됩니다. |
| 첫 중복 선택 후 | {hero} 승급 1 · {branch} | 피해 보너스 +18%p |
| 추가 중복 | {hero} 승급 {rank} · {branch} | 피해 보너스 +18%p. 선택한 갈래와 카드 강화는 유지됩니다. |
| 높은 승급 도움말 | 중복 영입마다 계속 승급합니다. | 갈래 고유 효과는 승급 2에서 한 번 더 강화됩니다. 이후 승급은 피해 보너스를 높입니다. |
| 전투 아이콘 도움말 | 자동 공격 / 승급 정보 | 아이콘을 누르면 설명을 볼 수 있습니다. |

“갈래 고유 효과”에는 사격 간격·추가 표적 수·반경·지속시간·고유 피해 계수가 포함된다. 고정되는 것은 승급에 따른 그 효과의 강화이며, 이후 사거리 카드 등으로 변하는 값까지 전부 고정된다는 뜻이 아니다. 낮은 MAX나 별 개수로 승급 상한을 암시하지 않는다.

| 실제 갈래명 | 선택 카드의 한 줄 설명 |
|---|---|
| 집중 연사 | 사거리 안의 같은 표적을 빠르게 집중 사격합니다. |
| 확산 탄막 | 주 표적과 전방 부채꼴 안의 다른 적들을 함께 공격합니다. |
| 광역 폭파 | 조준 지점에 넓게 폭발합니다. 빠른 적은 착탄 전에 벗어날 수 있습니다. |
| 소이 포격 | 착탄 뒤 불길을 남깁니다. 불길 안에 있는 적이 지속 피해를 받습니다. |
| 유도 파쇄 | 사거리 안의 보스를 우선 추적합니다. 표적이 죽으면 한 번 재조준합니다. |
| 직선 관통 | 발사 방향이 고정된 직선 범위의 적들을 관통합니다. |

소이 설명을 지대 이탈 후에도 유지되는 화상으로 쓰지 않는다. 유도는 무한 재추적을 보장하지 않으며 재조준할 유효 표적이 없을 수 있다. 관통에 표적 수 제한이 있다는 문구를 임의 추가하지 않는다.

## 변수와 계산 확인
아래는 개발 인수용 예이며 플레이어에게 계산 코드를 보여주라는 요구가 아니다.
- 성장 피해 배율은 모델이 반환한 값을 사용한다. 승급2·전용 피해2·공용 피해1이면 1.56배, 전용 피해1장을 더 고르면 1.64배다. “최종 피해 8% 증가”로 바꾸지 않는다.
- 비비 기본 공격 간격은 카드0/1/2/3회에서 0.18 / 0.1692 / 0.159048 / 0.14950512초. 갈래 기준 간격이 다르면 그 기준을 사용한다. 3회 선택을 간격 -18%로 표시하지 않는다.
- 파쇄 지속시간은 카드0/1/2/3회에서 3/4/5/6초다.
- 공용 사거리0→1회: 로코 사거리192→196, 관통 길이372→376. 관통 폭 증가로 표시하지 않는다.
- 방벽 보강: HP3/20→5/22, HP20/20→22/22. 단순 회복 카드로 바꾸지 않는다.
- count와 rank는 별도 값이다. 카드 최대3회는 승급3 상한을 뜻하지 않는다.
- 변수 값은 확정된 모델 상태와 현재 후보를 사용한다. 화면 설명을 위해 재추첨하거나 상태를 먼저 변경하지 않는다.
- 숫자 반올림이 필요한 경우 출력만 반올림하며 실제 계산 값은 유지한다.

## 문제점
- v0.3의 승급 전 안내에 첫 영입/중복 의미가 혼재한다. 정보창을 읽는 신규 플레이어가 갈래 해금 시점을 오해할 수 있다. COPY-01로 수정 제안.
- 성장 피해 배율이라는 제한 없이 표시하면 갈래 피해·장갑까지 포함한 값처럼 보일 수 있다. COPY-03으로 라벨 보완 제안.
- 공용 사거리의 관통 길이 영향이 생략되어 있다. COPY-05로 현재 효과를 설명하며 게임 규칙을 바꾸지 않는다.
- v0.3.1 개별 문구 동일성은 미확인. “최신 배포에서 같은 오류 재현”으로 보고하지 않는다.

## 다음 작업 후보
1. 우선순위 높음 — 개발1 배치 민감도 결과 인수 후 PL-04 가설 판정. 산출물: 조건별 차이와 유지/추가 관측 결론. 완료 조건: 원시 결과와 보고 수치 일치, 갈래와 배치 영향 분리. 의존성: DV1-P01 결과 전달. 입력이 없으면 재실험하거나 같은 비교 문서를 반복하지 않는다.
2. 우선순위 중간 — 개발2 문구 적용 증거가 오면 이 표와 대조. 산출물: 누락·오표기 목록 또는 일치 기록. 완료 조건: 실제 화면/문자열 근거와 상태 표시. 의존성: 적용 버전·화면 증거.

마지막 완료 지점: 카드12종·승급 상황·6갈래 문구와 실제 효과 정적 대조 완료. 다음 1단계는 두리·개발2 인수 또는 개발1 비교 결과 확인이다. 새 영웅·카드 확장이나 운영 반영은 포함하지 않았다.
