## 충돌과 변경
- P1의 승급 때 ui_recruit_new 임시 재사용 제안을 **ui_promote**로 교체 제안. 기존 음원 삭제 없음.
- 동일 영입 거래가 승급을 일으키면 ui_promote만. 중복 재료·새 영입음 이중 재생 금지. 최대성 환급은 기존 일반 확인음과 환급 문구 유지.
- 핀은 즉시 명중이다. 별도 투사체 비행음·딜레이를 추가하지 않는다.
- 애쉬는 좌표 즉시 장판이며 탄코 포탄처럼 지연 착탄음을 만들지 않는다.
- 애쉬 F1 노출1.5/0.75초 비교안에서 조건 통과만으로 소리를 추가하지 않는다. 실제 피해 틱마다 소리를 만들지도 않는다.
- 토리 지원 상한으로 실제 증가량0일 수 있다. 음향이 효율 보너스를 허위 보장하지 않게 연결 신호만 표현하고 수치는 화면에 맡긴다.
- BGM 보스 gain: 통합 manifest는 이전 v4의 -18dB+보스 -2dB 보정을 합쳐 **-20dB**로 기록했다. 이를 적용한 뒤 별도 -2dB를 다시 더하지 않는다. 원본 WAV/OGG는 변경하지 않았다.

## 루프·상태 계약 [제안]
애쉬 연소:
1. 활성 장판 수0→1 이상에 단일 루프 시작, 상한 전체1. 장판 생성·중첩마다 새 노드 시작 금지.
2. 기본/궁극기 장판은 같은 연소 인스턴스 공유. 장판 교체로 반복 위치 리셋하지 않는다.
3. 마지막 장판 종료 또는 웨이브 종료: 80ms 페이드 후 정지. 시작100ms 페이드.
4. 카드/수동정지/앱 숨김: 전투 루프 페이드 중지. 재개 시 현재 유효 장판이 있으면 다시1개, 사라졌다면 무음.
5. 새 런·결과·음소거 시 정리. 음소거 중 장판이 생겨도 노드를 누적하지 않는다.
6. gain -24dB 시작값. 음소거 해제 후 현재 상태로1개 재구성 가능하나 과거 점화음을 몰아 재생하지 않는다.
7. 효과음 전체12voice 한도에서 일반 슬롯1을 사용. 우선순위 낮게, 잘리면 매프레임 재생하지 않고 다음 상태 점검에 제한적으로 복원한다.
8. 루프 샘플 범위[0,96000), PCM48kHz. 주기적 노이즈 합성 후 짧은 경계 보정. 최종 경계 청취 미검수.

토리 지원:
- 매프레임/매공격/매버프수치 갱신 재생 금지.
- 준비 중 대상 집합이 변해 새 대상이 추가되면1회. 여러 연결 동시에는1회, 최소500ms.
- 전투 시작에 기존 연결을 다시 알리지 않는다. 링크 제거는 별도 경고음 없이 시각 표시만.
- 궁극기 사용 시 sfx_ultimate_tori만, 지원 신호를 중복 재생하지 않는다.
- 지원 대상0 또는 발동 조건 불충족은 기존 ui_reject, 성공 궁극기음 금지.

핀/불씨:
- 핀 처치 단축 토큰 획득·대기·소비는 별도 사운드 없음. 다음 실제 사격 때만 기본음.
- 핀 궁극기 파일 자체에 발사 강조를 포함했으므로 같은 사건의 sfx_pin_fire 생략.
- 불씨 250ms 최소간격/전체2개, 폭발 그룹 합계2개 상한에 포함. 추가 재귀 폭발·피해를 음향에서 생성하지 않는다.
- 기본/확장 발사·피격·사망·누수의 event_id/run_id 중복 방지 유지.

## 통합 패키지
파일: Nightroad_Audio_All_v1.zip
- p0/: 기존 기본전투17개
- p1/: 기존 UI/궁극기14개
- bgm/: 기존 BGM WAV2곡 + OGG2개(포맷 변환본)
- expansion/: 이번 승급/확장13개
- manifest_all.json: 상대경로·해시·gain·이벤트·검수상태를 통합
- preview.html: 전체/기본전투/UI/BGM/확장 분류로 원본 청취
- source/: 각 제작 스크립트 및 당시 manifest
- README.md: 이번 인계 문서
소재46개=효과음44개+BGM2곡. 서로 다른 sound_id35개, 변주 포함46개. OGG와 source의 중복 원본 기록은 소재 수에 더하지 않는다.
기존 파일은 바이트 그대로 복사했고 통합경로의 SHA256을 전수 대조했다. source/의 과거 manifest 경로는 당시 묶음 기준이며 **개발 연결은 manifest_all.json**을 사용한다.
재생성은 스크립트마다 별도 빈 폴더에 복사해 실행한다. 같은 폴더에서 여러 스크립트를 실행하면 manifest.json/preview.html이 겹친다. 기본 제작에는 Python/NumPy/SciPy, BGM에는 FFmpeg도 필요하다.
HTML은 압축을 전부 해제한 뒤 실행한다. 개별 음원 기본35% 재생, 다른 클립 시작 시 이전 클립 정지. 게임 gain 적용 전 원본 청취이며 브라우저 실행 검수 미완료.

## 파일 검사와 출처
신규13개 PCM48kHz/24bit/mono·길이 검사. 계산 파형 비무음·샘플 피크·4배 피크 추정 확인. 단발 샘플피크 -4dBFS, 루프 -6dBFS.
전체46개 연결 경로 존재·SHA256 일치·35 sound ID 집계 확인.
청취·무기 구별·7분 믹스·기기별 루프·게임 사건 동기화·전체voice 상한 동작은 미검수.
외부 녹음/샘플 없이 직접 합성. 출처는 포함 소스/시드. 제3자 오디오 샘플 귀속 없음, 배타적 권리 보증이나 임의 라이선스 계약 부여 아님.

## 개발1/2팀 인계
자료 작성은 타팀 메시지 전송·수락을 뜻하지 않는다.
개발2팀의 음향 연결 담당이 패키지를 받아 manifest_all.json을 기준으로 기본 음향과 승급부터 연결할 수 있다. 확장13개 중 ui_promote 외 PIN/ASH/TOR 음향은 해당 영웅 시험 활성 때 연결한다.
아직 개발환경에서 인수 확인을 받지 않았다. 저장소에는 본 Markdown만 추가하며 바이너리 업로드를 주장하지 않는다.
개발1팀의 전투 사건 확정 후 표현층에서 재생. 음향 코드가 공격/처치/XP/승급을 다시 호출하지 않는다.
공용파일·전투로직은 음향팀이 수정하지 않는다.
