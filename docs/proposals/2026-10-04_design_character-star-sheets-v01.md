## 현재 확정 기준과 제안 구분

### 현재 기준에서 사용한 내용

- 영웅 명단: 비비·탄코·로코
- 비비 식별자: 흰 머리, 토끼귀, 붉은 의상
- 탄코 식별자: 곱슬 구리색 머리, 남색 군모, 황동 고글
- 로코 식별자: 흰 포니테일, 검은 리본, 사람 귀
- 2성 갈래:
  - 비비: 화염방사기 / 저격수
  - 탄코: 폭발 / 소이
  - 로코: 유도 / 관통
- 3성: 현재 구현 잠금

### 디자인 제안이며 미확정인 내용

- 비비 3성 가칭: `인페르노 엔진` / `밤길 명사수`
- 탄코 3성 가칭: `공성 파쇄자` / `화염폭풍 포병`
- 로코 3성 가칭: `미사일 군집장` / `레일 관통병`
- 3성 장비 크기·오라·세부 실루엣

위 3성 명칭과 외형은 구현 규칙 또는 사용자 확정 사항으로 취급하지 않는다.

## 생성 산출물

모두 1920×1080 PNG이며 게임 제작 참고용 벡터형 정적 시트다.

1. `00_roster_overview.png` — 3영웅 전체 비교
2. `01_BIBI_character_sheet.png` — 1성, 2성 두 갈래, 잠긴 3성 두 갈래, 정면/측면/후면, 5표정, 무기, 공격 범위

4. `03_ROKO_character_sheet.png` — 동일 구성

각 시트는 모바일 64~128px 축소를 고려해 얼굴 세부보다 귀·모자·리본·무기 방향 등 큰 실루엣을 우선했다. 공격 다이어그램은 실제 구현 범위를 과장하지 않도록 원뿔·직선·원형·지대·유도 경로로 구분했다.

## 남은 문제와 경계

- 본 시트는 형태·계층·분기 전달용 블록아웃이며 최종 고해상도 원화가 아니다.
- 레이어 원본, 리깅, 애니메이션 프레임, 투명 알파, 실제 엔진 피벗은 제작하지 않았다.
- 휴대폰 실기, Godot 렌더, 실제 64px 사용자 식별률은 검증하지 않았다.
- 공개 저장소의 현재 텍스트 파일 쓰기 도구로 바이너리 PNG/ZIP를 직접 올리지 못해 산출물은 대화 첨부로 전달하며 GitHub 바이너리 업로드는 미완료다.
- 운영 UI·게임 코드·밸런스·3성 기능은 변경하지 않았다.
