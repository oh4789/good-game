# 능력 구매·중복 합성·희귀도 성장 제안

- 작성일: 2026-10-04 UTC
- 상태: **PROPOSAL / 미구현 / 미승인**. 사용자 아이디어에 대한 검토안이며 현행 규칙을 대체하지 않는다.
- 현재 Android v0.14는 화면 크기 수정만, Web은 v0.13이다. 기존 첫 중복 즉시 승급·이후 중복 성장·XP 카드 규칙은 그대로다.

## 논의할 방향

사용자가 능력 구매, 같은 영웅3개로2성 만들기, 능력 희귀도(실버·레어·에픽), 처치 누적 성장에 대한 의견을 요청했다. 다음은 실험을 위한 추천안이며 확정 설계나 구현 지시가 아니다.

- 기존 고철을 공유해 영입과 능력 구매 사이에 선택을 만든다. 능력 상점은 영웅 종류를 지정하고 후보3개 중 선택하는 형태부터 검토한다.
- 같은 영웅을 여러 개 배치할 수 있도록 하되, 동일 영웅3개→2성은 자동 소모 대신 수동 합성을 검토한다. 2성 갈래 선택은 개별 유닛에 귀속한다.
- 영웅 종류 공통의 기본 강화는 같은 종류의 모든 유닛에 적용하고 합성 뒤에도 유지한다. 개별 갈래 전용 능력은 해당 갈래를 해금한 뒤 상점에 등장시키는 안이다.
- 실버 능력은 구매 즉시 작은 효과와 구매 이후의 팀 처치 누적 성장을 함께 주는 안을 검토한다. 성장은 상한을 두고, 적1기 사망은 한 번만 센다. 중복 유닛 수나 다중 타격으로 처치 수를 부풀리지 않는다.
- 처치 누적치를 합성 때 더하거나 초기화하지 않는 쪽을 권한다. 구매 전 처치를 소급할지 여부는 위 추천안에서는 소급하지 않는 것으로 두되 최종 결정 전이다.

## 결정 전 확인할 질문

1. 영입·능력 구매가 고철을 공유할 때 영입을 포기할 만한 선택이 생기는가? 비용·후보 갱신·등장 확률은 실험 후 정한다.
2. 동일 영웅 다중 배치와3→2성 합성을 도입하면 기존 첫 중복 갈래 선택은 무엇으로 대체하는가? 서로 다른 갈래/성급의 합성, 배치 공간과 대기 보관 규칙은 미정이다.
3. 실버·레어·에픽의 차이는 누적 성장·즉시 효과·플레이 방식 변화 중 어디에 둘 것인가? 높은 희귀도가 항상 정답이 되지 않도록 비교가 필요하다.
4. 처치 누적의 귀속 단위, 상한·기울기, 여러 능력의 중첩·구매 시점·저장 복원 처리는 어떻게 할 것인가? 수치와 저장 migration은 미확정이다.

먼저 현재 빌드와 같은 조건에서 선택 이유·대기 시간·초반/후반 효율을 비교할 작은 설계 실험을 제안한다. 코드·경제·저장 구조를 바꾸거나 현행 인수표의 새 기능 동결을 해제하려면 별도 채택 판단이 필요하다. 새 맵·영구 경제·2차 보스/채굴 모드 승인으로도 해석하지 않는다.
