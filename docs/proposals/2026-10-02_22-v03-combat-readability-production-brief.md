# v0.3 전투 가독성·성장 체감 제작 지시안
작성일: 2026-10-02 America/Chicago
상태: 현재 규칙의 표현 구체화 제안 / 실제 에셋·게임 구현 없음
기준: 2026-10-03_v03-canonical-decisions.md, 20-v03-planning-migration-growth-review, 21-v03-eight-party-comparison-pack.
추가 확인: 2026-10-02_v03-six-branches-balance-validation.md의 6갈래 역할·8조합·경제 검토.
현재 자동 전투·첫 중복 2갈래·계속 승급을 유지한다. 피해·공속·보상·새 영웅·수동 스킬을 추가하지 않는다.

## 1. 이번에 해결할 경험 문제
사용자가 지적했던 적이 너무 빨리 사라짐, 전투의 단조로움, 캐릭터 생동감 부족, 무기 잘림을 네 작업으로 분리한다.
이 지적은 과거 버전에 대한 사용자 관측이며 현재 v0.3에서도 재현됐다고 단정하지 않는다.
- 적이 실제로 너무 빨리 죽음: 21 문서의 생존시간·유효 피해로 판단할 밸런스 문제.
- 처치와 누수가 구별 안 됨: 시각·음향 연결 문제.
- 6갈래가 같은 공격처럼 보임: 무기·탄도·피격 표현 문제.
- 무기가 잘리거나 움직이지 않음: 원본 프레임·원점·회전·레이아웃 문제.
적의 사망 판정이나 다음 웨이브를 연출 때문에 늦추지 않는다.

## 2. 6갈래가 화면에서 읽혀야 할 차이 [제안]
| 갈래 | 가장 먼저 보여줄 특징 | 최소 표현 | 피할 오해 |
|---|---|---|---|
| 비비 연사 | 한 적을 향한 연속 사격 | 표적 방향 총구·짧은 반동·좁은 탄흔 | 화면 전체 탄막처럼 보임 |
| 비비 탄막 | 여러 적으로 퍼지는 공격 | 실제 공격 방향별 궤적 | 표시만 여러 발인데 피해도 늘어난 듯 보임 |
| 탄코 폭발 | 한 번의 넓은 충격 | 착탄 중심·짧은 원형 폭발 | 시각 반경과 실제 판정 반경 불일치 |
| 탄코 소이 | 바닥에 남아 지속되는 불길 | 낮고 반투명한 장판·틱 피드백 | 불길이 적·경로·HP를 가림 |
| 로코 유도 | 강한 표적으로 향하는 탄도 | 실제 궤적을 따르는 짧은 꼬리 | 실제 직선 이동인데 곡선 추적처럼 연출 |
| 로코 관통 | 직선을 따라 연속 적중 | 실제 진행선·각 적의 짧은 피격 | 폭발이나 유도 공격처럼 보임 |

표적 추적·탄도 등은 구현 사건을 따라 표현한다. 기획상 이름만 보고 움직임을 새로 발명하지 않는다.
모든 차이는 색 이외에 궤적·형태·지속시간 중 하나로도 구별한다.
처음에는 대표 공격 한 번이 읽히는 수준을 완성하고 파티 동시 공격으로 확장한다.

## 3. 전투 표시의 우선순위 [제안]
1. 공용 HP 손실·적 출구 통과.
2. 살아 있는 적과 경로, 배치된 영웅.
3. 공격 궤적과 갈래별 핵심 효과.
4. 일반 피해 숫자·장식 잔광·파편.

혼잡하면 4번부터 줄인다. 실제 공격·피해 판정은 생략하지 않는다.
한 번의 누수에 경고 효과가 합쳐져도 누수 수량과 HP 손실 합계는 정확히 표시한다.
연속 사격마다 영웅 전체를 크게 흔들지 않는다. 반동은 무기/상체 중심이며 바닥 위치는 안정적으로 유지한다.
화면 흔들기와 섬광 감소 설정을 표현 옵션으로 제안한다. 적용 여부는 개발2팀이 기존 설정과 맞춘다.

## 4. 처치·누수·준비 전환
처치: 논리적으로 즉시 타겟에서 제거 → 짧은 사망 잔상 → 소멸. 기존 약0.25초는 표현 시험값이다.
누수: 살아 있는 적이 출구를 넘음 → 공용HP 변화/누수 표시 → 퇴장. 처치 보상·사망음을 재사용하지 않는다.
사망 잔상 때문에 살아 있는 적 수를 늘리거나 웨이브 종료를 지연하지 않는다.
준비 진입: 공격 효과 정리 후 다음 적 예고와 배치 조작을 읽을 수 있게 한다. 강제 감상 대기시간은 새로 넣지 않는다.
유효 공격 대상이 없을 때는 대기 동작을 사용한다. 총구불꽃을 계속 재생해 공격 판정이 있는 듯 보이게 하지 않는다.

## 5. 성장의 세 사건을 분리
| 사건 | 문구 후보 | 시각 | 소리 요청 |
|---|---|---|---|
| 새 동료 영입 | “탄코 합류” | 영웅 초상·배치 가능 상태 | 합류 사건 1회 |
| 첫 중복 승급 | “탄코 승급 1 · 갈래 선택” | 영웅 강조 후 2갈래 선택 화면 | 승급 1회, 선택 확정은 별도 |
| 추가 중복 승급 | “탄코 승급 3” | 수치 변화와 짧은 테두리 강조 | 승급 1회 |

보조 카드 선택은 카드 효과의 실제 변경값을 표시한다. 승급과 같은 별 게이지로 표시하지 않는다.
개수 성장이 제한된 이후에도 “공격력 증가” 같은 실제 변화가 보이게 한다.
시각적으로 더 큰 폭발이나 더 많은 탄환을 넣어 미적용 성능 증가를 암시하지 않는다.
첫 중복과 카드 선택이 겹치는 처리 순서는 20 문서의 후보를 실제 구현 정책에 맞춰 확정한 뒤 연결한다.
중복 화면 렌더나 앱 복귀는 새 성장 사건이 아니다.

## 6. 최소 제작 묶음
| 우선 | 담당 | 작업 단위 | 인수 조건 |
|---|---|---|---|
| P0 | 개발2·디자인 | 기본3영웅의 무기·몸·원점 확인 | 9칸과 실제 지원 공격 방향에서 잘림 없음 |
| P0 | 개발1·2 | 처치/누수 사건 구분 | HP·보상·소리·효과가 각 사건과 일치 |
| P1 | 디자인·개발2 | 6갈래 대표 공격 표현 | 단독 재생 후 파티 동시 재생에서 구별 가능 |
| P1 | 개발2·음향 | 영입/첫승급/추가승급/카드 연결 | 각 유효 사건에 1회, 겹침·과거 재생 없음 |
| P1 | QA | 모바일 혼잡 장면 | 경로·적·핵심 버튼 가림 여부 기록 |
| P2 | 디자인·음향 | 대기 동작·추가 파편·잔향 | P0/P1을 해치지 않고 실제 기기에서 확인 |

디자인 산출물에는 실제 파일, 투명도, 프레임 수, 프레임 크기, 원점, 재생 속도, 라이선스/출처를 포함한다.
설명용 보드·원화와 실제 게임용 파일을 구분한다.
음향은 기존 제작본의 적절한 소재를 먼저 확인한다. 수동 궁극기 이름이 붙은 파일을 현재 규칙의 궁극기 기능으로 연결하지 않는다.
실제 소스 파일 경로는 개발팀이 확인한 후 작업 범위에 기록한다.

## 7. 짧은 관찰 검수
- 소리를 끄고 공격만 보고 비비 연사/탄막, 탄코 폭발/소이, 로코 유도/관통 차이를 설명할 수 있는가.
- 색을 구별하기 어려워도 형태·궤적으로 차이가 보이는가.
- 적이 죽은 것과 놓친 것을 공용HP 변화까지 포함해 구별할 수 있는가.
- 첫 중복 이후 선택한 갈래가 무엇인지, 추가 중복이 무엇을 올렸는지 이해하는가.
- 전장 구석 배치와 최대 실제 회전에서 무기·불꽃·그림자가 잘리지 않는가.
- 혼잡한 장면에서도 영입·선택·준비 버튼에 접근 가능한가.

유도 질문 대신 먼저 “방금 무엇이 바뀌었나요?”라고 묻고 답과 화면을 기록한다.
이해 여부의 수치 합격선을 작은 표본에서 임의 확정하지 않는다.
실제 휴대폰 성능·발열은 데스크톱 크기 변경만으로 검증하지 않는다.

## 8. 인계 순서와 종료 조건
개발1팀이 유효 사건/판정 범위를 제공 → 디자인·음향이 실제 사용 파일을 인계 → 개발2팀이 표현 연결 → QA가 같은 빌드에서 확인.
독립 가능한 자산 작업은 병행 가능하지만 통합 완료는 적용 빌드 증거가 있을 때만 표시한다.
현행 갈래 비교는 기존 six-branches-balance-validation와21 문서를 재사용한다. 이번 작업 때문에 별도 40런을 추가 요구하지 않는다.
완료 증거는 6갈래 단독/혼합 장면, 처치/누수, 첫/추가 승급, 모바일 잘림 확인이다.
남은 불확실성: 실제 에셋 접근·엔진 사건 이름·모바일 지원 범위·표현 비용. 이번에 구현하거나 측정하지 않았다.
다른 Work에 직접 메시지를 발송하거나 사용자 대신 새로운 게임 규칙을 확정하지 않았다.
