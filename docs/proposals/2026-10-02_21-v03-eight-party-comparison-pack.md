## 3. 최소 비교 절차
### 1단계 — 8개 조합의 작동 확인
개발 전용 장면에서 세 영웅 승급1, 보조 카드 없음, 같은 적 구성·생성 시각·배치·초기 상태로 8개 조합을 비교한다.
갈래 강제 지정은 시험 도구에서만 사용하며 일반 플레이의 성장 속도나 획득 확률을 평가하지 않는다.
대표 적 장면은 현행 데이터에서 단일 강적·밀집 무리·빠른 적을 선택한다. 새 적 능력을 추가하지 않는다.
고정 배치에서 비교 후, 예상 역할이 드러나지 않는 갈래만 준비 단계의 다른 배치로 재확인한다.
유리한 배치 한 번의 결과로 다른 조합을 열등하다고 결론내리지 않는다.

### 2단계 — 수치 성장과 역할 차이 분리
승급1에서 확인한 역할이 승급3에서도 유지되는지 문제 있는 갈래만 비교한다.
승급3은 공격력 성장이 이어지는 단계이며 특수 효과 개수는 현재 제한을 따른다.
기준 조건에서 틀린 피해·중복 명중·사거리 판정이 발견되면 난이도 조정 전에 수정한다.
단순 연출 차이는 전투 성능 차이로 세지 않는다.

### 3단계 — 자연 성장 전체 런
기능 확인 이후 실제 뽑기·실제 카드 선택으로 전체 런을 기록한다.
8조합을 억지로 맞추려고 재시작을 반복하지 않는다. 실제로 열린 갈래와 미선택 영웅을 그대로 기록한다.
자연 런의 반복 수는 관측된 문제를 재현할 만큼 정한다. 8조합 모두 획득을 완료 조건으로 삼지 않는다.
같은 시드여도 행동에 따라 난수 소비가 달라질 수 있으므로 동일 시드만으로 동일 영입·적 사건을 보장했다고 쓰지 않는다.
개발 시험에서는 입력/생성 스크립트 또는 상태 스냅샷을 함께 고정한다.

## 4. 핵심 측정과 해석
| 측정 | 정의 | 주의 |
|---|---|---|
| 유효 피해 | 적의 남은 HP를 실제 줄인 피해 | 초과 피해 제외, 지원 기여 중복 없음 |
| 적당 생존시간 | 생성부터 처치/누수까지 | 처치와 누수를 따로 집계 |
| 누수 | 유형별 수·공용HP 손실 | 경고음 재생 횟수로 대체 금지 |
| 보스 처리시간 | 보스 생성부터 사망까지 전투 시간 | 생존/누수 종료는 처치시간으로 표기 금지 |
| 공격 기회 | 사거리 안 유효 표적이 있던 시간 | 적이 없어 쉬는 시간을 사거리 문제로 오해하지 않음 |
| 소이 기회 | 적의 불길 노출과 실제 피해 틱 | 틱이 오기 전 타 영웅이 처치한 경우 분리 |
| 관통 효율 | 발사당 고유 피격 적 수 | 같은 적의 중복 피격은 별도 기록 |
| 성장 시점 | 첫 영입·3인 확보·첫 갈래·영웅별 승급 | 강제 지급과 자연 획득 구분 |
| 런 시간 | 전투/준비/선택/정지 분리 | 미완주와 완주 시간을 섞지 않음 |

자료가 없으면 “미측정”으로 남긴다. 숫자0으로 채우지 않는다.
파티 총피해가 같아도 누수·보스 시간·처치 위치가 다를 수 있다.
모두 HP20 승리라면 생존시간과 공격 기회부터 본다. 차이가 작다고 즉시 갈래 실패로 판정하지 않는다.
게임이 너무 쉬워 차이가 가려진 경우 20 문서의 단일 변수 시험 후보를 별도 버전에서 비교한다.

- 결과 자료 충분: 비교를 종료하고 가장 영향 큰 문제 하나를 수정. 선택적 반복 시험을 계속 늘리지 않는다.
