# 별도 영웅 뽑기·레벨업 성장 — 밸런스와 검수 제안

- 작성일: 2026-10-02 (America/Chicago)
- 문서 종류: 제안·검수 계획
- 상태: 운영 초안 / 수치 미검증 / 게임 실행 미검수
- 관련 결정: 몬스터 처치 자원으로 영웅 뽑기, 레벨업 카드로 영웅 강화

## 1. 결정된 흐름

적 처치 → 경험치와 뽑기 자원 획득 → 경험치 레벨업으로 강화 카드 선택 → 모은 자원으로 별도 영웅 뽑기.

레벨업 카드에 영입을 넣지 않는다. 한 런의 진영이 섞이지 않는다. 아래 시작 인원·보장·대기석·수치는 제안이며 결정 사항과 구분한다.

## 2. 영입 운영 [제안]

| 상태 | 처리 |
|---|---|
| 시작 | 비비 1명 지급 |
| 고철 부족 | 뽑기 버튼 비활성화, 필요한 고철 표시 |
| 새 영웅 / 출전 3명 미만 | 영입 대기 → 다음 웨이브 준비 단계에 배치 |
| 새 영웅 / 출전 가득 참 | 대기석 보관 → 준비 단계에 교체 |
| 보유 영웅 중복 | 해당 영웅 승급 재료 누적 |
| 최대 승급 영웅 중복 | 표시된 고철 일부 환급. 환급량은 지출보다 적게 제한 |
| 첫 두 번 뽑기 | 미보유 영웅 보장. 고철 소모 횟수와 보장 횟수를 함께 기록 |

뽑기 결과는 플레이어가 누르는 별도 버튼으로 발생한다. 전투 중 뽑은 영웅의 배치는 다음 준비 단계에서 수행해 기존 웨이브 사이 배치 규칙을 유지한다.

한 번의 뽑기는 자원 확인·차감·횟수 증가·결과 지급을 한 번의 처리로 묶는다. 저장/로드가 있는 빌드는 처리 도중 중단되어도 결과나 자원이 두 번 적용되지 않게 한다.

대기석 이동과 교체는 영웅별 카드·승급·궁극기 충전 상태를 유지한다. 교체로 체력 회복이나 궁극기 초기 충전을 다시 받지 않는다.

## 3. 경험치와 카드 [제안]

- 파티 경험치를 공유한다. 마지막 타격 영웅에게만 경험치를 주지 않는다.
- 실제 적 사망 시 경험치와 고철을 각각 한 번 지급한다.
- 경로 완주 퇴장·아군 소환물·중복 사망 호출은 보상을 주지 않는다.
- 초과 경험치와 동시 레벨업을 보존한다.
- 카드 화면에서 이동·공격·생성·궁극기 충전을 정지한다.
- 현재 출전한 영웅의 유효 카드만 풀에 넣는다.
- 카드 ID 중복 제시, 최대 횟수 초과, 선행 조건 불충족을 제외한다.
- 부족한 선택지는 서로 다른 공용 보조 카드로 보충한다. 반복 가능 여부와 상한을 데이터로 정의한다.
- 기존 웨이브 종료 카드 성장과 이중 지급하지 않는다.
- 카드 선택 중 뽑기 입력은 보류하거나 비활성화하여 두 보상 화면이 충돌하지 않게 한다.
- 적이 없는 상태에서 마지막 레벨업과 결과 화면이 겹치면 런 종료 판정을 우선한다. 보스 처치 후 무의미한 성장 화면이 결과 진행을 막지 않게 한다.

## 4. 시험 수치 예시 [제안·미검증]

이 표는 정상 완료 런의 총 실제 처치가 약 200~260회라고 가정한 시작값이다. 현재 게임의 실제 처치 수를 확인한 값이 아니다. 생성량이 다르면 요구량·비용을 다시 맞춘다.

| 항목 | 시작값 예시 | 목적 |
|---|---|---|
| 처치 보상 | 일반 적 1회 처치=경험치 1·고철 1 | 첫 시험판에서 획득 경로를 단순화 |
| 레벨업 요구 경험치 | 다음 레벨마다 8, 12, 16, 20, 24, 28, 32, 36, 40, 44 | 총 200~260회 처치에서 카드 선택 8~10회 |
| 누적 레벨업 기준 | 8, 20, 36, 56, 80, 108, 140, 176, 216, 260 | 초반 빠른 성장, 후반 선택 간격 증가 |
| 뽑기 비용 | 10, 15, 25, 35, 45, 55, 65; 이후 회당 +10 | 초반 영입 후 중복·교체를 점차 고민 |
| 뽑기 누적 지출 | 첫 6회 185, 첫 7회 250 | 환급 없는 200~260 고철 가정에서 6~7회 뽑기 |
| 중복 승급 | 기본 1성, 2성까지 재료 1, 3성까지 추가 재료 2 | 기본 성능 성장과 카드 빌드 성장 분리 |
| 승급 성능 | 2성 기본 공격력 +10%, 3성 +20%로 대체 | +10%와 +20%를 연속 곱하지 않음 |

첫 두 번은 미보유 영웅 보장이므로 기본 3종 시험판의 나머지 뽑기는 중복 승급이 중심이다. 6종 확장판에서 새 영웅·대기석·교체의 선택을 평가한다.

최대 승급 중복 환급, 정예 가중 보상, 보스 보상은 총 획득 자원과 뽑기 횟수를 바꾸므로 위 가정과 분리해 기록한다. 카드 화면과 준비 시간을 포함한 실제 소요 시간은 전투 시간보다 길 수 있다.

영구 보유가 결정되지 않은 첫 시험판 기본안은 새 런에서 파티·고철·경험치·카드·승급을 초기화하는 것이다. 영구 수집을 채택할 경우 해당 부분을 별도 문서로 결정한다.

## 5. 개발 우선순위 [제안]

| 단계 | 구현 | 완료 판단 |
|---|---|---|
| P0-A | 처치 경험치·고철, 별도 뽑기, 단일 진영 제한 | 같은 사망 보상 1회, 자원 차감=결과 지급 |
| P0-B | 기본 3종, 영입 대기·배치, 중복 승급 | 출전 최대 3명, 카드 영입 없음 |
| P0-C | 레벨업 카드 3장과 정지·재개 | 초과 경험치 보존, 유효 카드만 제시 |
| P0-D | 7분 전투, 장갑 적·군집, 수동 궁극기 | 전투 역할과 성장 변화를 읽을 수 있음 |
| P1 | 추가 영웅 3종, 대기석 교체, 빌드 확장 | 같은 진영 내 조합과 배치의 차이 확인 |
| P2 | 다른 2진영, 영구 수집 선택 후 저장 구조 확장 | 기존 진행·저장과의 호환 검수 |

이미 대기석·교체를 지원하는 빌드라면 P0에서 재사용하고, 지원하지 않으면 기본 3종의 뽑기·성장부터 확인한다. 구현 상태를 보지 않고 새 시스템을 이미 있다고 가정하지 않는다.

## 7. 밸런스 실험

- 첫 영입 시점: 비비 1명만으로 첫 고철 뽑기까지 버틸 수 있는지 확인한다.
- 성장 빈도: 실제 총 처치와 카드 선택 횟수를 비교한다. 적 생성량으로 경험치 곡선을 보정한다.
- 뽑기 경제: 고철 획득·지출·환급과 뽑기 횟수를 기록한다.
- 역할 차이: 같은 조건의 군집·장갑 정예·단독 보스에서 3병종 기여를 비교한다.
- 배치 차이: 같은 시드·카드·승급으로 입구/후반/중앙 배치의 처리·누수를 비교한다.
- 성장 체감: 카드·승급 전후 공격 장면과 실제 기여를 비교한다.
- 런 길이: 전투 시간·카드 정지 시간·준비 시간·전체 소요 시간을 분리해 기록한다.
- 확장 후 조합: 6종 중 3명으로 구성했을 때 특정 조합이 모든 상황을 지배하는지 확인한다.

합격을 추정값으로 선언하지 않는다. 수치는 실제 플레이 기록을 얻은 뒤 조정한다.
