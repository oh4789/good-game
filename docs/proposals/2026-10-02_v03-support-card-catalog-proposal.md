## 1. 목적과 적용 경계
첫 중복의 2갈래 선택은 공격 방식을 결정하고, 경험치 카드는 해당 공격의 화력·빈도·공격 가능 구간을 보완한다.
아래 12종은 현재 구현 카드 목록을 확인한 결과가 아니라 대체·정리 후보다. 실제 카드 목록을 인수해 동등 효과를 먼저 매핑하고 채택된 차이만 구현한다. 기존 카드 위에 전부 추가하지 않는다.
사용자 확정 방향은 자동 전투·첫 중복 승급/갈래·계속 승급·경험치 3택1이다. 아래 이름·ID·수치·상한·추첨은 모두 제안이다.
기존 핵심/완성 카드, 수동 궁극기 카드, 영웅 지급 카드는 포함하지 않는다. 이 제안으로 갈래가 자동 해금되거나 승급 단계가 오르지 않는다.

## 3. 계산 규칙 후보 — 현재 소스와 다르면 변경안으로 심의
k=승급 횟수, a/s/r=해당 영웅 카드 레벨, A/S/R=공용 카드 레벨.
- 피해 계수: (1+0.18k) × (1+0.10a+0.04A).
- 공격 간격: 갈래 기준 공격 간격 ÷ (1+0.08s+0.03S).
- 사거리: 갈래 기준 사거리 × (1+0.05r+0.02R).
- 갈래 고유 피해 계수·방어 처리는 실제 구현 순서를 확인한다. 위 식은 승급/보조 카드 항목만의 후보다.
- 피해 카드 보너스는 영웅 소유 직접 피해와 소이 틱에 한 번만 적용한다. 공격력 기반 장판 생성 시 이미 적용했다면 틱에서 다시 곱하지 않는다.
- 공속은 발사/장판 생성 빈도에 적용하고 기존 장판의 틱 간격·지속시간을 바꾸지 않는다.
- 사거리는 표적 획득 범위다. 폭발 반경·소이 반경·관통 길이·표적 수는 바꾸지 않는다.
- 공격 속도 +8%는 공격 간격 -8%와 다르다. 간격1초라면 1/1.08≈0.9259초.
- 현재 구현의 공속 상한과 최소 간격을 먼저 확인한다. 이미 상한으로 효과0인 카드는 후보에서 제외하고 이유를 기록한다.
- 진행 중 탄환/장판의 새 카드 반영 시점은 현재 스냅샷 정책을 확인한다. 이 문서가 전투 중 소급 재계산을 요구하지 않는다.

검산 예: 승급2, 전용피해2, 공용피해1이면 승급/카드 합성은 1.36×1.24=1.6864.
전용공속2·공용공속1이면 간격은 기준/1.19.
전용사거리2·공용사거리1이면 기본사거리×1.12.
피해는 소수 유지 후 실제 표시에서만 반올림하는 후보이며 엔진과 UI가 별도로 다른 결과를 계산하지 않도록 한다.

## 4. 집중과 공용의 선택 가치 — 조건부 산술
한 영웅의 현재 파티 유효 피해 비중을 p라 하고 다른 조건·보너스가 없으면 전용 피해 +10%의 파티 증가분은 약0.10p, 공용 +4%는 약0.04다.
p>40%이면 전용이 유리할 수 있다. p<40%이면 공용이 유리할 수 있다.
이는 카드 보너스0의 단순 모델이다. 이미 피해 카드가 있거나 과잉 피해·노출시간·장판 중첩이 달라지면 경계도 바뀐다.
공속은 단순 공격 빈도 가정에서 3/8=37.5%가 대응 경계지만 소이 장판 중첩이나 발사 제한 때문에 실제 효율은 따로 측정한다.
사거리는 피해처럼 선형 효율을 계산하지 않는다. 사각 경로와 배치 때문에 특정 거리에서 공격 가능 구간이 크게 바뀔 수 있다.

## 5. 갈래별 카드 선택 가이드 [가설]
| 갈래 | 먼저 볼 카드 | 선택 이유 | 다른 카드로 전환할 때 |
|---|---|---|---|
| 비비 연사 | 비비 조준 보정 / 강화 탄약 | 같은 표적 공격 구간과 집중 화력 | 이미 충분히 오래 공격하면 공속 비교 |
| 비비 탄막 | 급속 장전 / 공용 탄약 보급 | 반복 발사와 파티의 남은 적 처리 | 적중 전 과잉 피해가 많으면 배치부터 확인 |
| 탄코 폭발 | 강화 탄약 / 급속 장전 | 한 번에 죽이는 기준 또는 후속 폭발 | 착탄 전에 표적이 자주 사라지면 단순 화력 추가 보류 |
| 탄코 소이 | 강화 탄약 / 조준 보정 | 실제 틱 피해와 장판을 놓을 수 있는 구간 | 장판 중첩으로 공속 효율이 낮으면 피해 우선 비교 |
| 로코 유도 | 강화 탄약 / 급속 장전 | 강한 표적에 들어가는 피해 | 사거리 이탈이 주원인이면 조준 보정 |
| 로코 관통 | 조준 보정 / 강화 탄약 | 발사 기회와 관통 피해 | 사거리만 늘려 직선 정렬이 좋아진다고 단정하지 않음 |

특정 카드가 항상 정답이라고 표시하지 않는다. 현재 적·배치·승급과 무관한 추천 화살표 자동 제공은 보류한다.
무기를 관통/소이로 바꾸는 효과는 카드에 넣지 않는다. 카드로 약점을 줄일 수 있지만 갈래의 공격 방식은 유지한다.

## 6. 대표 투자 예시
아래는 선택 순서 예시일 뿐 9회 선택 보장·현재 XP 곡선·최적 빌드가 아니다. 등장하지 않은 카드를 강제로 지급하지 않는다.
- 집중 화력 6선택: 주력 피해2 + 주력 공속2 + 주력 사거리1 + 공용 피해1.
- 균형 파티 6선택: 공용 피해2 + 공용 공속2 + 가장 취약한 영웅 피해1 + 그 영웅 사거리1.
- 공격 구간 보완 6선택: 주력 사거리2 + 두 번째 영웅 사거리1 + 공용 사거리1 + 공용 피해2.
마지막 조합은 모든 배치에서 우월하지 않으며 과한 사거리로 배치 의미가 사라지는지 우선 관찰한다.
갈래 미선택 상태에서 얻은 보조 카드는 첫 승급 이후에도 해당 영웅에게 유지되는 후보다. 갈래 선택으로 카드가 사라지거나 무료 재선택되지 않는다.

## 7. 추첨·상한·빈 풀 처리 후보
최소안은 유효한 고유 카드 ID 중 균등·비복원 추첨으로 3장을 제시한다.
전용2+공용1, 핵심 우선, 목표 카드 보장 같은 구안은 자동 이식하지 않는다. 현재 추첨 정책이 있으면 유지안과 비교한 뒤 채택한다.
유효 조건: 소유/공용 최소인원/레벨상한/실제증가량>0. UI 다시 표시만으로 후보를 재생성하지 않는다.

초기 영웅1명·공용 비활성·3전용 카드 상태에서 각 상한5/5/3이다. 서로 다른3ID를 9번째 선택까지 유지하려면 특정 카드만 골라 상한에 닿는 경우도 고려해야 한다. 따라서 이 구성만으로 모든 선택 화면에3종을 보장하지 못한다.
이 문제를 가리기 위해 무효 카드나 미보유 카드를 끼워 넣지 않는다.
채택 전 실제 최대 카드 선택 횟수와 영입 지연 시나리오로 남는 ID수를 검증한다. 후보가3개 미만일 수 있으면 상한 재설계 또는 별도 반복 보조 카드 정책을 먼저 결정한다.
검토 권고: 현재 카드 풀/상한이 정상 작동하면 그대로 유지하고 위12종은 효과 정리와 교체 후보로만 사용한다. 이 문서의 추첨안을 미완성 상태로 출시하지 않는다.

## 8. 카드 문구·비교 표시
전용 예:
“비비 · 강화 탄약”
“비비의 피해 보너스 +10%p”
“카드 피해 보너스 10% → 20% · Lv.1 → Lv.2”
“승급과 갈래는 바뀌지 않습니다.”는 최초 도움말에서만 설명한다.

공용 예:
“공용 · 정비 지원”
“모든 영웅의 공격 속도 보너스 +3%p”
“나중에 합류한 영웅에게도 적용됩니다.”

사거리 예:
“탄코 · 조준 보정”
“기본 사거리의 5%만큼 증가”
“폭발과 불길의 크기는 그대로입니다.”

전체 최종 수치를 표시할 수 있으면 엔진 계산 결과를 사용한다. +10%p 카드 문구 옆에 최종 DPS +10%라고 쓰지 않는다.
갈래 선택은2개, 강화 선택은3개라는 화면 차이를 유지한다.

## 9. 인수·검수 항목
1. 실제 카드 목록과 제안12ID의 유지/대체/미채택 매핑.
2. 전용 대상 외 다른 영웅 능력 불변.
3. 공용 효과가 이후 합류 영웅에 정확히 한 번 적용.
