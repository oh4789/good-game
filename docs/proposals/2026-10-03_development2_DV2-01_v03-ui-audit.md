## 실행과 검증

Ubuntu24.04 / Godot4.6.3 / Xvfb 실제 native renderer. headless에서는 실제 Godot 입력 이벤트·컨트롤 좌표를 검증하고 별도 native 실행에서 픽셀을 캡처했다. 오디오는 장치 부재로 Dummy fallback이므로 검증하지 않았다.

패키지 DV2-01 디렉터리에서 XDG_DATA_HOME, XDG_CONFIG_HOME, XDG_CACHE_HOME을 각각 그 디렉터리의 user/config/cache로 설정하고 실행한다:

```sh
godot --headless --path runtime-project --editor --import --quit
godot --headless --path runtime-project --script DV2Audit.gd
xvfb-run -a godot --audio-driver Dummy --path runtime-project --script DV2Capture.gd
```

원본 QA/independent/UIAdversarial.gd를 전용 하네스로 복제·확장했다. 숨겨진 라벨을 화면 이탈로 오인하던 조건을 제외했고, 상세창의 스크롤 높이99px는 접근 불가가 아닌 사용성 주의로 구분했다. 결함 재현 때문에 audit 종료코드1은 예상 결과다.

**103개 assertion: 100 통과, 3 실패.** 실패3개는 영웅 카드 이탈을 시작/진급에서 각각 검출한2건과 XP 세 번째 카드 이탈1건이다.

시작·영입·첫 중복2갈래·상세·XP·결과·새 런을 4크기에서 총28장 캡처해 모음 이미지로 직접 확인했다. 가로 시작/XP, 320 상세, 390 진급은 개별 원본 이미지도 확인했다. 원정종료 화면의 영웅이 종료 글자 위에 그려지는 별도 시각 결함을 발견했다.

통과:
- 마우스/합성 터치 영입 취소·확정·결과 닫기, 중복 비용 차감 방지.
- 진급 상세 확인/취소/확정, 대기 XP 처리, 오래된 epoch·즉시 재확정 거부.
- Escape/뒤로가기, 수동·포커스 일시정지 보존, 새 런 상태 초기화.
- 실제 Tab15회 모달 내부 초점 유지.
- 격리 저장 경로에 최고 웨이브7 저장 후 새 화면에서7 로드, 새 원정은 배치·초기 영웅1명.
- 관측 화면에 궁극기·3성 MAX·중복 재료 안내 없음. 모든 가능한 텍스트 경로의 부재를 증명한 것은 아님.

미검증/제약:
- 실제 휴대폰, iOS/Android 브라우저, 운영 Site 로그인/WASM/브라우저 저장과 접근성 트리/스크린리더.
- 캡처는 경제·종료 상태를 주입한 UI fixture다. 완주·밸런스 검증이 아니다.
- 세로 캡처 배치에서 몸체/무기 잘림은 관측하지 않았지만 모든 공격 방향·고승급·애니메이션 극값은 검증하지 않았다.
- 가로 상세 본문99px는 스크롤 가능하고 닫기/확정도 보인다.
- v0.3 중간 런 이어하기 미지원은 결함으로 계산하지 않았다.
