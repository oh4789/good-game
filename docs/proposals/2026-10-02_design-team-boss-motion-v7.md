## 차이와 처리 제안
- 이전128px 디자인과 최신18의 영웅 원본256px 제안이 다르다. 정리 작업은256px·정규화 원점(0.5,0.75)을 우선 후보로 하며128은 선택 파생본으로 둔다. 보스256px는 별도 디자인 제안이고 엔진 확정 규격이 아니다.
- 05의 체력50% 이하 장갑해제1회·무적/회복 없음 유지. 판이 떨어지는 동안에도 이동·피해 판정을 유지한다.
- 노출된 화로는 새 약점 배율을 뜻하지 않는다.
- 최신18의 탈갑 시 파쇄·R02 제거안을 채택하면 대응 아이콘/VFX도 제거한다. 장갑0에 파쇄 효과를 다시 만들지 않는다.
- 보스 파괴는 즉시 승리를 뜻하지 않는다. 호위 생성/생존적/공용HP 조건은 로직에서 확인한다.

## 제작할 애니메이션 [제안]
| 동작 | 목표 | 동작/중단 |
|---|---|---|
| 장갑 이동 | 6프레임/600ms 반복 | 바퀴 회전·작은 차체 운동·깃발 후행 |
| 탈갑 이동 | 6프레임/600ms 반복 | 같은 위상에서 앞판만 제거 |
| 장갑 해제 | 4프레임/240ms 1회 | 40/60/80/60ms, 사망·누수 시 중단 |
| 피격 | 밝기 강조60ms | 이동 위상 초기화 없음 |
| 파괴 | 6프레임/240ms 1회 | 각40ms, 붕괴·바퀴 이탈·먼지 소멸 |
| 누수 | 현재 본체 재사용 | 장갑 상태 유지한 채 퇴장, 처치효과 없음 |

위 숫자는 앞으로 제작할 목표이며 시안 패널 수가 아니다. 이동 위치·속도는 경로 로직을 따르고 바퀴 재생률은 실제 화면에서 조정한다. 사망 시 즉시 표적/충돌에서 제거하고 보상1회, 잔해는240ms 내 소멸한다. 누수 보상0 유지.
로직이 확정한 사망 또는 누수 > 장갑해제 > 피격 > 이동 순으로 표현한다. 사망/누수 동시 판정 순서는 개발 명세를 따른다. 한 타격으로 사망하면 탈갑 전용 연출을 생략한다. 반복 피격으로 탈갑 연출을 재시작하지 않는다.

## 파일 정리 후보
256×256, 원점(128,192). 본체·바퀴·조종사/깃발·장갑판·먼지/파편·그림자를 분리한다. 효과 잘림은 별도 캔버스로 해결하고 본체 크기를 프레임마다 바꾸지 않는다. 누수 경계는 캐릭터에 굽지 않는다. 시안 붉은 문/깃발은 새 게임 오브젝트가 아니며 제외한다.
예정 파일명: boss_scrap_king_armored_move_00~05.png, exposed_move_00~05.png, armor_release_00~03.png, death_00~05.png. 실제 파일은 아직 없다.
manifest에는 파일명·순서·durationMs·canvas·pivot·loop·layer·전환 조건을 기록한다.

## 검토 결과
장갑 낙하와 파괴는 구분되고 보스 정체성은 유지됐다. 이동 바퀴 위상·차체 위치는 정렬되지 않아 연속 루프 사용 불가. 화로 밝기는 축소 화면에서 추가 검수 필요. 먼지·배경·설명이 합쳐져 바로 투명 스프라이트로 자를 수 없다. 누수는 장갑 상태 예시만 그렸으므로 실제 탈갑 상태 누수도 필요하다.
이미지 육안 확인만 완료. 알파·원점·연속재생·모바일 실기·게임 통합 미검수.
