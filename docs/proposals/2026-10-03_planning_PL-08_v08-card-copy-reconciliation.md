## 문제점·예상 효과·검증 조건

높은 우선순위는 **첫 영입/중복 혼동과 공용 카드 대상 안내** 두 가지다. 플레이어가 카드·영입의 의미를 잘못 이해할 가능성이 직접 근거이며, 새 영웅·카드 풀이나 밸런스 변경 없이 줄일 수 있다.

나머지는 합산 방식과 성장 범위의 설명 보완이다. 카드명·화면 구조를 유지하는 문자열 변경 정도의 작업량이다. 긴 상세 설명은 작은 화면에서 읽기 부담이 있으므로 전면 안내는 짧게 두고 기존 스크롤 상세를 사용한다. 스크롤 코드가 있다는 사실만으로 실제 글자 잘림과 버튼 접근을 통과했다고 하지 않는다.

채택 후 개발2/QA 인수 조건:
1. 신규 합류·첫 중복·추가 중복을 각기 표시하며 선택 전 rank0/선택 후 rank1을 혼동하지 않음.
2. 공용 HP 후보가 표시돼도 카드 선택 안내가 영웅 공격 강화로만 한정되지 않음.
3. 1.56/1.64 배율 예와 전용/공용 횟수 표시가 모델 상태와 대응.
4. 최소 지원 세로·가로 화면에서 보충 본문 스크롤과 닫기/확정 버튼 접근 가능.
5. 문구 열기·닫기·복원으로 카드·영입이 재적용되거나 재추첨되지 않음. 기존 ResumeUI 검수를 재사용하고 변경 부분만 확인.
6. 이미 저장된 원정의 카드·승급·선택 상태를 바꾸지 않음.

현재 규칙 충돌 없음. 범위는 설명 보완이며, 실제 반영은 담당자 인수 뒤 진행한다.
