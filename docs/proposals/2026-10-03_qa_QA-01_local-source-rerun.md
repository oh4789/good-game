## 문제점

1. 배포 Site 인증 접근은 이전 차단 상태다. 이번에는 로그인을 재요청하거나 우회하지 않았다. 실행 접근 실패를 게임 결함으로 집계하지 않는다.
2. Godot import 때 로컬 TCP listen 생성 실패 로그가 발생했다. import 종료 코드는 0이며 이후 네 실행 로그에는 ERROR/SCRIPT ERROR가 없고 모든 실행이 0으로 종료됐다. 환경 소켓 제한과 관련된 도구 단계 문제로 기록하며 게임 오류로 단정하지 않는다.
3. 카드 정책이 조합마다 달라 공정한 밸런스 비교가 아니다. 모든 런 HP20이라는 결과만으로 최종 난이도를 승인하지 않는다.
4. Git 커밋과 ZIP의 독립 대조, PCK/WASM, 브라우저 저장, 가로 화면, 휴대폰 성능/오디오 검증은 남았다.
