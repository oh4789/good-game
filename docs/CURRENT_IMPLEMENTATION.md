## 현재 기능과 역사적 기록의 구분

- v0.7은 3영웅 텍스처의 import 크기 제한과 축별 UV 보정을 통합했다. 원본 PNG·메시·메타데이터·발/총구 기준점은 보존했으며 런타임 소스 변경은 4개 파일에 한정된다.
- PCK는 v0.6 대비 4,007,088 bytes, 38.46% 작아졌다. 세 영웅의 디코딩된 mip 이미지 할당량은 25,154,992 → 3,959,012 bytes로 84.26% 감소했다. 전체 GPU·프로세스 메모리 절감률, FPS 개선률 또는 휴대폰 성능 보장이 아니다.
- v0.6의 적 HP·장갑·보스 전면 표시, 출입구 가독성, 실제 HP 손실량 기반 누수 피드백과 마지막 적 누수 뒤 웨이브 전환 보호를 유지한다.
- v0.5의 비비·탄코·로코 원화, 발사 사건 기반 단일 스프라이트 메시 모션, 전장 안으로 자른 배치 사거리와 전면 승급 배지를 유지한다. 완전한 관절 리그는 아니다.
- v0.4의 같은 런 이어하기·저장 schema·백업 복구·손상 보존·새 런 확인/취소 보호를 유지한다. 기존 런을 강제로 초기화하지 않는다.
- 효과음·BGM, 반응형·터치·동작 줄이기, DPR·포인터 대응을 보존한다. 신규 음향 설정 기본값은 OFF다.
- v0.1·v0.2·v0.3·v0.3.1·v0.4·v0.5·v0.6의 일곱 런타임 버전과 기존 저장 브리지를 보존했다. 엔진과 저장 경로는 바꾸지 않았다.
- [v0.3 게임 규칙](proposals/2026-10-03_v03-canonical-decisions.md)을 유지하며 밸런스 변경은 없다. 과거의 “이어하기 없음”, “v0.4 미배포”, “v0.5 아트 후보”, “v0.6 후보”, “텍스처 최적화 미배포”는 당시 상태다. 현재 구현은 이 문서와 [v0.7 보고](proposals/2026-10-03_main-v07-release-integration-report.md)를 따른다.

## 검수 경계와 다음 인수

정확한 PCK에서 8개 갈래 조합의 직접 실행·복원 16회와 실제 Screen/Store 복원 80회를 통해 v0.6 대비 전체 모델·난수·저장 UI 일치를 확인했다. 소스에서도 전체 16회 완료 기록과 복원 결과를 확인했으며, 소스 측 비교의 구성상 한계는 배포 보고에 따로 적었다. 저장·일시정지·음향·DPR 입력·적 상태·마지막 적 손실 피드백 회귀 검수를 재실행했다.

네이티브 96개 대응 프레임 쌍에서 발·총구·높이 기준점 288세트가 동일했다. 이미지 204개의 해시를 대조하고 선택한 실제 크기 화면을 시각 검토했다. 전체 이미지 수동 검토 또는 v0.6과의 픽셀 동일성을 뜻하지 않는다. 더 깊은 과거 검수는 바이트 동일 모듈·리소스 범위에서만 상속하며 모두 재실행했다고 쓰지 않는다.

**v0.7 브라우저 WASM·IndexedDB·실제 휴대폰·주관적 믹스는 독립 검증되지 않았다.** 네이티브 결과나 이전 버전의 브라우저·성능 기록을 v0.7 웹·휴대폰 통과로 옮겨 적지 않는다. Android APK·실기, PWA·safe-area, 발열·배터리·장시간 성능도 미검증이다. 런타임 제목·도움말의 이전 버전 문구는 텍스처 한정 범위 밖이라 그대로다.

다음 인수 우선순위는 승인된 접근 환경에서 현재 v0.7의 실제 브라우저 저장·재접속과 휴대폰 터치·표시를 확인하는 것이다. 새 검수·후속 개발은 현재 전달물·버전을 기준으로 한다. 과거 완료 결과는 보존하고 실제 재검수한 버전을 구분한다. 운영 파일 변경에는 담당·파일·기준 커밋·격리 브랜치·인수 조건을 먼저 확인하며, 현재 Site 최종 통합과 배포는 두리가 맡는다.

## 연구와 후속 후보

자동화된 자연 진행 208회는 밸런스 연구 자료이며 사람의 승률이 아니다. 적 조기 소멸과 전투 대기 구간을 후속 비교 대상으로 본다. 새 런에만 32초 스폰 구간을 적용하고 기존 런의 타이밍을 보존하는 격리 v0.8 후보는 계획 단계다. 현재 배포·구현 완료로 기록하지 않는다. 무작위 중복 보장이나 카드 강화 수치 변경은 승인·반영된 것으로 취급하지 않는다.
