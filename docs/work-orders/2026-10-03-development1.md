3. 기대 소스 기준은 `922f0808783aa31a88395a80c877e71bce7f0edc`다. 커밋 식별자와 ZIP 해시는 구분한다.
4. 현재 공개 GitHub에는 게임 소스가 없다. 소스를 받지 못하면 파일명·기대 버전·필요한 접근을 적고 BLOCKED로 남긴다. 문서만으로 코드 구현 또는 실행 성공을 주장하지 않는다.

### 격리 작업 범위

- 인수한 소스의 별도 사본을 사용한다. Git 작업이면 로컬 격리 브랜치 `work/dev1-v03-benchmark-20261003`를 쓴다.
- 이번 쓰기 허용 범위는 그 사본의 새 전용 경로 `workbench/dev1/DV1-01/` 안의 도구·고정 입력·결과다. 이 경로는 전달할 검수 도구용이며 기존 게임 경로가 있다고 주장하는 것이 아니다.
- 기존 전투·성장·저장·UI·음향 파일과 게임 데이터는 수정하지 않는다.
- 실제 엔진 API를 읽어 재사용한다. 필요한 계측이 생산 코드 수정 없이는 불가능하면 정확한 파일·최소 변경안을 제안하고 인계를 기다린다.

### 검수할 내용

- 8조합 C01~C08은 QA 지시서와 같은 행 순서를 사용한다.
- 동일 배치·승급·보조 카드·적 생성·입력 조건을 고정한다. 시드뿐 아니라 난수 소비와 입력 순서도 기록한다.
- 첫 묶음은 조합별 동일 조건 1회와 동일 입력 재실행 1회다. 총 16회 실행은 8개의 서로 다른 조건을 반복한 것이며, 16개의 서로 다른 사용자 플레이가 아니다.
- 재현 가능한 결과나 상태 해시로 두 실행의 일치 여부를 확인한다. 비결정성이 남으면 원인과 해당 범위를 보고하고 DONE을 선언하지 않는다.
- HP, 처치·누수, 완료 시간, 갈래·승급·카드 상태와 가능한 유효 피해를 기록한다. 얻을 수 없는 값은 미측정으로 둔다.
- 강제 갈래·고철·승급 주입이 있으면 검수 도구 전용으로 명시하고 자연 성장·획득 확률 측정과 분리한다.
- 현재 비용·공격력·적 HP·이동 속도·갈래 수치는 바꾸지 않는다. 강약 의견은 실측 근거가 있는 제안으로만 남긴다.
- 기존 178항목·40시나리오 보고를 자신의 실행 결과에 합산하지 않는다.

- 실제 엔진 소스를 사용하는 벤치마크 도구, 고정 입력, 실행 명령과 필요한 버전
