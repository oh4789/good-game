## 해석
1. 전투 시간은 약 6분40초~6분59초다. 7분 전투 목표와 가깝지만 선택 시간을 더한 실제 한 판이 7분이라는 근거는 없다.
2. 평균 최단 C03과 최장 C06의 차이는 16.024초다. 카드 우선 정책·획득 이력·승급 시점이 섞였으므로 최강/최약 순위로 쓰지 않는다.
3. 탄코 피해 비중이 모든 조합에서 56.42~73.47%다. 고정 배치, 광역 피해, 적 구성, 다른 영웅의 처리 순서가 함께 영향을 준다. 이 비율만 보고 탄코를 하향하지 않는다.
4. 전부 무누수라 HP·승패 지표는 이 조건에서 조합의 여유 차이를 구별하지 못한다. 적이 어느 구간까지 진행했는지, 보스 처리 여유가 얼마나 남았는지 추가 관측이 더 유용하다.
5. 기존 전체 런의 성공은 성장 포함 자동 정책의 기능 증거다. 카드0·승급1 고정 상태의 성공까지 보장하지 않는다.
