## 기준 확인
현재 자동 전투·수동궁극기 없음·첫 중복 즉시 승급2갈래·계속 성장·런 한정 보유 기준을 따른다. 디자인v8 이전18안에 있던 수동궁극기·3성 상한은 적용 기준이 아니다. 원본128/256 제안 역시 엔진 확정값으로 취급하지 않는다.
WORK_START_HERE, 디자인 지시서, canonical, character-sources-v2, hero-motion-review-v8을 직접 읽었다. 확인한 docs 트리에는 기존 DS-01 결과 문서가 없었다.

## 실제 인수와 발견
3영웅 정적 원화 실파일을 열었다. 비비/탄코/로코1536×1024 RGBA 파일을 보존하고 빛 번짐·경계 접촉 상태를 재확인했다. 탄코 좌측·로코 하단의 알파 경계 접촉은 최종 납품 통과가 아니다.
별도 기존 데모를 파일 검색으로 찾아 실제 인수했다.
- Bibi_Machinegun_Motion_v01.mp4:1280×720,30fps,11초,330프레임.
- Bibi_Machinegun_Godot_Source_v01.zip:project.godot,Main.tscn,Main.gd,README,render.sh,원본 atlas,기존 QA기록 포함.
- bibi_atlas.png를 직접 열고 Main.gd의15개 파츠 영역·원점·위치를 읽었다. 팔2관절·머리/뒷머리 다각형 UV창·무기반동·포구효과가 존재한다.

중요 외형 충돌: 기존 컷아웃은 흰 머리·토끼귀·붉은 의상의 비비, 이 디자인 대화의 원화는 검은 포니테일·주황 스카프·남색 작업복 비비다. 어느 외형이 최종 승인됐는지 canonical은 명시하지 않는다. 두 버전을 같은 원본의 수정판으로 취급하지 않는다. 기존 리그를 삭제하거나 전체 영웅을 다시 그리지 않았다.

## 재사용 및 보완
재사용 후보: 기존 컷아웃 파츠 배치, 팔 조준 방식, 무기 반동, gun.to_global(Vector2(198,-25)) 포구 연결, 대기/조준/사격/탄약점검 구성.
보완: 파츠 경계·색 번짐·손 접점, 화면크기와 방향, 실제 게임 이벤트 연결. 기존Main.gd는 _process에서frame을1씩 늘리고frame/FPS로 시간을 산출하므로실제delta를사용하지않는다. 고정30fps영상과실시간게임속도는같다고보장할수없다. 리그 소스는인수보존만했고수정하지않았다.
기존'reload'는탈착탄창장전이아닌탄약공급부손동작이다. 새 재장전 판정·영웅 개인HP·수동궁극기를 추가하지 않는다.

## 이번 진행 중이던 비교본
지시서 확인 전 시작한 검은 포니테일 비비 단일포즈 보완을 비교 자료로만 보존했다.

- alpha>0 전체영역(0,21,1220,1254)으로 저알파 잔여 픽셀이 남아 깨끗한컷아웃합격아님.
