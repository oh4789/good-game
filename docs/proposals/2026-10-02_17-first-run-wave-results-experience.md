## 3. 첫 판 안내 — 행동에 맞춰 짧게 [제안]
새 별도 튜토리얼 전투를 만들지 않고 기존 첫 런에 비차단 안내를 붙인다.
게임 규칙과 보상은 숙련자 런과 동일하다. 안내를 읽지 않았다고 적 생성을 지연하지 않는다.
한 번에 안내1개,전장 밖의 고정 도움말 영역 사용. 사용자가 닫거나 관련행동을 하면 해제한다. 표시 최대6초는 시험값이며 카드/수동정지/앱숨김 중에는 안내시간도 정지한다.
도움말은 설정에서 다시 켤 수 있다. 읽음 상태는 도움말 설정이며 영구영웅보유와 다른 데이터다.

### 안내 충돌 우선순위
결과/패배 → 카드세션 안내 → 준비의범위불일치·미배치 안내 → 궁극기·영입 안내 → 일반설명.
대기 안내는 현재조건을 재확인해서 아직 필요한 것 하나만 노출. 이미 영입한 뒤 '영입하세요'가 뒤늦게 뜨지 않는다.
안내창은 보상·일시정지 상태를 직접 바꾸지 않는다.

## 5. 보스와 승패 가독성
- 보스HP와장갑상태는별도표시. 50%탈갑은1회로직과연동한다.
- 보스가죽어도예정호위가있으면 '보스 처치 · 남은 호위를 막으세요'.
- 예정생성이남아있으면승리음·결과화면을표시하지않는다.
- 성공:보스처치+예정생성완료+생존적0+공용HP>0.
- HP0은같은tick의성공보다우선. 보스완주실패는채택된시험규칙에따른다.
- 사망과누수는효과·보상·음향을구별. 그림의출구선은실제경로경계와일치시킨다.
이 섹션은05/07 규칙을 사용자표현과 연결하며 새로운보스능력을추가하지않는다.

## 6. 결과 화면 — 핵심 먼저, 자세한 기록은 펼치기
첫화면:
1. '밤길 방어 성공' 또는 '원정 종료'.
2. 도달웨이브·최종HP·플레이시간.
3. 관측된사실을기반으로한한줄피드백.
4. '다시 도전' 및 '상세 기록'.

상세기록:
- 영웅3명과대기영웅,별·빌드·전용카드·공용카드.
- 유형별누수수량·피해. 피해는소리묶음횟수가아닌모든누수사건합.
- 영웅별실제피해·처치·궁극기사용횟수.
- 고철획득/지출/환급,영입횟수.
- 전투/준비/카드선택시간,별도일시정지시간.
- 확장지원영웅의기여는지원대상·지원시간으로별도표시. 아군피해를토리피해에더하지않는다.

플레이시간=전투+초기/웨이브준비+카드선택. 중첩상태를이중합산하지않는다.
6~8분은목표다. 오래고민한사람에게플레이실패나낮은평가등급을부여하지않는다.

## 7. 재도전·중도 종료·도감 범위
- 일반다시도전:새시드,새런. 고철/XP/영입/별/카드/충전/장판/입력예약/보류알림초기화.
- 유지:음량·효과설정·도움말표시설정. 도감/해금은아직미결정이므로임의저장보상추가없음.
- 같은시드재도전은개발검수옵션. 일반다시도전과구별한다.
- 진행중중도종료는정지화면에서가능. '현재 원정을 종료할까요?'와'계속하기/종료' 표시.
- 중도종료는패배통계에섞지않고abandoned로구분. 승리보상·가상의재화를지급하지않는다.
- 새런버튼연타는한번의run_id만생성. 이전런의소리·탄환·카드입력이새런으로넘어오지않음.
- 영웅도감은후속후보. 첫빌드에는보유영웅정보화면으로충분하며영구수집규칙결정전해금재화를만들지않는다.
