## 반영 범위와 측정

런타임 소스 변경은 다음 4개 파일에 한정된다.

- `assets/bibi.png.import`
- `assets/tanko.png.import`
- `assets/roko.png.import`
- `scripts/CogHeroVisual.gd`

세 PNG의 원본 바이트는 그대로 보존했다. import size limit과 Polygon2D의 축별 texture scale을 함께 조정했다. 실제 import 결과는 비비 512×512, 탄코 512×426, 로코 512×512다. 원본 픽셀 기준 메시·메타데이터·발/총구 앵커·정규화 UV와 게임플레이 모델·저장 schema·음향·DPR·적 전면 상태·누수 피드백을 유지한다.

| 측정 대상 | v0.6 | v0.7 | 감소 |
|---|---:|---:|---:|
| PCK bytes | 10,418,120 | 6,411,032 | 4,007,088 (38.46%) |
| 세 영웅 decoded mip image bytes | 25,154,992 | 3,959,012 | 21,195,980 (84.26%) |

두 번째 값은 해당 세 영웅의 디코딩 이미지와 mip 할당량이다. 전체 GPU·프로세스 메모리, 다운로드 전체 크기, FPS 개선 또는 휴대폰 성능 측정으로 표현하지 않는다. WEB 보존본에는 과거 런타임도 포함되므로 PCK 절감률을 ZIP 전체 절감률로 옮기지 않는다.

v0.6 이하 일곱 런타임과 저장 브리지의 바이트를 보존했다. 엔진 전송물은 동일하고 배포 설정의 PCK 파일 크기만 조정했다. 루트 HTML은 버전 표시와 v0.6 이력 링크만 바뀌었다.

## 독립 검수 결과

소스·정확한 PCK·네이티브 한정 최종 QA는 2026-10-03 06:13:21 UTC PASS, 최종 SOURCE 결속 대조는 06:15:02 UTC PASS다. 이후 배포 및 보존본의 실제 재조회로 게시·전달을 별도로 확인했다.

- 16개 컴파일 스크립트를 깨끗한 재컴파일 결과와 대조했다. 변경된 스크립트는 지정된 영웅 시각 처리 1개뿐이다. 재컴파일 PCK 전체 해시는 export 메타데이터 때문에 다르므로 전체 바이트 동일이라고 쓰지 않는다.
- 리소스 39개가 모두 로드됐고 변경된 로드 리소스는 지정한 영웅 텍스처 3개다. 나머지 런타임 소스·컴파일 모듈·리소스는 허용 범위대로 보존됐다.
- 정확한 PCK에서 8갈래 조합의 직접/복원 16회와 실제 Screen/Store 복원 80회를 확인했다. v0.6 원본 영웅 표시를 연결한 화면과 전체 모델·정확한 난수 seed/state·저장 UI가 일치했다.
- 소스에서도 16회 완료 기록과 복원 종결 상태가 PCK에 일치했다. 소스 비교는 양쪽 화면에 후보 영웅 표시가 연결되어 있어 독립적인 구/신 표시 비교 증거로 쓰지 않는다. 초기 시간 예산에 걸린 마지막 복원 경로는 따로 완료했고 런타임 오류나 불일치는 없었다. 구/신 표시 비교는 정확한 PCK 전체 경로와 별도 제작 검수로 뒷받침한다.
- 저장·일시정지·음향 지속성·종료 음향·DPR 입력·전면 상태·동시/치명 누수·마지막 적 손실 표식·복원 시 재생 방지·모달 순서 회귀를 재실행했다.
- 네이티브 96개 대응 프레임 쌍의 발·총구·높이 앵커 288세트가 동일했다. 비정사각형 합성 텍스처의 축별 UV 곱을 별도로 증명하고 DPR 1/2/3을 확인했다.
- 이미지 204개의 해시를 확인했으며 독립 재실행 캡처 4개가 제작 캡처와 바이트 동일했다. 실제 크기 명목 화면과 최대 전장 DPR3 화면에서 실루엣·방향/종횡비·앵커·가독성의 유의미한 퇴행을 발견하지 못했다. 리샘플링으로 픽셀은 달라지며 v0.6과 전체 픽셀 동일성을 주장하지 않는다.
- 네이티브 장면은 자연 저장 상태에 기반하지만 비교용 방향·공격 포즈를 명시적으로 고정·일시정지했다. llvmpipe 네이티브 렌더링이며 브라우저나 물리 GPU 실행이 아니다.

이전 v0.6의 깊은 저장 손상·복구·실제 종료 재시작·음향·픽셀 계층 검수는 바이트 동일한 모듈·리소스에 한해서만 상속한다. 이번에 그 모든 사례를 다시 실행했다고 집계하지 않는다.

- v0.7 브라우저 WASM·IndexedDB·브라우저 프로세스 저장 내구성은 미검증이다.
- 실제 휴대폰의 터치·safe-area·PWA·APK·GPU·발열·배터리·장시간 성능은 미검증이다.
- 실제 스피커의 주관적 믹스·반복 청취는 이번 검수에 포함하지 않았다.
- 런타임 제목/도움말의 이전 v0.6/v0.4 문구는 텍스처 한정 변경 범위 밖이라 보존했다. 배포·파일 버전의 확인은 위 해시와 현재 전달물로 한다.
- 네이티브 PASS와 배포 성공을 브라우저·휴대폰 합격으로 쓰지 않는다.

## 연구, 제안과 다음 인수

- 기존 자동화 자연 진행 208회는 밸런스 연구 자료이며 사람의 승률이 아니다. 적이 일찍 사라지는 구간과 이후 대기 구간은 후속 비교 대상이다.
- 격리 v0.8 후보로 새 런의 스폰 구간 32초를 검토하며 기존 런의 타이밍을 보존할 계획이다. 이 보고 시점에는 계획 단계이며 현재 배포·구현 완료·검수 완료가 아니다.
- 무작위 중복 보장, 카드 강화 수치 변경 등 게임 방향 변경은 승인·반영된 것으로 취급하지 않는다. [v0.3 확정 규칙](2026-10-03_v03-canonical-decisions.md)을 유지한다.

1. QA: 승인된 실행 접근이 있으면 정확한 v0.7의 브라우저 시작→전투→저장·재접속→이어하기와 휴대폰 터치·표시를 우선 확인한다. 기기·OS·브라우저·버전·재현 결과가 완료 증거다.
2. 개발·디자인: 후속 후보는 v0.7과 격리 비교하고 변경 파일·기준·기존 런 호환·정확한 PCK·증거를 인계한다. 현재 운영 파일과 Site는 인계 없이 동시에 수정하지 않는다.
3. 제목·도움말 버전 문구는 다음 허용 범위에서 표시와 실제 전달 버전을 함께 맞춰 검수한다.

이 보고는 현재 릴리스 상태를 갱신한다. 과거 보고·확정 규칙·팀별 결과는 그대로 보존하며 후보나 측정 관찰을 새 게임 규칙의 승인으로 바꾸지 않는다.
