## 이번 확인과 완료한 일

최신 main 트리에서 시작 안내·기획 지시·협업 규약·현재 결정 및 DV1-01 보고가 직전 확인본과 동일함을 확인했다. 새로 [다른 기획 Work의 기존 40런 분석](2026-10-02_planning_PL-04_existing-run-analysis.md)을 읽었다. 확인 blob은 b5025d4dabb6dc4a50470196bb81367f0a6d7e10이다.

1. 다른 Work의 PL04-A, 개발1의 DV1-P01, 본 Work의 PL-06은 같은 C01/C03 배치 민감도 질문이다. PL04-A가 명시한 기준 [5,2,0]과 대체 [5,4,0]도 PL-06과 일치한다. 새 시험을 세 건으로 늘리지 않고 PL-06의 네 조건에 연결한다. 개발1 수락·실행 완료를 뜻하지 않는다.
2. 기존 40런과 승급1·무카드 DV1-01의 차이는 입력 조건 차이다. 40런은 카드 투자 우선 정책까지 조합마다 다르다는 새 분석이 있다. 이를 갈래 회귀·소이 우월의 근거로 사용하지 않는다.
3. 새 보고의 원본 route_combo→공통 C 대응은 C01~C08 순서에서 0,4,2,6,1,5,3,7이다. 원시 기록을 인수할 때 명시적인 갈래표와 함께 확인한다. DV1-01은 이미 명시적 C표를 사용한다고 보고하므로 옛 비트 순서를 다시 적용하지 않는다.
4. 공용 카드 선택 0/480이라는 보고는 제시 이력이 없는 기록이다. 노출0회·선호도0으로 바꾸지 않는다.

위 수치와 해석은 공개 선행 보고 대조다. 본 Work가 40개 원시 런을 재집계하거나 게임을 실행한 결과가 아니다.

## 자료 인수 시도와 차단

승인된 전달물 검색에서 Nightroad-Square-Defense-v0.3-SOURCE.zip과 Nightroad_DV1-01_Benchmark.zip을 찾았다. 검색한 자료에서는 v0.3.1 소스 및 배치 민감도 후속 전달물을 식별하지 못했다. 이는 해당 자료가 어디에도 없다는 뜻은 아니다.

기존 DV1-01 원시 묶음을 실제로 인수하려 했으나 파일 다운로드가 네트워크 오류로 실패했다. 따라서 압축 내용·원시 결과·반복 동일성의 독립 검증은 하지 못했다. 자료 존재 확인과 내용 검증을 구분한다. 인증 거절 또는 파일 자체의 결함으로 판단할 근거는 없다.
