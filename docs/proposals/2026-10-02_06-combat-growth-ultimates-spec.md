## 1. 결정·제안·미결정과 우선순위

자료 기준: 01~05 문서를 읽고 최신 목록에서 동일 blob SHA임을 확인했다. 이전 원본 디펜스·톱니 공방 문서도 앞선 작업에서 읽었다.
- 02의 기본 3병종과 카드 목록을 유지한다. 빌드는 출발 전 고정 선택 대신 런 중 카드로 형성한다.
- 03의 XP·뽑기 비용을 유지하며 확률·승급·환급을 구체화한다.

- 05의 장갑30%→10% 4초와 보스50% 탈갑을 유지한다.
- 보스 미처치 실패는 사용자 확정 조건이 아닌 05의 시험 제안임을 다시 명시한다.
- 영구 수집, 다른 진영 출시, 광고·결제는 미결정이다. 아래 런 초기화는 시험 기본안이다.

## 2. 좌표·기본 처리
경로 꼭짓점(-2,-2),(2,-2),(2,2),(-2,2), 둘레16, 좌상단에서 시계방향. A/B/C=(-1,-1)/(0,-1)/(1,-1), D/E/F=(-1,0)/(0,0)/(1,0), G/H/I=(-1,1)/(0,1)/(1,1).
거리는 좌표 단위이며 화면 픽셀과 독립적이다. 적 간 충돌·밀어내기·경로 막기는 없다. 영웅은 피해받지 않는다.

- 범위 판정은 적 중심 기준, 거리<=사거리. 폭발·관통도 중심 기준으로 시작하고 시각 효과는 판정 크기를 표현한다.
- 준비 중 유효 표적이 없으면 발사 타이머를0으로 초기화. 사격 가능할 때 공격 간격을 채운 뒤 발사한다. 공백 중 발사 횟수 축적 없음.
- 표적 사망/이탈 시 새 유효 표적이 있으면 일반 발사 타이머는 이어가되 비비 집중은 초기화. 표적이 전혀 없으면 둘 다 초기화.
- 모든 동률은 진행률 내림차순 후 enemyId 오름차순. 피해는 소수 유지하고 UI만 반올림한다.
- 매 전투 tick 순서: 시간·예정 생성 → 이동·진행률>=1 누수/제거 → 상태 만료·궁극기 입력 → 공격/투사체/추가타 → 피해·사망 보상 → 성공/실패 → 레벨업 화면. 같은 tick 경계에 이미 완주한 적은 피해 대상이 아니다.
- 피해 사건은 발생시각·공격자 고정ID·사건 순번 순. HP<=0 즉시 사망 표시하고 뒤 사건은 보상을 재지급하지 않는다. 종료는 모든 해당 tick 처리를 마친 뒤 HP<=0 실패를 성공보다 우선한다.
- 피해 보너스는 같은 항목에서 합산한다. 최종피해=기본피해×(1+승급공격력+공용공격력)×(1+집중+약점추격 등 피해보너스)×(1-적 장갑).
- 발사 시 공격력/집중을 고정하고 피격 시 장갑·파쇄/약점추격 상태를 확인한다. 파쇄타는 기존 장갑으로 피해 후 생존 적에게 약화 적용.
- 공격 속도는 기본간격/(1+공격속도 보너스 합), 최대+100%. 아래 재장전 카드도 이 항목으로 처리한다.
- 웨이브 종료 시 탄환·예약 추가타·집중·파쇄·일시 궁극기 효과·발사 타이머를 정리한다. 카드·승급·고철·XP·궁극기 충전은 유지한다.

## 5. 영입·승급
출전 최대3, 동일 영웅 본체는1. 첫 판은 BBI 시작, CAN/RKT가 미보유.
뽑기 비용은10,15,25,35,45,55,65, 이후+10. 결제수단은 런 고철뿐. 별도 영입 버튼에서1회씩, 애니메이션 중 중복 입력 차단.
- 첫 유료 뽑기: CAN/RKT 각50%.
- 둘째 유료 뽑기: 남은 미보유100%.
- 셋째 이후 BBI/CAN/RKT 각1/3. 승급 단계와 무관하며 확률 조작 없음.
- 아직 배치하지 않은 영입 대기도 보유로 친다. 대기 중 중복은 동일 영웅 재료로 처리한다.
- 1성→2성 재료1, 2성→3성 추가재료2. 승급은 자동. 공격력 계수 1.0/1.1/1.2로 대체, 카드·사거리·궁극기 충전은 자동 지급하지 않는다.
- 전투 중 중복 승급은 즉시 다음 공격부터 적용. 이미 발사된 탄환은 발사 시 배율 유지.
- 3성 중복은 해당 뽑기에 실제 지출한 고철의30%를 내림해 환급. 예:65소모→19환급. 뽑기 누적횟수는 증가하며 비용 단계는 되돌리지 않는다.
- 환급 포함 경제는 05의 “최대6회” 기본 산술과 구분한다.
- 전투 중 새 영웅은 영입 대기. 다음 준비 단계에 빈 칸을 선택해 배치한다. 자동 강제 배치 없음. 준비 화면에 미배치 알림을 유지하되 무시하고 시작할 수 있다.
- 런 시작 고철0·XP0·1성 비비·카드0·궁극기0. 새 런에서 영입/재료/승급/카드는 초기화. 설정만 유지한다.
- 런 재개가 지원되는 구현은 RNG상태·고철·횟수·결과·보장 사용 여부를 한 거래로 저장한다. 저장 전후 재접속으로 재뽑기/중복 지급되지 않게 한다.

6종 확장 전까지 대기석 교체는 필수 화면이 아니다. 이미 구현되어 있으면 재사용하고, 없으면 영입 대기3종을 먼저 완성한다. 확장 시 미출전3명까지 보관하며 보유6종 외 중복 본체는 만들지 않는다.

탄코 궁극기는 C01의 반경 증가분(+0.15/+0.30)을 적용한다. C02 추가 폭발·C03 공속은 적용 안 함. 로코 궁극기 파쇄는 R01로+2/+4초, 감소율은 일반 파쇄와 같은30→10%. 약한/강한 파쇄 중복은 감소율을 더하지 않고 잔여시간과 새 지속시간 중 큰 값으로 갱신한다.
궁극기는 승급/G01 공격력과 피격 시 R02 보너스를 적용한다. 탄코·로코는 궁극기 동안 일반 공격 타이머를 멈추고 종료 시0부터 시작한다. 로코 발동 상태는 발사부터 적중 또는 표적 소실까지, 탄코는 마지막 예정 포탄이 적중/정리될 때까지다.
표적 소실 뒤 충전 환급은 없다. 단, 발동 입력 순간부터 대상이 없었던 경우는 소비하지 않는다. 모든 궁극기는 준비 단계에 지속효과를 넘기지 않으며 사용한 충전은 돌려주지 않는다.
본시험판은 감속·기절·넉백을 넣지 않는다. 이전 확장안의 감속 상한은 현재 적용 효과가 아니다.
