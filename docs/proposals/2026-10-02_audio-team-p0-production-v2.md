5. 현재 게임 이벤트 존재 여부는 미확인. manifest의 이벤트는 제안 매핑이다.

외부 녹음·샘플·음악 파일 없이 수학적 발진기와 필터링된 노이즈를 조합해 이 작업에서 합성했다.

제3자 오디오 샘플 귀속 표시 대상 없음. 특정 서비스 생성 음원이나 타 게임 추출물이 아니다.
이는 배타적 저작권이나 법적 권리 심사를 보증한다는 뜻은 아니다. 별도 라이선스 계약을 임의로 부여하지 않는다.

## 검사 결과와 한계
- 17개 모두 저장 후 재읽기: 48kHz / mono / 24bit PCM 확인.
- 17개 모두 peak -3.000 dBFS(샘플 피크), 포화 샘플 없음. true peak 측정은 미수행.
- 첫·마지막 샘플 0, 비무음 RMS 확인. 짧은 시작/끝 페이드 적용.
- 각 파일 SHA256 및 RMS는 manifest 참조.
- 귀로 듣는 평가, 무기 식별 시험, 실제 휴대폰 출력, 반복 피로도는 미검수.
- 혼합 스트레스/게임에서의 최대 voice 및 최종 출력 클리핑은 미검수. 개별 파일 합격이 믹스 합격을 뜻하지 않는다.

## 개발 인계
1. 파일별 game gain은 manifest 적용. 원본이 모두 같은 peak여도 체감 크기는 다르므로 실청취 후 보정한다.
2. weapon_fired는 실제 발사, projectile_impacted는 실제 충돌 때만 1회.
3. 대포 범위 피해는 착탄 1회. 해당 피해에서 일반 피격음 중복 생략.
4. enemy_killed와 enemy_leaked는 구별. 일반 피격 후 즉시 사망이면 사망만 사용.
5. 장갑 약화 갱신 때 파쇄음 반복 금지.
6. 같은 변주 연속 선택 방지, 기관총 80ms 제한. 제한 중 사건은 소리만 생략하고 나중에 몰아 재생하지 않는다.
7. 카드/정지/앱 숨김에서 전투음 종료, 새 런에서 이전 예약 제거.
8. 이 문서 커밋에는 Markdown만 저장한다. WAV 바이너리는 제공 ZIP에 있으며 GitHub에 업로드했다고 간주하지 않는다.
