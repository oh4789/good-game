## 확정·구현된 변경

1. Android Back과 데스크톱 Escape가 성급 상점·유료 카드·합성의 가장 위 레이어부터 닫힌다. 상세가 열렸으면 상세부터 닫고 다음 입력에서 상위 선택을 닫는다.
2. 유료 카드 선택을 닫아도 이미 결제한 같은 후보·RNG를 보존한다. 다시 결제하거나 다시 뽑지 않는다. 합성 취소는 미확정 재료·유닛을 소비하지 않는다.
3. 버튼을 누른 상태에서 Back을 보낸 뒤 손을 떼어도 확정/구매가 새로 실행되지 않도록 진행 중 포인터 소유를 취소한다. 수동/포커스 일시정지·저장오류 차단을 보존하고 Escape 키 반복으로 정지가 여러 번 전환되지 않게 한다.
4. 성장 카드·기록의 기산점을 '카드 선택 확정 후 팀 처치'로 명확히 한다. 현재 적용 대상이 0명이어도 미래에 영입하는 해당 1성에게 기록이 적용됨을 설명한다. 규칙 변경이 아닌 기존 구현의 문구 정합성 수정이다.

모델·경제·밸런스·명단·4×4·남길 1명+자동 재료 2명 합성·준비 3초·속도 정책은 변경하지 않았다. 새 영웅·3성 전투·영구 경제·새 음향 정책은 구현하지 않았다.
