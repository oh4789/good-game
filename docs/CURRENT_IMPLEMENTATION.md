## 현재 기능과 역사적 기록의 구분

- v0.6은 적 HP·장갑·보스 표식을 전면 표시하고 출입구 가독성을 높였다. 누수 시 실제 공용 HP 손실량을 구별해서 표시하며, 마지막 적 누수 직후 웨이브가 바뀌어도 새 손실 피드백을 유지한다.
- v0.5의 비비·탄코·로코 새 원화, 발사 사건 기반 단일 스프라이트 메시 모션, 전장 안으로 자른 배치 사거리와 전면 승급 배지를 유지한다. 완전한 관절 리그는 아니다.
- v0.4의 같은 런 이어하기·저장 schema·백업 복구·손상 보존·새 런 확인/취소 보호를 유지한다. 기존 런을 강제로 초기화하지 않는다.
- 효과음·BGM, 반응형·터치·동작 줄이기, DPR·포인터 대응을 보존한다. 신규 음향 설정 기본값은 OFF다.
- v0.1·v0.2·v0.3·v0.3.1·v0.4·v0.5의 여섯 런타임 버전과 기존 저장 브리지를 보존했다. 엔진과 저장 경로는 바꾸지 않았다.
- [v0.3 게임 규칙](proposals/2026-10-03_v03-canonical-decisions.md)을 유지하며 밸런스 변경은 없다. 과거의 “이어하기 없음”, “v0.4 미배포”, “v0.5 아트 후보”, “v0.6 후보”는 당시 상태다. 현재 구현 상태는 이 문서와 [v0.6 보고](proposals/2026-10-03_main-v06-release-integration-report.md)를 따른다.
- 텍스처 최적화는 격리 실험이며 현재 v0.6 배포에 포함되지 않았다. 추가 게임플레이 확장 승인으로 취급하지 않는다.

## 검수 경계와 다음 인수

독립 소스와 정확한 PCK에서 각각 1,160,987개 검증 항목을 통과했다. 적 상태·누수 경계, 8개 갈래 조합, 저장 호환, 화면·모델·난수 일치, 각 런타임의 실제 강제 종료·재시작 8개 사례와 확인된 새 런 70개를 확인했다. 네이티브 픽셀도 확인했다. 검증 항목 수는 서로 다른 사용자 플레이 수가 아니다.

v0.5의 60FPS 상한 네이티브 성능 표본은 역사적 증거다. v0.6의 새 성능 보장으로 옮겨 적지 않는다.

**v0.6 브라우저 WASM·IndexedDB·실제 휴대폰·주관적 믹스는 독립 검증되지 않았다.** 네이티브 결과나 이전 버전의 브라우저 기록을 v0.6 웹·휴대폰 통과로 옮겨 적지 않는다. Android APK·실기, PWA·safe-area, 발열·배터리·장시간 성능도 미검증이다. 도움말의 v0.4 표기는 이전 버전에서 이어진 비차단 문구 문제이며 이번 동결 범위에서는 그대로다.

다음 인수 우선순위는 승인된 접근 환경에서 현재 v0.6의 실제 브라우저 저장·재접속과 휴대폰 터치·표시를 확인하는 것이다. 새 검수·후속 개발은 이 문서의 현재 전달물·버전을 기준으로 한다. 과거 버전의 완료 결과를 다시 쓰거나 삭제하지 않고, 실제 재검수한 버전을 구분한다. 운영 파일 변경에는 담당·파일·기준 커밋·격리 브랜치·인수 조건을 먼저 확인하며, 현재 Site 최종 통합과 배포는 두리가 맡는다.
