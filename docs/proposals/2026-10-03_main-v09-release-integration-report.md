## 반영 범위

사용자가 채택한 최대 10배속과 첫 영입부터 중복 가능한 무작위 뽑기를 반영했다. 첫 두 번 미보유 영웅 보장은 폐지하며 원래 문서는 당시 이력으로 남긴다.

- 속도: 1·2·3·5·10배 순환, 허용 정수만 저장·복원
- 영입: 첫 회부터 전체 비비·탄코·로코 각각 1/3, 이미 보유한 영웅도 포함
- 첫 중복 즉시 승급·2갈래 선택, 이후 중복마다 성장 유지
- 가격 12·12·24·이후 +6, XP·고철·승급·카드·명단·기존 32/28초 스폰 규칙 유지
- 저장된 과거 결과·RNG 상태·진행 중 선택창 유지, 미래 영입부터 기존 런에도 새 규칙 적용
- 고정 60Hz 전투 스텝 유지, 250ms 실제 시간 제한을 배속 전에 적용하여 저프레임 10배속이 잘리는 문제 방지
- 일시정지·모달·종료 때 진행 정지, 선택 후 누적 시간 몰아 처리 없음

2배를 넘는 속도로 저장한 런은 v0.9에서 이어한다. 이전 클라이언트의 저장 판독·백업 복구를 현재 진행 보존 수단으로 쓰지 않는다. 저장 형식·경로는 유지했지만 미래 뽑기 결과는 이전 규칙으로 계속할 때와 달라질 수 있다.

같은 시나리오의 소스/PCK 반복을 서로 다른 자연 플레이로 합산하지 않는다. 이전 보장에 의존하던 테스트는 과거 fixture로 보존하고, 새 규칙에서는 정확한 복원 뒤 새 전체 명단 영입으로 검증했다. 테스트 중 합성 상태 오류·짧은 시간 제한은 수정·재실행했으며 최종 결과만 합격 근거로 사용한다. 과거 QA 폴더에 파일이 남았다는 이유만으로 이번 재실행에 포함하지 않는다.

### 정확한 최종 PCK의 네이티브 화면 검수

Godot 4.6.3 네이티브에서 최종 PCK를 열고 실제 포인터로 확인했다. 결정론적 fixture는 시드 1, 고철 12 주입, 비비만 보유한 상태다. 자연 경제 진행이나 실제 휴대폰 플레이가 아니다.

1. 첫 영입부터 각 1/3 확률이라는 문구 표시
2. 첫 영입에서 비비 중복 → 2갈래 선택, 탄코·로코 잠금 유지
3. 연사 선택 후 비비 +1, 다른 영웅 잠금 유지
4. 기존 속도 버튼으로 읽을 수 있는 10배속에 도달
5. 종료·재실행·이어하기 후 10배속·수동 일시정지·비비 +1·적 상태 복원

화면은 도구에서 직접 관찰했으며 별도 스크린샷 파일 전달을 주장하지 않는다.

## 미검증·남은 문제

**브라우저 WASM 실행, IndexedDB 저장·재접속, 실제 휴대폰 터치·성능, 주관적 음향 청취는 미검증이다.** 배포 서비스 성공, 바이트 동일성, 네이티브 실행은 이 검증을 대신하지 않는다. APK·PWA·safe-area·발열·배터리·장시간 성능도 합격으로 표시하지 않는다.

초반 중복과 10배속이 사람의 재미·승률·적 인지 시간을 개선했는지는 아직 모른다. 확정 중복 지급이나 다른 수치 변경은 이번 범위에 포함하지 않았다.
