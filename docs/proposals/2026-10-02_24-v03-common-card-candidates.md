# v0.3 공용 보조 카드 후보
작성일: 2026-10-02 America/Chicago
상태: 신규 채택 검토용 제안. 실제 카드 풀·구현·밸런스 검증 완료가 아님.
기준: 2026-10-03_v03-canonical-decisions.md. 기준 파일 blob 4929e26b4bc7e23b04acd1f0fecf72c933890dba 유지 확인.
사용자 요청: 공용 카드와 지원형 요소 기획.
유지: 자동 전투, 첫 중복의 2갈래 선택, 중복마다 승급, 경험치 카드3택1.
변경 제안: 공용 보조 카드의 후보 효과와 상한. 채택 전 현재 카드 풀에 자동 추가하지 않는다.

## 1. 역할
갈래는 공격 방식을 정하고 공용 카드는 부족한 화력·공격 기회·생존 여유를 보완한다.
공용 카드로 영웅·승급·갈래를 지급하지 않는다.
수동 궁극기 충전, 재화 생성, 중복 보장, 영구 능력치는 이번 후보에 없다.
현재 카드 목록을 먼저 읽고 같은 기능이 있으면 기존 카드에 대응시킨다. 새 이름만 붙여 중복 카드를 늘리지 않는다.
아래 PC ID는 문서용 제안 ID이며 실제 게임 ID가 아니다.

## 2. 1차 비교 후보 3종
| ID | 이름 | 효과 시험값 | 제안 상한 | 선택 이유 |
|---|---|---|---|---|
| PC01 | 공동 정비 | 파티 기본 공격력 +5%p | 4회, 총+20%p | 전반적인 화력 보완 |
| PC02 | 합동 훈련 | 파티 공격속도 +5%p | 3회, 총+15%p | 공격 기회가 충분한 배치에서 유리 |
| PC03 | 방어 보강 | 공용 최대HP와 현재HP 각각 +2 | 3회, 최대HP 총+6 | 누수를 버틸 여유 확보 |

초기 후보는 이3종이다. 효과 수치·상한은 확정이 아니다.
PC01의 제안 산식: 기본 공격력 D × (1 + 0.18×승급 + 0.05×PC01횟수).
이 식은 승급과 이 카드만의 관계를 명확히 하는 후보이며 실제 기존 보조 카드·갈래와의 연산을 대체하지 않는다.
승급2·PC01 2회면 이 부분의 배율1.46. 승급 배율1.36에 1.10을 곱한1.496과 다르므로 개발은 기존 계산 방식과 충돌을 먼저 기록한다.
이미 구현된 공용 공격력 방식이 다르면 임의 변경하지 않고 기존 카드와의 비교안으로 남긴다.

PC02 제안 산식: 기본 공격간격 I / (1 + 기존 공속 가산항 + 0.05×횟수).
기존 최소 공격간격·프레임 제한을 유지한다. 화염 피해 틱 간격은 바꾸지 않고 공격/장판 생성 주기에만 적용하는 후보다.
기존 엔진이 다른 공속 모델이면 실제 수치와 설명을 맞춘 뒤 채택한다.
PC03 획득 전 HP3/20이면 획득 후5/22. HP20/20이면22/22.
확정 패배 이후 대기 카드로 부활하지 않는다. 기존 HP 카드가 있다면 먼저 중복 여부를 확인한다.

## 3. 2차 비교 후보 2종
| ID | 이름 | 효과 시험값 | 상한 | 보류 이유 |
|---|---|---|---|---|
| PC04 | 관측 장비 | 각 영웅 기본 사거리의 5%만큼 추가 | 2회 | 사거리와 배치의 가치가 크게 변할 수 있음 |
| PC05 | 응급 수리 | 공용HP 즉시4 회복, 최대HP 초과 없음 | 런당2회 획득 | PC03과 선택 가치가 겹치며 난이도를 크게 낮출 수 있음 |

PC04는 폭발 반경·장판 반경·관통 폭을 늘리지 않는다. 사거리 증가로 중앙칸이 유효해지는지는 실제 전장 좌표로 확인한다.
PC05는 HP가 최대보다 낮을 때만 후보가 되는 제안이다. 후보를 확정한 후 상태가 바뀌는 예외는 현재 카드 세션 정책에 맞춰 처리한다.
PC03과 PC05를 함께 넣기 전에 동일한 비용의 카드 선택으로 각기 어떤 상황에서 유리한지 비교한다.
현재 보고된 만HP 승리가 지속되는 환경에서는 생존 카드의 낮은 선택률만으로 카드 자체가 실패했다고 판단하지 않는다.

## 4. 공용의 적용 범위
현재 출전 중인 파티 전체에 적용한다. 이후 이번 런에 합류한 영웅에도 같은 보유 효과가 적용되는 후보다.
공용 카드 획득 횟수는 파티에 한 번 저장하며 영웅마다 복제해 중복 합산하지 않는다.
새 런에서 초기화한다.
피해 보너스가 탄환→폭발→장판 경로에서 두 번 적용되지 않도록 실제 피해 생성 구조를 확인한다.
공용 카드가 적용되는 피해 종류는 기존 공격력 규칙과 일치시킨다. 미확인 자동 특수 공격까지 포함한다고 단정하지 않는다.

## 5. 카드 제시 정책
3택1은 유지한다. 구안의 “전용2+공용1” 고정 슬롯은 이 문서로 부활시키지 않는다.
현재 추첨 방식·가중치·상한·최대 선택 횟수를 먼저 인수한다.
공용 후보를 넣은 전체 풀에서 도달 가능한 모든 선택 상태에 유효한 서로 다른3장이 남는지 검토한다.
후보3종만으로 전체 카드 풀을 구성하지 않는다. 상한을 가진3종만 사용하면 획득 후 후보 부족이 생길 수 있다.
3장 확보를 위해 상한 초과·무효 회복·이미 선택한 갈래 카드를 섞지 않는다.
기존 시스템에 후보 부족 대책이 없으면 전체 풀/상한 조정안을 먼저 작성하고 적용한다. 현행 구현을 모른 채 무료 재추첨·고철 대체를 추가하지 않는다.

## 6. 화면 문구 후보
PC01: “모든 영웅의 기본 공격력 +5%p.”
PC02: “모든 영웅의 공격속도 +5%p. 지속 피해의 틱 속도는 바뀌지 않습니다.”
PC03: “공용 최대HP +2, 현재HP +2.”
PC04: “모든 영웅의 기본 사거리 +5%. 폭발 범위는 바뀌지 않습니다.”
PC05: “공용HP 4 회복. 최대HP를 넘지 않습니다.”
첫 줄은 짧게, 누적 적용값·상한·실제 공격간격은 상세 설명으로 표시한다.
파티 공용 아이콘과 영웅 전용 아이콘을 구별한다. 희귀도나 유료 표시를 임의 추가하지 않는다.

## 7. 채택 전 검수
1. 현행 카드 목록과 중복·산식 충돌 확인.
2. 승급0/2/3에서 공격력 카드의 선형 가산 확인.
3. 추가 영입 영웅에도 공용 효과가 한 번 적용되는지 확인.
4. 공격속도와 화염 틱이 의도대로 분리되는지 확인.
5. HP 카드 획득 전후 현재/최대 값과 패배 우선 처리 확인.
6. 사거리 카드가 반경·폭을 잘못 늘리지 않는지 확인.
7. 상한 도달 후보 제외 및 전체 풀3택1 유효성 확인.
8. 새 런 초기화·화면 재표시 중복 적용 방지 확인.

역할: 개발1팀은 실제 목록/산식/추첨 대응, 개발2팀은 공용 범위와 실제 변화 표시, QA는 위 조건 검수, 기획은 선택 이유와 결과 비교.
1차 후보3종이 기존 기능으로 이미 충족되면 신규 구현 없이 이름·설명 정리로 끝낼 수 있다.
현재 무피해 여유 문제를 해결하지 않은 채 전체 카드를 한꺼번에 상향하지 않는다.
지원형 영웅 토리·저격수 핀·별도 화염 영웅 애쉬는 기존 확장 제안으로 보존하며 이번 공용 카드와 동시에 필수 범위로 늘리지 않는다.

## 8. 완료와 미완료
완료: 현행 규칙에 맞는 공용 카드 1차3종/2차2종 후보, 적용 범위, 산식 예시, 화면 문구와 검수.
미완료: 사용자 최종 채택, 실제 코드 확인/적용, 카드 풀 유효성 계산, 실전 선택률·밸런스 검증.
게임 코드 수정·배포·다른 Work 직접 전달 없음.
