### 사용자 확정 사항
단일 진영, 최대 출전 3명, 내부 3×3 배치와 웨이브 사이 재배치, 사각 경로 완주 시 공용 HP 피해·퇴장, 자동 공격·수동 궁극기, 약 7분 런을 유지한다. 처치 자원 영입과 처치 기반 레벨업 카드 3택1은 분리한다. 음향 담당은 게임 코드를 수정하거나 배포하지 않는다.

### 제안
톱니 공방 및 비비·탄코·로코는 시험안이다. 아래 음색·파일 길이·볼륨·제한 수치는 음향팀의 시험 제안이며 사용자 확정 수치가 아니다.

### 충돌 표시
- 앞선 음향팀 소개의 비비·모르·루미 혼합 파티는 최신 단일 진영 방향과 충돌한다. 이번 제작 기준은 기관총·대포·로켓이다. 모르·루미 삭제를 뜻하지 않는다.
- 웨이브 종료마다 강화음을 재생하지 않는다. 실제 레벨업 선택 화면과 카드 적용 사건에만 연결한다.
- 보스 사망만으로 승리 음악을 틀지 않는다. 개발이 최종 확정한 run_finished 결과를 따른다.
- 아트의 장전 동작만으로 장전 쿨다운·추가 발사음을 만들지 않는다.

## 2. 음향 방향 [제안]
귀여운 공방 무기와 서늘한 밤길. 짧은 기계 타격, 황동의 작은 떨림, 나무·금속 잔향으로 캐릭터성을 만든다. 사실적인 전쟁 폭음·비명보다 작고 명료한 게임 음향을 사용한다.
- 기관총: 짧고 건조한 “탁”, 연속 리듬. 고음이 귀를 찌르지 않게 한다.
- 대포: 둥근 발사 충격과 낮고 넓은 착탄. 긴 저음 꼬리는 줄인다.
- 로켓: 압축 공기 같은 “푹-슈”, 착탄은 좁고 단단한 금속 파쇄.
- 피격: 작은 접촉, 사망: 짧은 해체, 누수: 낮은 경고 2음. 서로 같은 파일을 쓰지 않는다.
- 화면 위치 패닝은 중앙 기준 ±0.35 이내. 스마트폰 모노에서도 구별되어야 한다.
- 보이스와 적 이동 루프는 첫 시험판에서 보류한다.

## 4. 연결 이벤트 계약 [제안]
06의 enemy_killed, enemy_leaked, recruit_resolved, hero_deployed, card_selected, ultimate_cast, wave_started, run_finished를 유지한다.
추가 필요 사건: weapon_fired, projectile_impacted, enemy_damaged, armor_state_changed, card_panel_opened, ultimate_ready_changed. 현재 코드에 이미 존재한다고 주장하지 않는다.

필수 필드:
- 공통: event_id, run_id, simulation_time, event_type.
- 전투: source_id, hero_id, projectile_id 또는 attack_id, target_id, weapon_type, 화면 위치.
- 결과: recruit_result(new/duplicate/refund), run_result(win/lose), armor_transition.
- 프레임/애니메이션 콜백과 로직이 동일 사건을 이중 송신하지 않는다.
- event_id 기준 현재 런 중복 방지. 새 런에서 기존 예약·핸들·중복 이력을 정리한다.
- 발사는 투사체 생성/실제 공격 판정 시점, 착탄은 실제 충돌 시점에 연결. 그림의 잔상·사망 프레임에서 사건을 다시 만들지 않는다.
- 관통탄: 발사음 1회, 개별 적의 약한 피격음만 제한적으로 허용.
- 범위 폭발: 착탄음 1회. 폭발음이 있는 피해 사건의 일반 피격음은 생략한다.
- 같은 피해 사건에서 적이 죽으면 일반 피격 대신 사망만 사용한다.
- 약화 지속시간 갱신은 파쇄음을 반복하지 않는다. 무약화→약화 전환 또는 별도 보스 상태 전환만 재생한다.
- 표적 소실로 로켓이 소멸하면 착탄음을 만들지 않는다.
- 영입/카드의 보상 확정 전에 성공음을 재생하지 않는다. 소리는 보상·피해 계산을 호출하지 않는다.

## 5. 반복·동시 재생·볼륨 [모두 시험값]
전체 SFX 최대 16 voice: 일반 12 + 중요 신호 예약 4. BGM은 별도, 전환 중 최대 2트랙.
우선순위: 결과 > 누수 > 궁극기 발동/장갑 전환 > 영입/카드 > 착탄 > 발사 > 피격/사망.
가득 차면 낮은 우선순위의 가장 오래된 소리를 10~20ms로 줄여 종료한다. 결과 도달 시 전투 예약을 취소하고 결과음 1회만 남긴다.

| 그룹 | 동시 상한 | 최소 재생 간격 | 기준 gain |
|---|---:|---:|---:|
| 기관총 발사 | 영웅별 2, 전체 3 | 영웅별 80ms | -12dB |
| 대포/로켓 발사 | 각 종류 2 | 같은 영웅 120ms | -9dB |
| 폭발/로켓 착탄 | 합계 3 | 같은 종류 100ms | -8dB |
| 일반 피격 | 전체 2 | 전체 100ms | -18dB |
| 일반 사망 | 전체 2 | 전체 100ms | -16dB |
| 누수 | 1 | 전체 250ms | -6dB |
| 장갑 파쇄 | 1 | 전체 250ms | -8dB |
| UI/궁극기 시작 | 합계 3 | 같은 ID 120ms | -8dB |
| BGM | 정상 1 | 해당 없음 | -18dB |

gain은 원본을 맞춘 뒤 적용할 초기 상대값이며 최종 체감 음량 보장이 아니다.
- 최소 간격 동안의 추가 사건은 소리만 생략하며 피해·보상은 전부 유지한다. 생략한 소리는 나중에 몰아서 틀지 않는다.
- 변주는 직전과 다른 파일 우선, 기관총만 피치 ±3%/gain ±1dB를 시작안으로 한다. 경고·결과음 피치 변조 금지.
- 빠른 연사는 발사음을 제한하되 실제 공격 속도·발사 횟수를 변경하지 않는다.
- 대포 지연 소폭발은 동일 착탄 파일을 -4dB 추가 감쇠해 재사용. 상한을 공유한다.
- 누수 여러 건이 250ms에 몰리면 경고 1회로 묶되 화면의 누수/HP 변화는 모두 표시한다.
- 궁극기 준비 3명이 300ms 이내 동시에 되면 준비음 1회, 화면 버튼은 각각 표시한다.
- 궁극기 발동/누수 동안 BGM -4dB 추가 감쇠: attack 30ms, hold 200ms, release 250ms. 겹쳐도 감쇠를 누적하지 않는다.
- 모든 사건음을 합산한 출력에서 클리핑이 없는지 측정한다. 제한기를 기본 음량 설계의 대체로 사용하지 않는다.

## 6. BGM 제작 지침 [제안]
battle: 작은 목재 타악기·낮은 현악 피치카토·황동 장식. 보컬 없음, 긴 리드 멜로디와 잦은 심벌 제외. 공격 리듬이 들릴 공간을 남긴다.
boss: 같은 조성/템포, 낮은 타악과 긴장 화성 추가. 전투 효과음보다 큰 상시 폭발·경보를 넣지 않는다.
루프 시작/끝 박자와 잔향을 연결하고 WAV와 실제 배포 코덱 둘 다 경계를 청취한다.
일반 전투→보스 전환은 boss encounter 사건에 따라 500ms 교차 전환. 웨이브 번호나 벽시계 7분에 하드코딩하지 않는다.
준비 단계는 battle을 추가 -6dB로 낮춰 유지. 결과는 300ms 페이드 후 승패 징글. 타이틀 전용 BGM은 후속 제작한다.

## 7. 정지·음소거·재시작 [제안]
- 카드 선택: 전투 소리 30ms 이내 페이드 종료, 예약 중지, BGM 추가 -6dB. 카드 UI음은 허용. 닫으면 정상 gain 복귀.
- 일시정지: 전투 소리 종료, BGM 위치 보존 정지. 정지 메뉴 UI음만 허용.
- 앱 비활성: 모든 소리 정지. 복귀 시 과거 사건 재생 금지. 실제 게임 일시정지 정책과 개발에서 일치시킨다.
- 재개: 중간의 짧은 발사/폭발음을 이어 틀지 않고 다음 신규 사건부터. BGM만 보존 위치에서 재개.
- 여러 정지 사유가 겹치면 사유 집합이 모두 해제될 때 전투 재생을 허용한다.
- Master/BGM/SFX 개별 음소거. gain 0만 설정하고 새 노드를 무한 생성하지 않는다.
- 음소거 해제 시 지난 발사·준비·레벨업 알림 몰아 재생 금지.
- 재시작: 이전 run_id의 예약·노드·BGM 종료 후 신규 런 1회 시작.
- 웹일 경우 첫 사용자 입력에서 오디오 활성화. 실패해도 게임 진행을 막지 않고 소리 켜기 상태를 표시한다.
- 경고·궁극기 준비·영입·결과는 모두 시각 표시를 동반한다.

## 8. 제작 파일·권리 인계 [제안]
원본 WAV PCM 48kHz/24bit, 짧은 SFX mono, BGM stereo. 실제 배포 코덱은 엔진/대상 기기 확인 후 정한다.
파일명 예: sfx_mg_fire_v01_a.wav. 음성/음악 샘플을 무단 추출하지 않는다.
manifest 필수 열: sound_id, filename, variant, duration_ms, sample_rate, channels, peak_dbfs, loop_start/end, event, priority, gain_db, max_voices, cooldown_ms, source, creator_or_generator, license_or_terms, attribution, creation_date, sha256, QA_status.
현재 모든 파일의 source/license/sha256는 미제작으로 미확정이다. 권리 확인 완료로 표기하지 않는다.
납품 전 실제 생성/녹음/허용 소재 사용 경로와 이용 조건을 파일별 기록한다. 엔진 통합은 개발 담당에게 인계한다.
