## 1. 확인한 관측과 질문

개발1 보고에 따르면 동일한 승급1·무카드·고정 배치에서 C01(연사/폭발/유도)은 HP0 패배, 342처치·3누수이고 C03(연사/소이/유도)은 HP20 승리, 345처치·0누수다. C01 누수는 일반 적2와 보스1이다. C03 보스 처치 시간은 51.7초다.

이것은 강제 초기화한 통제 시험이다. 일반 사용자 승률이나 소이의 보편적 우월성을 뜻하지 않는다. 이미 보고된 결과를 본 Work가 재현한 것으로 표시하지 않는다.

질문: **탄코 위치 하나를 바꿨을 때 두 갈래의 결과 차이가 유지되는가?**

현재 자료로 최적 위치는 알 수 없다. 한 번의 대체 배치는 배치 민감도 탐색이며, 전체 위치의 최적화나 차이 원인의 확정을 목표로 하지 않는다.

## 2. 최소 비교: 갈래 2개 × 배치 2개

배열 순서는 비비·탄코·로코, 칸 번호는 기존 도구의 0기반 ID를 그대로 사용한다.

| 시험 ID | 공통 조합 | 탄코 갈래 | 배치 배열 | 변경 |
|---|---|---|---|---|
| PL06-C01-B | C01 | 폭발 | [5,2,0] | 기존 기준 |
| PL06-C03-B | C03 | 소이 | [5,2,0] | 기존 기준 |
| PL06-C01-T | C01 | 폭발 | [5,4,0] | 탄코만 2→4 |
| PL06-C03-T | C03 | 소이 | [5,4,0] | 탄코만 2→4 |

칸4는 기존 배열에서 사용하지 않은 대체 ID 후보다. 실제 소스의 합법 칸·배치 검사를 통과하는지 실행 담당이 먼저 확인한다. 좌표 매핑·경로 노출을 직접 보지 않았으므로 중앙·고지·최적 위치라고 단정하지 않는다. 칸4가 불법이면 실행하지 말고 합법 대체 칸과 선정 이유를 기록해 시험 정의를 먼저 고정한다. 결과를 보고 유리한 칸으로 바꾸어 같은 시험으로 보고하지 않는다.

기준과 대체를 비교할 때는 같은 갈래 안에서 위치만 다르다. 같은 배치에서 C01과 C03을 비교할 때는 탄코 갈래만 다르다. 비비·로코까지 교환하지 않는다.

DV1-01의 실제 인수 v0.3 ZIP·runtime 해시 기준, Godot 4.6.3.stable.official.7d41c59c4, seed44217, dt1/60초를 유지한다. 소스 기대 커밋은 922f0808783aa31a88395a80c877e71bce7f0edc이나 ZIP만으로 Git 커밋 동일성을 증명한 것은 아니라는 원 보고의 한계를 유지한다.

웨이브 내 생성 일정은 같아도 이전 웨이브 종료 차이로 런 전체 시각은 달라질 수 있다. 이를 입력 불일치로 자동 판정하지 않고 원인과 시간 기준을 구분한다.

## 4. 최소 기록과 판정

기존 JSON·CSV의 필드를 재사용한다. 값이 없는 항목은 미측정으로 남기며 0을 채우지 않는다.

| 기록 | 목적 / 처리 |
|---|---|
| 시험ID·소스/도구 버전·입력 해시·반복 번호 | 비교 가능한 네 조건인지 확인 |
| 결과·최종HP·처치·일반 적 누수·보스 누수 | 승패만으로 숨겨지는 일반 적 차이를 확인 |
| 보스 생성→처치 시간 | 처치한 경우만 수치, 미처치는 null |
| 보스 누수/종료 시점과 당시 잔여HP | 가능하면 실패 경계 확인. 기존 로그에 없으면 미측정 |
| 영웅별 유효 피해 | 기존 damage_total 정의 유지. 기여의 기술통계로만 사용 |
| 전투 시간·웨이브별 종료 시각 | 전체 흐름 변화의 관측 |
| 반복별 출력·상태 연쇄·불일치 | 결정론적 재현 여부 확인 |

잔여HP 등 새 계측은 개발1의 도구 소유 범위에서 필요성을 검토한다. 추가 계측이 없다는 이유만으로 기본 네 조건의 결과 기록을 중단하지 않는다. 발사 기회·소이 노출·틱별 기여는 원 보고에서도 미측정이므로 위치 효과의 기전을 단정하지 않는다.

판정 순서:
1. 입력·합법 배치·원본 보존·반복 재현을 확인한다. 실패하면 성능 해석 전에 도구/조건 문제를 분리한다.
2. C01-B↔C01-T, C03-B↔C03-T에서 배치 변화의 관측 결과를 적는다.
3. B에서의 갈래 차이와 T에서의 갈래 차이를 함께 본다. 승패 차이가 유지/축소/역전됐는지 기술한다.
4. 조건이 충족되더라도 한 시드·두 위치·승급1·무카드 범위로 결론을 제한한다.

| 관측 결과 | 허용되는 해석 | 다음 판단 |
|---|---|---|
| C01이 개선되고 C03과 차이가 축소 | 시험한 위치가 결과 차이에 영향을 줌 | 위치 민감도 확인. 폭발 계수 상향을 바로 제안하지 않음 |
| 둘 다 비슷한 방향으로 개선/악화 | 두 갈래 모두 시험한 위치에 민감할 가능성 | 갈래만의 고유 문제로 단정하지 않음 |
| 갈래 차이가 유지 | 두 위치에서 차이가 유지됨 | 배치 영향이 없다는 일반 결론은 불가 |
| 승패가 역전 | 이 조건에서 갈래 순위가 위치에 의존 | 최강 갈래 선정 대신 조건부 강점으로 기록 |
| 반복 출력 불일치 | 재현 조건 또는 도구 문제 미해결 | 밸런스 결론 보류 |

미처치 보스 시간을 0초·무한대 또는 임의 패널티로 바꾸어 평균내지 않는다. 반복 두 번은 결정론 확인이며 서로 다른 플레이어 표본 두 명으로 세지 않는다.

## 5. 문제점 / 개선 제안 / 다른 팀 요청

문제점: 현재 공개 보고만으로는 칸별 공격 기회와 누수 직전 상태를 확인할 수 없다. 고정 배치에서 생긴 결과를 갈래 자체의 성능으로 일반화할 위험이 있다. 재현 근거는 DV1-01의 고정 조건·문제점·미검증 절이다.

개선 제안 PL06-A: 위 네 조건을 기존 도구로 비교한다. 기대 효과는 갈래 수치를 바꾸기 전에 위치 민감도를 좁혀 보는 것이다. 작업량은 입력 두 조건 추가와 기존 결과 비교 정도이나 실제 도구 변경량은 개발1이 판단한다. 위험은 대체 위치 하나를 최적 위치로 오인하는 것. 기존 v0.3 소스·도구에 의존하며 현재 게임 규칙과 충돌하지 않는다. 상태는 제안이며 코드 작업의 새 배정이나 채택 완료가 아니다.

다른 팀 요청:
- 개발1: 기존 DV1-P01 후보를 진행할 때 칸4의 합법성, 기준 B 재사용 가능성, 네 조건의 결과와 반복 일치를 확인해 인계. 기존 보고의 기획 요청에 대한 답변이며 본 Work가 직접 메시지를 보내지는 않았다.
- 두리: 결과 수령 후 수치 조정 필요 여부 검토. 이번에는 밸런스 변경을 요청하지 않는다.
- QA: 이 통제 결과를 자연 성장 브라우저 승률과 합산하지 않는다.
