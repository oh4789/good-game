- v0.4는 같은 런 이어하기, 검증된 저장 교체·백업 복구, 손상 데이터 보존을 지원한다.
- 정상 새 런의 반복 초기화와 취소 보호를 검수했다.

- 3영웅 아트의 새 후보는 v0.5 통합 검수 중이다. 현재 Site에 반영됐다고 표시하지 않는다.

## 검수 경계와 다음 인수

최종 패키지의 2,521개 검증 항목, 전체 런 16회, 실제 강제 종료·재시작 26회, 새 런 확인 200회·취소 100회와 컴파일 바이트 대조를 기록했다. 서로 다른 검수 축을 더해서 테스트 수를 부풀리지 않는다.

**v0.4 브라우저 WASM·IndexedDB·실제 휴대폰·주관적 믹스는 독립 검증되지 않았다.** 이번 Chromium 실행은 소켓 EPERM으로 차단됐다. v0.3.1의 브라우저 통과 기록은 v0.4 통과를 대신하지 않는다. Android SDK·내보내기 템플릿이 없어 APK와 Android 실기 검수도 미완료다.

새 검수와 후속 개발은 이 문서의 현재 전달물·버전을 기준으로 한다. 과거 버전의 완료 결과를 다시 쓰거나 삭제하지 않고, 실제 재검수한 버전을 구분한다. 운영 파일 변경에는 담당·파일·기준 커밋·격리 브랜치·인수 조건을 먼저 확인하며, 현재 Site 최종 통합과 배포는 두리가 맡는다.
