## 이벤트·중복 방지 계약 [제안]
기본: event_id와 run_id로 중복 방지. 실패·취소된 행동에서 성공음을 내지 않는다. 소리는 보상과 상태를 변경하지 않는다.
- 일반 버튼: 전용 사건음이 있으면 ui_confirm 생략. 사용 불가는 동일 행동 300ms 제한과 사유 문구 동반.
- 배치: 유효 위치 확정 때만 재생. 원위치 드롭/취소는 무음. 두 영웅 교환은 거래 1건으로 1회.
- 새 영입: 차감과 새 영웅 보유 등록이 성공한 뒤 1회. 대기석 영입도 동일. 배치음은 이후 실제 배치 때 별도.
- 중복: 재료 지급에만 ui_recruit_duplicate. 최대 승급 환급은 ui_confirm으로 임시 대체하고 환급 문구 표시. 재료 지급을 거짓 표현하지 않는다.
- 승급: 이번 14개에는 별도 승급 음원이 없다. 실제 별 상승 시 ui_recruit_new를 임시 재사용하는 제안. 해당 거래에서는 중복 재료음을 생략한다. 이것을 신규 영입 확정음과 구별한 최종 디자인이라고 주장하지 않는다. 전용 승급음은 다음 추가 후보.
- 카드: 후보 클릭/설명 열기는 일반 확인음 또는 무음. ui_card_apply는 확정 후 실제 적용 사건에만. 카드 선택이 별 승급음을 내지 않는다.
- 여러 레벨업 큐: ui_level_open은 연속 카드 세션의 최초 진입만. 카드 적용음은 선택마다, 세션 종료 후 새 레벨업 진입 때 다시 허용.
- 영입 결과와 카드 세션 동시: 결과 지급은 즉시 1회. 영입 시각 알림이 보류되면 오디오도 보류하되 카드 세션 종료 시 가장 최근 1개만. 재지급 없음, 결과 진입/런 변경 시 보류 큐 삭제.
- 준비 완료: 충전 수치가 준비 상태로 전환될 때 1회. 이미 완충된 영웅 교체/정지 해제로 재알림 금지. 300ms 내 여러 영웅 준비는 1음, 각 버튼은 모두 표시.
- 궁극기: 사용 승인 때 시작 강조 1회. 버튼 누름과 실제 발동 양쪽에 연결 금지. 충전 부족/무표적은 ui_reject. 실제 발사와 착탄은 P0 파일로 별도 연결하며 시작 강조음을 매 탄환에 반복하지 않는다.
- 탄코 고정 조준/매발 재조준 미결정과 독립적으로 각 실제 착탄 사건만 듣는다. 음향에서 발사 예약·피해·조준 방식을 생성하지 않는다.
- 결과: run_finished의 win/lose 확정 1회. 보스 사망만으로 승리음 금지. 같은 tick에 HP0이면 게임 로직의 패배 우선 결과를 따른다. 결과 화면 재렌더링은 무음.
- 정지/숨김/새 런 시 이전 전투 예약과 보류 알림 정리. 카드 UI음은 카드 화면에서 허용, 앱 비활성은 전체 정지. 복귀 시 누적 이벤트 재생 금지.

## 믹스와 상태
P0 v2의 전체 SFX 12개(일반8/중요4), 대포·로켓 착탄 합계2개 유지.
P1 UI/궁극기 시작음 합계3개 상한, 결과는 단일 전용 슬롯으로 기존 전투/UI 소리를 정리한다.
결과 > 누수 > 궁극기 발동 > 영입/카드/준비 > 일반 버튼. 중요한 신호를 버튼 클릭이 밀어내지 않는다.
manifest 개별 max_voices 외에 위 그룹/전체 제한을 모두 적용한다.
모든 알림에는 시각 표시를 동반. BGM 미제작이며 실제 출력 혼합/ducking 검증은 후속.

## 출처와 검사
외부 녹음/게임 추출/기성 음원 없이 발진기·노이즈를 직접 합성했다. 제작 소스와 고정 시드 포함. 제3자 오디오 샘플 귀속 대상 없음. 배타적 권리 보증이나 별도 라이선스 계약 부여를 의미하지 않는다.
14개 재읽기 검사: PCM 규격, 길이, ID 유일성, 시작/끝 0, 비무음, 샘플 피크 -4dBFS 통과.
4배 업샘플링으로 계산한 최대 피크 추정 -3.981dBFS. 정식 true-peak 인증 측정은 아니며 최종 혼합 피크를 보증하지 않는다.
파일별 RMS/해시는 manifest, 검사 요약은 qa_results.json 참조.
청취 평가, 브라우저/휴대폰 재생, 7분 반복 피로도, 실제 이벤트와 동기화는 미검수. 이번 HTML은 청취용 제공물이며 브라우저 실행 검수 완료로 보고하지 않는다.
