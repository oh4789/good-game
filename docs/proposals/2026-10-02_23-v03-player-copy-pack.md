# v0.3 플레이어 화면 문구 묶음
작성일: 2026-10-02 America/Chicago
상태: 적용 후보 문구 / UI 구현·실기 검수 없음
기준: 2026-10-03_v03-canonical-decisions.md (6412c5252f6e6da78f402f32aa47bdf937082f12).
현재 자동 전투·첫 중복 즉시 승급/2갈래·추가 중복 성장·보조 카드·최고 웨이브 기록을 따른다.
이 문서는 17-first-run의 구규칙 문구를 현행판에 그대로 연결하지 않도록 필요한 문구만 제공한다. 기능 추가나 규칙 변경 승인이 아니다.

## 1. 용어
| 사용 | 의미 | 사용하지 않을 혼동 표현 |
|---|---|---|
| 영입 | 고철로 영웅 획득 | 경험치로 영웅 뽑기 |
| 승급 1, 승급 2 | 중복 획득 누적 단계 | 2성, 승급 재료 1/2, 낮은 MAX |
| 갈래 | 첫 중복 때 선택한 공격 방식 | 카드로 해금하는 핵심/완성 빌드 |
| 강화 카드 | 경험치 보조 강화 | 영입 카드 |
| 최고 웨이브 | 런 밖에 저장되는 기록 | 영웅 영구 성장, 이어하기 |

## 2. 첫 플레이 안내
| ID | 실제 조건 | 표시 문구 |
|---|---|---|
| INTRO-01 | 초기 배치 | 영웅을 배치하고 전투를 시작하세요. 공격은 자동으로 진행됩니다. |
| INTRO-02 | 최초 전투 | 적이 길을 한 바퀴 돌면 공용 HP를 잃습니다. |
| INTRO-03 | 첫 처치 | 경험치로 강화하고, 고철로 동료를 영입합니다. |
| INTRO-04 | 첫 영입 가능 | 고철이 모였습니다. 동료를 영입해 보세요. |
| INTRO-05 | 실제 배치 대기 영웅이 있는 준비 단계 | 새 동료를 배치해 보세요. |
| INTRO-06 | 첫 중복 갈래 선택 | 중복 영웅은 즉시 승급합니다. 이번 원정에서 사용할 갈래를 고르세요. |
| INTRO-07 | 첫 강화 카드 | 보조 강화 3개 중 하나를 고르세요. 갈래는 첫 중복 영입 때 선택합니다. |
| INTRO-08 | 첫 추가 중복 승급 | 같은 영웅을 다시 얻을 때마다 승급이 계속 오릅니다. |

한 번에 하나만 표시하고 실제 조건이 사라진 대기 안내는 버린다.
현재 게임이 자동 배치라면 INTRO-05는 사용하지 않는다. 배치 방식을 문구로 새로 확정하지 않는다.
도움말은 화면 밖 전용 영역을 사용하고 읽기를 강제해 적 생성을 지연하지 않는다.
궁극기 사용 안내·무료 중복 지급·튜토리얼 전용 재화는 추가하지 않는다.

## 3. 영입·승급 피드백
| 조건 | 문구 |
|---|---|
| 영입 버튼 | 영입 · {cost} 고철 |
| 자원 부족 | 고철이 {missing}개 더 필요합니다. |
| 새 영웅 | {hero} 합류 |
| 첫 중복 | {hero} 승급 1 · 갈래를 선택하세요. |
| 추가 중복 | {hero} 승급 {stage} |
| 갈래 선택 제목 | {hero}의 갈래 선택 |
| 선택 안내 | 선택한 갈래는 이번 원정 동안 유지됩니다. |
| 선택 버튼 | {branch} 선택 |
| 승급 정보 | 중복 획득마다 승급합니다. |
| 개수 제한 설명 | 공격 효과 개수에는 제한이 있어도 승급 수치 성장은 이어집니다. |

{missing}=현재 확정 비용-현재 고철이며 부족 상태에서만 표시한다.
승급 수치 변화는 엔진이 확정한 이전→이후 값을 받는다. 피해 계산식을 UI에서 추정하지 않는다.
첫 중복 선택창 재표시로 승급음·차감을 반복하지 않는다.
추가 중복에 갈래 선택을 다시 요구하지 않는다.

## 4. 6갈래 설명
- 비비 연사: 한 표적에 공격을 집중합니다.
- 비비 탄막: 여러 표적을 처리합니다.
- 탄코 폭발: 넓은 범위의 적을 공격합니다.
- 탄코 소이: 불길로 지속 피해를 줍니다.
- 로코 유도: 강한 표적을 노립니다.
- 로코 관통: 일직선의 적을 꿰뚫습니다.

설명은 기준 문서 수준이다. 실제 추적·표적 우선순위와 맞지 않는다면 구현 담당 확인 후 수정한다.
피해 배율·발사체 수·반경·지속시간은 실제 데이터가 있을 때 상세 정보에 넣는다.

## 5. 결과 화면
첫 화면: 성공 여부 / 도달 웨이브 / 최종 HP / 플레이 시간 / 다시 도전.
- 성공 제목: 밤길 방어 성공
- 패배 제목: 원정 종료
- 새 런 버튼: 다시 도전
- 기록 라벨: 최고 웨이브
- 갱신 표시: 최고 기록 갱신!
- 초기화 안내: 새 원정에서는 영웅과 강화가 초기화됩니다.
- 기록 저장 실패가 실제 감지된 경우: 기록을 저장하지 못했습니다.

성공은 게임의 확정 종료 상태를 따른다. 보스 사망 연출만으로 성공 문구를 띄우지 않는다.
기록 갱신은 실제 값이 이전 최고보다 높을 때만 표시한다.
저장 성공·실패를 확인할 수 없으면 성공으로 단정하는 토스트를 띄우지 않는다.
중간 런 이어하기 버튼·영구 영웅 보상은 현재 범위에 없다.

상세 정보가 실제 수집된 경우에만:
- 누수: {enemyType} {count}마리 · HP {damage} 손실
- 영웅: {hero} · 승급 {stage} · {branch}
- 갈래 미선택: 갈래 미선택
- 총 시간은 정지를 분리하고 전투/준비/선택이 중복 합산되지 않도록 한다.
- 없는 지표는 “미측정”. 0으로 채우지 않는다.

다음 판 안내 후보: “다음 원정에서는 배치나 갈래 선택을 바꿔 보세요.”
특정 갈래면 승리했을 것이라는 단정, 궁극기 미사용 지적, 승급 부족 탓은 표시하지 않는다.

## 6. 재개·설정
- 일시정지: 원정 일시정지
- 재개: 계속하기
- 종료 확인: 현재 원정을 종료할까요?
- 종료 설명: 이번 원정의 영웅과 강화는 유지되지 않습니다.
- 취소: 돌아가기
- 앱 복귀: 준비되면 계속하기를 눌러 주세요.
- 음향 재생 차단 안내가 필요한 경우: 소리를 켜려면 화면을 눌러 주세요.

앱 복귀나 오디오 허용 버튼이 갈래/카드 선택을 대신 확정하지 않는다.
수동 정지·복귀 동작은 실제 구현 정책을 확인해 연결한다. 중간 런 저장을 약속하지 않는다.

## 7. 개발2팀 인계
1. 기존 문자열과 이 후보를 대응시켜 중복된 도움말을 제거할 위치를 기록한다.
2. 현재 화면에 존재하는 기능만 적용한다. 이 문구를 넣으려고 새 기록·도감·성장 기능을 만들지 않는다.
3. 변수 값은 확정 게임 상태에서 받는다. 긴 이름·큰 승급 수·큰 비용이 잘리지 않는지 확인한다.
4. 360px 세로 및 실제 지원 가로 화면에서 선택 버튼과 설명 접근성을 확인한다.
5. 적용한 문자열 목록·소스 커밋·화면 증거를 남긴다.

미완료: UI 반영·실제 번역 리소스·사용성 관찰·모바일 검수.
