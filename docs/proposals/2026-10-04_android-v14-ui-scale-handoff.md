## 문제와 수정 범위

사용자가 제공한 작은 중앙 UI 화면과 같은 종횡비를 네이티브1080×2340에서 재현했다. 화면의 물리 픽셀을 배치 단위로 사용하면서 내용은500단위로 제한되고 하단 버튼은 전체 높이를 따라가 큰 빈 공간이 생겼다. 제공 화면이 APK인지 Web인지는 명시적으로 확인되지 않았으며, Android 문제는 별도로 재현했다.

Android에서만 루트 canvas-items/EXPAND와390×390 기준을 적용해 짧은 변을390논리 단위로 만든다. 예를 들어1080×2340은390×845가 되며 기존 반응형 배치와 엔진의 물리→논리 입력 변환을 사용한다. WebViewportScale·모델·RNG·수치·음향·에셋·저장 형식은 바꾸지 않았다. 능력 구매·중복 합성·새 희귀도는 이 수정에 포함하지 않는다.

## 다음 실제 기기 확인

기존 앱 삭제나 저장 초기화를 요구하지 않는다. 제공된 v0.14 업데이트를 기기 보호 절차에 따라 적용할 수 있는지 확인하고, UI가 화면 폭에 맞는지·영입/카드/메뉴 터치가 맞는지·닫고 다시 연 뒤 이어하기가 보존되는지 기록한다. 설치 경고가 있으면 우회하지 말고 문구를 남긴다. 같은 패키지·서명은 실제 업데이트/저장 보존 성공의 증거가 아니다.

실제 휴대폰 업데이트·이어하기·safe-area·시스템 뒤로가기·장시간 성능은 미검증이다. 사용자의 재미있다는 긍정적 반응은 플레이 피드백으로 보존하되 설치 성공·완주·전체 인수 합격으로 확대하지 않는다. [v0.13 휴대폰 체크리스트](2026-10-03_main-v13-test-handoff-report.md)를 현재 Android 버전에 맞춰 재사용한다.
