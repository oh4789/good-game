## 현재 기능과 역사적 기록의 구분

- v0.5에는 비비·탄코·로코의 새 원화와 발사 사건 기반 단일 스프라이트 메시 모션을 적용했다. 완전한 관절 리그는 아니다.
- 배치 사거리 표시를 전장 안으로 잘랐고 승급 배지를 영웅 앞에 표시한다.
- v0.4의 같은 런 이어하기·저장 schema·백업 복구·손상 보존·새 런 확인/취소 보호를 유지한다. 기존 v0.4 런을 강제로 초기화하지 않는다.
- 효과음·BGM, 반응형·터치·동작 줄이기, DPR·포인터 대응을 보존한다. 신규 음향 설정 기본값은 OFF다.
- v0.1·v0.2·v0.3·v0.3.1·v0.4의 다섯 런타임 버전을 보존했다.
- [v0.3 게임 규칙](proposals/2026-10-03_v03-canonical-decisions.md)을 유지하며 밸런스 변경은 없다. 과거의 “이어하기 없음”, “v0.4 미배포”, “v0.5 아트 후보”는 당시 상태다. 현재 구현 상태는 이 문서와 [v0.5 보고](proposals/2026-10-03_main-v05-release-integration-report.md)를 따른다.
- v0.6 적 상태 전면 표시와 구별되는 누수 피드백은 두리 소유의 별도 후보이며 현재 배포 기능이 아니다. 추가 게임플레이 확장은 승인된 것으로 취급하지 않는다.

## 검수 경계와 다음 인수

독립 소스와 정확한 PCK에서 각각 354,273개 검증 항목을 통과했다. 8개 갈래 조합·저장 호환·1,016개 상태/난수 체크포인트와 각 런타임의 실제 프로세스 강제 종료·재시작 8개 사례를 확인했다. 네이티브 픽셀도 확인했다. 이 수치들은 서로 다른 검수 축이며 사용자 플레이 수처럼 합산하지 않는다.

60FPS 상한의 네이티브 표본에서 평균 프레임은 약 16.8~16.9ms를 유지했고 갱신 CPU는 약 0.56ms 증가했다. 실제 휴대폰 성능 보장은 아니다.

**v0.5 브라우저 WASM·IndexedDB·실제 휴대폰·주관적 믹스는 독립 검증되지 않았다.** 네이티브 결과나 v0.3.1의 브라우저 기록을 v0.5의 웹·휴대폰 통과로 옮겨 적지 않는다. Android APK·실기 검수도 미완료다.

새 검수와 후속 개발은 이 문서의 현재 전달물·버전을 기준으로 한다. 과거 버전의 완료 결과를 다시 쓰거나 삭제하지 않고, 실제 재검수한 버전을 구분한다. 운영 파일 변경에는 담당·파일·기준 커밋·격리 브랜치·인수 조건을 먼저 확인하며, 현재 Site 최종 통합과 배포는 두리가 맡는다.
