## 문제점

전달 테스트 EarlyLifecycle은 QA/v10/lifecycle.json에 기록하지만 깨끗한 추출본에 QA/v10 폴더가 없었다. 최초 실행은 FileAccess.open이 null인 기록 단계에서 오류 후 timeout. 재시작도 폴더 생성 전에 진행돼 실패 기록을 보존했다. 검수 사본에 해당 출력 폴더를 먼저 생성한 최종 실행은 종료0·73검사 통과했다. 게임 런타임 결함이 아닌 테스트 전달·재현 준비 문제다.

최소 재현: 새 SOURCE 추출/import → EarlyLifecycle 실행 → 결과 파일 open 실패. 해결: 실행 전 mkdir -p QA/v10. 게임 코드를 수정할 필요 없다. 원문 실패·최종 로그를 모두 저장했다.

v0.9부터 첫 영입도 전체3종 각1/3이며 초기 미보유 보장은 폐지됐다. 이전 QA의 보장 검사를 현재 합격 근거로 재사용하지 않는다. 이번 영입 확률/경제는 재실행하지 않았으며 규칙 확인과 실행 검증을 구분한다.
