## 이번 적용

- 기존 자동 전투·3영웅·첫 중복 즉시 승급과 2갈래·이후 계속 성장·보조 강화 카드·영입 경제를 유지했다.
- 실제 발사 횟수가 늘 때만 영웅 반동을 시작하도록 수정했다. 매 프레임 반동이 재시작되는 표현 오류를 고쳤다.
- 높은 승급에서 시각 표시와 총구 효과 길이를 제한했다. 승급 수치에는 상한을 추가하지 않았다.
- 작은 세로 화면, 가로 화면의 전장·조작 패널과 카드 선택 화면을 조정하고 주요 버튼의 터치 영역을 확대했다.
- 음향팀 `Nightroad_Audio_v03.zip`을 실제 인수하고 사용 음원의 해시를 대조했다. 발사·착탄·처치·누수·영입·승급·갈래 적용·강화·웨이브·승패와 일반/보스 BGM을 연결했다.
- 소리 ON/OFF와 설정 저장, 개별/전체 음성 수 제한, 쿨다운, 준비/선택 감쇠와 일시정지 처리를 적용했다. 전투 난수와 별개로 변형 음원을 순차 선택한다.
- 웹 음원 Stream 재생·리소스 캐시·정지 상태 전환 처리를 적용했다. 초기 음향 빌드에서 발생한 브라우저 종료 문제를 수정하고 완주 검사를 다시 수행했다.
- 기존 v0.1/v0.2 파일은 바이트 동일하게 보존했다.

## 검증 증거

- 네이티브 기존 UI 108개, 신규 표현·음향·반응형 68개 검사 통과.
- 4시드 × 8갈래 조합의 32개 자동 전체 런 JSON이 수정 전과 동일. 모두 승리, 전투 400.2~414.0초.
- 실제 Chromium/Godot WASM에서 소리 ON 상태로 시작 → 영입 → 첫 중복 갈래 → 카드 → 보스 승리 → 새 런 → 새로고침을 통과했다. 전투 404.3167초, 345처치, 12카드, 9영입. 게임의 2배속 버튼을 사용했으며 브라우저 시계 강제 가속은 사용하지 않았다.
- 승리음 1회, 갈래 적용 3회와 기타 사건별 음향 호출을 확인했다. 실제 스피커 청취 합격을 의미하지 않는다.
- 새 런 성장 초기화, IndexedDB 최고 웨이브 10과 음향 설정의 새로고침 후 유지 확인. 페이지/콘솔 오류 없음.
- 320×568, 360×800, 390×844, 844×390 화면과 조작 영역 검사 통과. 실기 휴대폰 검수와 구분한다.
- PCK 파일 크기·해시, WASM 일치, 자산 참조, 기존 버전 바이트 보존 검사 통과.

실행 스크립트와 원시 결과는 비공개 Site 소스의 `game-source/tests/`, `game-source/QA/`, `scripts/browser-v031.cjs`, `qa-v031/`, `WEB_STATIC_QA.json`에 있다. 이전 V03 보고서는 역사적 기록이며 이번 결과와 중복 집계하지 않는다.

## 다음 팀을 위한 연결 지점

음향 AU-02의 파일 인수 차단은 이번 통합 범위에서 해소됐다. `CogAudio.gd`는 발사 횟수, 표현 사건 일련번호, 영입/카드 이력, 상태 전환을 읽는다. 모델을 변경하지 않으며 화면 재렌더로 사건을 반복 재생하지 않는다. 첫 중복은 승급음, 확정 시 갈래 적용음을 사용한다. 별도 갈래 열기음은 겹쳐 재생하지 않는다. 지속 연소 루프·점화와 생존 피격음, 최종 믹싱은 후속이다.

디자인 DS-01은 기존 토끼귀 비비와 새 검은 포니테일 비비의 외형 충돌을 보고했다. 새 원화를 자동 채택하지 않았다. 현행은 `sd-rig.webp`의 영역을 원점 기준 (-20,-43)에 40×48로 그리고, 무기층은 (0,-12)에서 방향 회전한다. 공격 연결은 `CogHeroVisual.play_attack()`, 시간은 `advance(dt)`, 표시 승급은 최대 2단계다. 이것은 현재 임시 표현 계약이며 새 원화의 최종 납품 규격은 아니다.

개발2는 같은 비공개 Site의 소스를 열 수 있는 환경에서 `game-source/project.godot`을 기준으로 UI를 이어갈 수 있다. 공개 저장소만으로 실행 소스를 확보했다고 간주하지 않는다. 다른 Work가 이 기록을 읽었거나 검수에 착수했다고 주장하지 않는다.
