## 결과
14개 고정 조건을 독립 프로세스에서 각각 2회 실행했다. 실행당 3,892개 검사가 통과했고 두 결과 JSON이 일치했다. 이는 14개의 서로 다른 조건이며 사람의 플레이나 승률 측정이 아니다.
검사한 조건에서 피해 판정 시점의 범위 밖 피해는 0건이었다. 경계선은 포함되며 반경보다 0.01 큰 위치에서는 피해가 없었다.

| 조건 | 승급1 적중/피해 | 승급2 적중/피해 |
|---|---:|---:|
| 직선 60단위/초 | 3 / 35.40 | 5 / 95.20 |
| 직선 120단위/초 | 1 / 11.80 | 3 / 57.12 |
| 모서리 60단위/초 | 4 / 47.20 | 4 / 76.16 |
| 정확한 경계, 정지 | 6 / 70.80 | 8 / 152.32 |
| 경계 안쪽 0.01, 정지 | 6 / 70.80 | 8 / 152.32 |
| 경계 바깥 0.01, 정지 | 0 / 0 | 0 / 0 |
| 피해 후 같은 프레임 이탈 | 1 / 11.80 | 1 / 19.04 |

피해 후 같은 프레임 이탈 조건은 피해 직전 반경 안쪽 0.5, 직후 바깥쪽 0.5다. 실제 실행에서 각 승급당 1회 관측됐다. 모델은 피해를 먼저 처리하고 적을 이동하므로 이동 후 좌표만으로 범위 밖 피해라 판정하면 잘못된 결론이 된다. 시각적 체감 문제 여부는 별도 화면 검수가 필요하다.

## 방법과 전달물
기존 DV1-P03의 실제 모델을 이용한 격리 검수 방식을 재사용하고 최신 v0.8에 새 Boundary.gd를 추가했다. 실제 탄코 공격과 포탄 처리로 장판을 생성한다. 이후 공격을 중단하고 HP 100만·장갑 0·고정 위치와 속도의 표적을 설정한다. 모서리 조건의 장판 중심도 시험용으로 지정한다. 자연 전투나 실제 적 속도 분포 측정이 아니다.

생산 코드의 범위 판정 함수를 기대값 계산에 사용하지 않고 직선·모서리 좌표를 시간으로 계산한다. 60Hz의 매 프레임 HP 차이, 30프레임마다의 피해 주기, 만료 후 60프레임 무피해, 총 피해, 생존을 대조한다. 별도 프로세스 반복과 원본 ZIP 파일 바이트 보존도 확인한다.

변경 경로는 격리 사본의 workbench/dev1/DV1-P04/뿐이다. 전달 묶음 Nightroad_DV1-P04_Boundary.zip에는 도구, 두 실행 JSON, 검증 요약, 실행 안내와 이 보고를 담았다. 전체 게임 소스는 기존 v0.8 전달물을 사용한다. 운영 코드 변경·앱 반영·배포는 없다.

실행: v0.8 프로젝트 루트에 도구 경로를 복사한 뒤
`godot --headless --path . --script workbench/dev1/DV1-P04/Boundary.gd -- a`
와 마지막 인자를 b로 바꾼 명령을 실행한다.

## 문제점
새 전투 결함은 재현되지 않았다. 이 결과는 위 조건의 네이티브 모델에 한정된다. 브라우저 WASM, 렌더링과 장판 표시, 실제 휴대폰, 가변 화면 프레임과 저장 복원은 미검증이다. DV1-P03의 패배 시 잔존 장판 문제를 이번 결과로 해결됐다고 처리하지 않는다.
