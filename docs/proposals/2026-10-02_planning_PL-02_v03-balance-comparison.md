## 4. 정상 플레이와 통제 시험
N: 정상 플레이. 실제 영입과 카드 후보를 따른다. 강제 재화·카드·갈래 지급 없음.
C: 통제 시험. 승인된 개발 검수 기능으로 상태를 고정. 일반 사용자 경제/성장 확률을 평가하지 않는다.
M: 조건 불일치. 영입·승급·카드·적 사건이 달라져 순수 갈래 효과로 해석할 수 없는 짝.

N에서 첫 중복이 나오지 않은 영웅은 “미해금”이다. 목표 조합 이름만으로 갈래3개를 모두 얻었다고 세지 않는다.
C가 필요하면 두리에게 위 고정 카드와 개발 검수 입력/로그를 요청한다. 본 기획팀은 코드를 수정하거나 디버그 권한을 우회하지 않는다.
현재 요청 상태: 인수 대기. 직접 메시지 전송/승인 확인 없음.
같은 시드에서도 RNG 호출 차이로 다른 사건이 생기면 M으로 표시하거나 별도 사건 스트림/스크립트를 인수한다.
이 문서가 새로운40런을 무조건 요구하지 않는다. 먼저 한 조건8조합을 비교할 준비를 하고 문제 재현에 필요한 만큼만 확장한다.
