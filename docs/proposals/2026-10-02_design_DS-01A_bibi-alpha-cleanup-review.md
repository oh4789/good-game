# DS-01A 토끼귀 비비 파츠 경계 정리 검토

작성일: 2026-10-02 America/Chicago
담당: 디자인
상태: BLOCKED — 두 편집본 제작·검사 완료, 정리 품질 불합격
상위 작업: DS-01 (게임 미통합)

## 승인 범위와 기준
사용자가 직전 후보 1순위인 기존 토끼귀 비비 파츠 정리를 시작하도록 승인했다. 기존 원본 보존, 경계 편집, 검수와 보고가 범위다. 게임 코드·배포 변경 없음.
main의 WORK_START_HERE, 디자인 지시서, 협업 규약, v0.3 canonical을 다시 읽었다. 문서 blob SHA는 순서대로 7df3525aee6338c21f7e3953ecca0470a6108f79, 40f2d2d9cce5127c12aaaed01342d58d06c195c7, 5918dc32cd96d2c7dec47b0be91447809799b43f, 4929e26b4bc7e23b04acd1f0fecf72c933890dba다.
기준 소스 922f0808783aa31a88395a80c877e71bce7f0edc, 배포 11a9a0a43af37888e6489167e8fb1fc7173fb0f1. 실제 게임 실행 검수는 하지 않았다.
선행 결과: [DS-01 인수](2026-10-02_design_DS-01_bibi-integration-handoff.md), [외형 선택과 표정](2026-10-02_design_DS-01_expression-sheets_v2.md). 사용자 선택에 따라 흰 머리·토끼귀·붉은 의상을 유지한다.

## 검증과 문제점
직접 이미지 열람 및 Python/Pillow 읽기 전용 알파·치수 검사, SHA256 계산을 수행했다. 주요 귀·총구·부츠 형태는 보이나 머리카락·리본 주변 색 테두리가 여전히 보인다. 1차는 저알파 영역이 상단에 닿는다. 중간알파 픽셀 수만으로 품질을 판정하지 않으며 실제 외곽 잔여와 위치 변화를 함께 근거로 불합격 처리했다.
밝은 배경과 어두운 배경에 동일 픽셀을 합성한 비교판은 이번에 제작·검수하지 못했다. 전 파츠 분리·관절 정합·발 기준점·동작 재생 역시 미완료다. 이 결과를 깨끗한 엔진용 파츠나 DS-01 DONE으로 표시하지 않는다.

## 개선 제안
정밀 경계 보정은 원본 레이어/마스크를 확보해 픽셀을 보존하는 방식이 적합하다. 예상 효과는 외형 변형 없이 색 번짐 제거, 작업량은 중간이며 흰 머리의 얇은 끝과 붉은 리본 손실 위험이 있다. 현재 규칙 충돌 없음. 같은 자동 편집을 계속 반복하는 것은 개선 증거가 없어 중단한다.

## 다른 팀 요청
두리: 편집 가능한 비비 레이어 또는 정확한 파츠 마스크, 실제 엔진 입력 규격과 인계 경로를 확인해야 DS-01 최종 인수를 진행할 수 있다. 저장소 요청 기록이며 수령·수락 증거는 아니다.

## 마지막 완료 지점과 다음 후보
원본 보존, 편집 2회, 정적 이미지·알파 검사, 불합격 원인 기록까지 완료. 정밀 경계 정리는 BLOCKED로 남긴다.
1. 기존 비비 대기·공격 디자인 데모 보완: 기존 atlas를 재사용해 프레임 수에 묶인 재생 시간을 수정한 별도 검토 소스와 MP4를 준비. 동일 시간 진행·발 위치·반복 경계 확인이 완료 조건. Godot 실행 환경 확보가 의존성이며 실패 시 실행 검증을 완료로 표시하지 않는다. 운영 게임 코드 수정은 범위 밖이다.
2. 3영웅 표정 초상화 정리: 기존 18표정을 바탕으로 투명 초상화와 축소 비교. 잘림·정렬·감정 구별 확인이 완료 조건. 최종 UI 규격은 미확정이며 디자인 검토 크기로 구분한다.
