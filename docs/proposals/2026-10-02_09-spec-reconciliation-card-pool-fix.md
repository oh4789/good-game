## 3. 핵심 문제 — 정상 최대 9회에서도 카드 3장 부족 가능

### 기존 주장
전투06은 비비 전용 카드 총5회와 공용 총11회가 있으므로 정상 최대9회 선택에 여유가 있다고 설명한다.
그러나 남은 총 강화 횟수와 서로 다른 유효 카드 ID 수는 다르다.

### 가능한 반례
영입을 하지 않거나 새 영웅을 배치하지 않아 비비만 출전한 상태:
1. B03 관통 탄환 1회.
2. 예비 카드 G03 충전 축전기를 3회 선택.
3. B02 집중 조준 2회.
4. B01 연사 장치 2회.

총8회 선택 후 B01/B02/B03/G03이 모두 상한에 도달한다.
아홉 번째 카드 선택에는 G01 정밀 공구, G02 비상 수리만 남아 2택1이 된다.
전용 카드가 2개로 줄어든 시점부터 공용 후보가 보충되므로 이 순서는 현재 추첨 규칙상 가능하다.
이는 해당 상태에 실제 플레이로 반드시 도달한다는 뜻이 아니라, 사양이 그 상태를 허용하며 3택1을 보장하지 못한다는 뜻이다.

### 수정 제안 CARD-FIX-01
G03의 최대 획득 횟수만 3→4로 변경한다.
- 회당 충전 속도 +10% 유지.
- 최대 충전 속도 +30%→+40%.
- 기본 초당4에서 최대 초당5.6.
- 활성 충전 시간 기준 100/5.6 ≈17.86초. 기존 최대는100/5.2 ≈19.23초.
- 실제 궁극기 간격에는 발동 중 충전 정지·적 없음·카드/준비 정지가 추가되므로 17.86초마다 반드시 사용 가능하다는 뜻은 아니다.
- UI 상한, 저장 스키마의 카드 단계 검증, 테스트 데이터를 함께 맞춘다.
- 신규 카드나 4번째 선택지를 추가하지 않는다.

### 확인한 범위
도구에서 카드 획득 상태를 순서대로 탐색했다.
가정: 비비만 출전, 정상 최대9회, 전용 우선 및 부족분 공용 보충, 각 유효 후보는 등장할 가능성이 있음.
기존 상한 [2,2,1,4,4,3]에서는 9번째 제시 시 유효 ID가2개인 상태 1종을 확인했다.
수정 상한 [2,2,1,4,4,4]에서는 첫9회에 유효 ID가3개 미만인 상태가 없었다.
이는 가능한 상태의 탐색이며 카드 등장 확률·승률·실제 UI 구현 테스트가 아니다.
비비 전용3종과 공용3종 중4종을 소진하려면 수정 후 최소1+2+2+4=9회 획득이 필요하므로 9번째 선택 직전(8회 획득)까지3종 이상이 남는다.
확장 모드·다른 출전 조합·카드 제거 효과에는 이 보장을 그대로 적용하지 않는다.

### 추가 주의
전투06의 '후보0개면 레벨업 소비' 방어 처리는 비정상/확장 상황의 복구안으로 남긴다.
정상 시험판에서 3장 미만을 발견하면 이를 정상 UI로 숨기지 말고 QA 실패로 기록한다.
G03 증가가 궁극기 밸런스에 미치는 영향은 실측 미완료다.

## 5. 전투 판정 빈칸 보완 [시험 제안]

### RULE-01 비비 집중 기준
전투06은 '공격 공백0.4초 초과 시 초기화'와 관통 탄환의 관계가 명확하지 않다.
집중은 주 표적의 기본 사격 명중만으로 유지한다. 관통 보조 명중은 집중 대상을 바꾸거나 타이머를 연장하지 않는다.
카드·수동정지·앱숨김은 공백 시간에서 제외한다.
집중이 붙은 발사 피해를 관통에 상속하는 기존 규칙은 유지한다.

### RULE-02 장갑0 보스와 약점 추격
전투06은 보스 탈갑 이후 장갑0에 파쇄 아이콘을 표시하지 않는다고 하지만 R02의 '유효 파쇄'가 남는지는 모호하다.
보스 탈갑 순간 기존 파쇄 상태를 제거하고 R02 보너스도 종료하는 안을 제안한다.
기본 장갑0인 적에게는 일반/궁극기 로켓 피해만 적용하고 파쇄 상태를 생성하지 않는다.
임계값을 넘긴 해당 타격은 적중 직전 장갑·파쇄 상태로 피해를 계산하고, 그 피해 처리 직후 생존 보스의 탈갑을 수행한다.
같은 시각의 후속 피해 사건은 탈갑된 장갑0·R02 없음 상태로 계산한다.
이 안은 로코의 후반 보스 지원을 줄이므로 직접 피해와 궁극기 기여를 QA가 따로 기록해야 한다. 기존 문서의 확정 사실로 취급하지 않는다.

### RULE-03 지연 소폭발 반경
전투06의 '현재 반경'은 카드가 비행 중/폭발 대기 중 선택됐을 때 어느 시점인지 불명확하다.
기본 포탄 발사 시 피해 배율과 폭발 반경을 함께 고정하고, C02 예약 소폭발은 같은 반경과 발사 시 피해 배율을 상속하는 안을 제안한다.
피격 순간 장갑·R02만 다시 평가한다. 비행 중 선택한 C01은 다음에 발사하는 포탄부터 반영한다.
추가 폭발은 다시 추가 폭발을 생성하지 않는다. 궁극기는 C02를 생성하지 않는다.

### RULE-04 영입 입력과 프레임 내 상태 전환
유효 영입 입력이 자원 차감·결과 지급까지 완료된 뒤 카드 또는 결과 화면으로 전환되면 영입 결과는 유지하고 알림만 보류/종료한다.
상태 전환 후 도착한 입력은 새 상태의 허용 입력 규칙으로 처리한다.
한 번의 클릭을 영입과 카드 선택 또는 결과 재시작에 동시에 쓰지 않는다. 구현 사건 순서를 로그로 남긴다.

## 7. 다른 Work에 전달할 변경 요약

### 개발
전투06 수치를 기준으로 위 CARD-FIX-01과 INT/RULE 제안의 채택 여부를 기록한다.
카드 상한 수정, 탄코 포격 지점, 보스 탈갑 시 R02, 발사 시 반경 고정, 최초 출전/재출전을 특히 명시한다.
기존 문서의 상충 문구를 동시에 구현하지 않는다.

### 디자인·애니메이션
영웅 원본256와 파생128을 구별하고 정규화 원점·포구·여백을 제출한다.
탄코 궁극기의 세 착탄 예고는 각 발사 시 선택한 서로 다른 지점일 수 있다.
파쇄가 제거되면 아이콘과 협공 표시도 함께 제거한다. XP·고철은 중복 표시하지 않는다.

### 음향
궁극기 입력음과 실제 발사음을 구별한다. 탄코의 표적 부재로 생략된 발에는 포격 소리를 발생시키지 않는다.
누수와 처치의 사건명이 다르다는 이유로 보상이 중복 실행되지 않게 개발 이벤트표만 구독한다.

### QA
PQA-01~09를 전달08의 F01~26에 추가한다.
카드 상태 탐색 통과는 실제 게임 통과가 아니다. 채택한 specVersion과 빌드 커밋을 함께 기록한다.
