## 4. 실제 소재와 신규 제작

- UI9개(확인/거절/배치/신규영입/카드열기/카드적용/웨이브/승리/패배).
- 승급1개.

- 신규 갈래 열기1 + 갈래 적용1: 직접 발진기 합성, 외부 샘플 없음.

신규 ui_branch_open:0.42초, ui_branch_apply:0.48초.

BGM은 일반 -18dB/보스 -20dB 총 gain. 이전의 보스 추가 -2dB를 중복 적용하지 않는다.

## 5. 개발 이벤트 계약 [제안]
event_map.json은 의미 대응표이며 실제 구현 API를 읽고 검증한 이름이 아니다.
runId/eventId 기준 중복 방지, 현재 코드 이름과 adapter로 연결할 것. 상태값·피해·보상 계산을 음향층에서 재실행하지 않는다.

### 영입·승급·갈래
- 신규 영웅 지급 확정: ui_recruit_new 1회.
- 모든 중복 승급 확정: ui_promote 1회. 재료음·환급음·일반 버튼 확인음 동시 재생 없음.
- 첫 중복의 갈래 화면이 즉시 열려도 승급음과 열기음을 겹쳐 크게 만들지 않는다. 권장: 첫 중복 거래에서는 ui_promote를 우선, 해당 갈래 열기음은 생략. ui_branch_open은 별도 화면 진입이 필요한 경우에만.
- 갈래 확정 성공: ui_branch_apply. 후보 설명 탭은 일반 확인음 또는 무음.
- 이후 중복에서 갈래 선택음을 반복하지 않는다.
- 승급 단계가 커져도 gain/재생 횟수를 단계만큼 증가시키지 않는다.
- 갈래/카드 화면의 정지 여부는 실제 게임 상태를 따르고 음향이 임의로 정지를 추가하지 않는다.
- 카드와 갈래 선택 대기 우선순위는 현재 구현을 확인해 연결. 음향 문서에서 추첨/선택 순서를 새로 결정하지 않는다.

### 기본공격·2갈래
- 비비 연사/탄막: 같은 기본 발사음 변주. 탄막의 표적 수만큼 발사음을 중복하지 않는다. 실제 발사 사건 단위, 최소80ms.
- 탄코 폭발: 발사와 실제 착탄 분리, 범위 내 적 수와 무관하게 폭발1회.
- 탄코 소이: 실제 장판 생성 때 점화1회. 같은 사건에 폭발+점화가 모두 맞는지는 실제 피해/연출을 확인해 선택. 디폴트로 무조건 둘 다 재생하지 않는다.
- 소이루프: 전체 활성장판0→양수면1개, 장판 중첩·교체로 재시작 금지. 마지막 소멸/웨이브종료 시80ms 종료, 시작100ms. 피해 틱마다 점화·피격음을 만들지 않는다.
- 로코 유도: 발사1회, 실제 충돌1회. 표적 소실·탄 소멸에 착탄음을 꾸며내지 않는다.
- 로코 관통: 발사1회, 같은 투사체의 강한 착탄음은 최초 유효 충돌1회만. 후속 적 접촉은 제한된 약한 피격으로 처리하는 안. 사망 시 일반피격 생략.
- 적 처치/누수는 배타. 누수에 처치음을 쓰지 않는다.
- 소리 제한은 실제 피해·투사체·보상을 생략하는 뜻이 아니다.

### 상태와 결과
19문서의 후보: 준비/카드 BGM-6dB, 수동정지/앱숨김은 위치 보존 정지, 결과300ms fade-out.
실제 v0.3 상태명을 확인한 뒤 채택 기록. 갈래화면이 정지라면 카드와 같은 감쇠를 권장.
중첩 사유 집합이 남으면 전투 SFX 재개 금지. 음소거해제가 게임/음악을 무조건 재개시키지 않는다.
run_finished 승리/패배만 P1 결과음. abandoned는 승패음 없이 정리. 보스사망만으로 승리음 금지.
새 런에서 오래된runId 콜백·예약·루프·보류알림 제거. 최고웨이브 기록 로드에 이전 결과음 재생 금지.

## 6. 오프라인 혼합 검사
제공: mix_fixture_60s.mp3, mix_events.json, qa_results.json.
실제 게임 녹음이 아닌 지정 시간에 음원을 배치한 검토용 시나리오다.
2~10초 기본전투,10.4초 영입,12초 승급,12.8초 별도 갈래열기 비교,14초 갈래적용,
26.5초 카드열기/28초 적용,36초 보스음악 전환,38~53초 연소,56.5초 승리.
12.8초 열기음은 구별 청취용으로 포함했으며 실제 첫중복에서 승급음과 함께 반드시 재생하라는 뜻이 아니다.
보스음악 전환은 이번 fixture에서 두 트랙을 짧게 fade 종료/시작한 순차 전환이다. 500ms equal-power 교차전환 runtime 검증이 아니다.

측정:
- 60초,487개 배치 사건.
- 샘플 피크 **-6.068dBFS**.
- SFX 최대 동시6개, BGM은 별도.
- limiter/사후 정규화 없음.
- 소재32개 해시 및 매핑 대상24ID 확인.
이 결과는 전체12voice 포화·최악 타이밍·실제 스케줄러·7분 반복·사람의 경고 식별을 검증하지 않는다. 무조건 클리핑이 없다고 일반화하지 않는다.
