## 1. 화면 흐름과 상태
첫 판은 시작 화면→초기 배치→전투→웨이브 사이 준비→최종 결과. 레벨업 선택은 전투/준비 위에 열리는 정지 화면이다. 별도 영입은 버튼·작은 결과 알림이며 대형 전면 화면으로 전투를 가리지 않는다.

| 상태 | 전투 시간 | 허용 입력 | 나가는 조건 |
|---|---|---|---|
| 시작 | 정지 | 새 런, 설정, 지원 시 이어하기 | 새 런/재개 |
| 초기/웨이브 준비 | 정지 | 배치·교환·영입·영웅 설명·시작 | 미처리 카드가 없으면 시작 |
| 전투 | 진행 | 영입·궁극기·일시정지 | 웨이브 종료·레벨업·실패·앱 숨김 |
| 레벨업 카드 | 정지 | 카드 설명·선택, 시스템 정지 | 대기 레벨업 전부 처리 후 원래 상태 |
| 수동/앱 정지 | 정지 | 설정·재개·런 종료 | 재개 또는 종료 확인 |
| 결과 | 정지 | 기록 보기·다시 도전·시작 화면 | 명시적 새 런 |

오버레이는 하나만 입력을 받는다. 카드가 열린 동안 궁극기·영입·배치 입력을 다음 화면으로 넘기지 않고 무시한다. 카드 선택으로 배경 궁극기가 눌리지 않도록 입력을 소비한다.
동일 tick 우선순위: 누수와 피해/보상 정산→패배→최종 성공→레벨업 큐→웨이브 준비. 웨이브 완료와 레벨업 동시이면 카드를 다 고른 뒤 준비. 일반 전투 레벨업이면 원래 전투로 복귀한다.
XP가 여러 임계치를 넘으면 한 번에 한 선택만 표시하고 순서대로 처리한다. 다음 후보는 앞선 카드 적용 후 다시 생성한다. 이미 표시한 후보는 정지·재개로 다시 뽑지 않는다.

영입 거래는 입력 수락 시 자원확인→차감→RNG결과→보유/재료/환급→횟수증가를 단일 처리한다. 시각 알림만 약0.8초 표시한다. 레벨업이 열리면 완료된 영입 알림은 카드 뒤로 보류하되 지급을 다시 실행하지 않는다.
앱 숨김은 즉시 정지. 복귀하면 재개 버튼을 보여주며 경과시간을 따라잡아 전투를 진행하지 않는다. 숨긴 시점에 카드가 열려 있으면 같은 카드로 돌아간다.

## 2. 모바일 세로 화면 구조
기준 설계 크기390×844, 추가 확인360×800, 가로844×390. 특정 기종에 종속시키지 않는다.
| 영역 | 표시 | 조작 |
|---|---|---|
| 상단 | W/10, 공용HP/최대, 전투 경과시간, 정지 | 정지 버튼 |
| 전장 | 사각 경로·9칸·적·영웅, 보스 HP | 준비 중 칸 선택, 전투 중 정보 조회 |
| 전장 아래 | 파티XP/다음 요구량, 고철, 영입 비용/버튼 | 별도 영입 |
| 하단 | 영웅3칸·별·카드 단계 요약·궁극기 충전 | 각 궁극기·길게 눌러 정보 |
| 준비 전용 영역 | 다음 적 아이콘2종·짧은 예고·영입 대기·시작 | 영입 배치/교환/전투 시작 |

상하 안전영역을 반영한다. 버튼 최소44×44 논리픽셀, 본문14 이상을 시작값으로 쓴다. 궁극기와 영입 버튼 사이 간격 최소8. 색상만으로 충전·장갑·위험을 구분하지 않는다.
전장은 가능한 너비를 사용하되 경로와 무기가 화면 바깥으로 나가지 않는다. 전투 중 패널 확장으로 경로를 덮으면 게임을 정지시키거나 설명을 전장 밖에 표시한다. 첫 시험은 정보 패널을 정지 화면에서 제공한다.
가로에서는 전장 왼쪽·상태/조작 오른쪽으로 재배치. 화면 높이가 낮으면 정보 설명만 스크롤하고 전투 조작 버튼을 화면 밖으로 밀지 않는다.

## 3. 배치와 영입
- 초기 비비A 추천. 탭으로 영웅 선택→빈칸 탭으로 이동, 점유칸 탭이면 교환. 드래그는 같은 결과를 주는 보조 입력이다.
- 드래그 중 범위와 착지칸 미리보기, 유효칸에서 놓을 때만 확정. 밖에 놓으면 원위치.
- 영입 대기 초상화를 선택한 뒤 빈칸을 누르면 출전한다. 출전 시 충전0, 보유 카드·승급은 보존.
- 기존 영웅 재배치는 충전·강화 유지. 전투 중 위치 변경 없음.
- 중앙E는 사거리가 경로에 닿지 않으면 “현재 위치에서는 적을 공격할 수 없어요” 표시. 막지는 않지만 시작 전 한 번 안내한다.
- 신규 영입이 남아 있으면 “배치 대기 1명”. 안내는 보여주되 강제 자동배치 없음.
- 추천 배치는 참고 표시만 하고 강제 경로 가이드나 정답 보상은 넣지 않는다.
- 확장 대기석 교체는 준비 중만. 출전 해제/교체로 카드·승급·재료·충전은 유지하되 적 상태·일시효과는 준비 시작에 이미 정리되어 있다.

## 4. 카드와 영웅 정보
세로 화면 카드3개는 위아래 목록, 각 카드에 영웅 얼굴·이름·효과·현재→다음 값·상한을 표시한다. 첫 탭은 설명 선택, 별도 “이 카드 선택” 버튼으로 확정해 오터치를 줄인다. 선택 화면에서는 전투·궁극기 충전 모두 정지.
예: “연사 장치 1/2→2/2 / 공격속도 +15%→+30%”. 카드 획득 전후 실제 공격간격도 정보 패널에서 확인 가능.
승급 별과 카드 강화 횟수는 다른 아이콘·라벨을 쓴다. “2성=카드2단계”로 오해하지 않게 한다.
영웅 정보는 역할, 우선 표적, 사거리, 현재 간격/피해, 승급 재료(예:1/2), 보유 카드, 궁극기 설명을 표시한다.

## 5. 예고와 결과
초반 도움말은 한 번에 하나:
W1 처치로 XP와 고철 획득→첫 뽑기 가능 시 영입 버튼 강조→W2 준비 때 영입 대기 안내→첫 궁극기100일 때 버튼 테두리 강조.
강조는 전투를 강제 중단하지 않는다. 튜토리얼을 읽어야 생성이 진행되는 별도 규칙은 첫 판에 넣지 않는다.
W4 “장갑 적 등장 — 파쇄 뒤 집중 공격”, W5 “빠른 적 등장 — 후반 사거리를 확인”. 다음 파형의 전부를 복잡한 숫자로 나열하지 않는다.

결과 화면:
- 성공/실패, 도달W, 최종HP, 보스 처치 여부.
- 실제 플레이 시간(전투+준비+카드), 별도 일시정지 시간.
- 영웅별 실제 피해와 처치, 승급·선택 카드.
- 고철 획득/지출/환급, 뽑기 횟수, 누수 적 유형.
- 실패 설명은 관측 사실을 사용: “질주자 6마리를 놓쳐 HP6 손실”. 기록 없이 “배치를 잘못했어요”라고 단정하지 않는다.
- 파쇄 기여를 직접피해에 다시 더하지 않는다. 구현 시 추정 추가피해는 별도 항목으로 표시.
- 같은 조건 재도전(시드 재사용)은 개발 검수 옵션. 일반 다시 도전은 새 시드·새 런이다.

## 6. 아트 제작 규격 [제안]
첫 시험판은 일관된 상단에서 약간 내려다보는 치비2D 스타일. 큰 머리·짧은 몸·큰 무기로 역할 구별. 기존 자산을 확인하지 않았으므로 아래는 새 제작 기준이며 기존 파일이 이 규격이라고 주장하지 않는다.

영웅 몸체 기본 화면 크기 약48×56, 무기 포함 전체 동작 폭 최대80을 시작값으로 한다. 128×128 투명프레임, pivot(64,96), 좌우·상하 최소8픽셀 여백. 여백을 넘으면 효과를 별도 레이어로 분리하거나 캔버스를 키운다. 프레임마다 자동 잘라내기를 하면 pivot 이동을 유발하므로 고정 캔버스를 유지한다.
몸·무기·총구불꽃·투사체/폭발을 분리. 공격 방향은8방향 회전 무기 또는 방향별 그림으로 표현하되 손잡이가 몸에서 떠 보이지 않는지 확인한다. 수평 반전만으로 총구·탄띠 위치가 바뀌어도 허용할지 아트 검토에 기록한다.
| 자산 | 필수 동작 | 최소 시작 프레임 | 완료 기준 |
|---|---|---:|---|
| 비비 | 대기·사격·장전/점검 | 4/3/4 | 총구 방향·짧은 몸 반동·탄띠 구분 |
| 탄코 | 대기·발사·복귀 | 4/4/4 | 느린 강한 반동과 폭발 구분 |
| 로코 | 대기·발사·장전 | 4/4/5 | 어깨 로켓과 장전 동작 읽힘 |
| 일반 적4종 | 이동·피격·사망 | 4/1/4 | 그림자·자세로 유형 구분 |
| 보스 | 이동·탈갑·사망 | 6/4/6 | 장갑 전후 실루엣 명확 |
| 효과 | 탄흔·폭발·파쇄·승급 | 별도 레이어 | 프레임 경계 잘림 없음 |

프레임수는 예산안이다. 연속 재생과 입력 피드백을 확인해 줄이거나 늘린다. 시각 장전이 논리 공격주기를 늘리지 않으며 애니메이션 종료 이벤트에 피해 처리를 의존시키지 않는다.
사망 판정 직후 타겟/보상에서 제거하고 잔상은0.25초 이내 재생. 피격 흰색 강조 약0.06초, 전체 화면 플래시는 쓰지 않는다. 화면 흔들기는 큰 포격에만 작게, 설정에서 끌 수 있게 한다.
프레임별 바운딩박스와 pivot, A~I 모든 칸,8공격방향을 검수한다. 이미지 생성 결과를 그대로 스프라이트로 간주하지 않고 투명도·경계·동작 일관성을 별도 검수한다.

## 7. 음향 제작 명세 [제안]
| 사건 | 성격 | 반복 제어 |
|---|---|---|
| 비비 발사 | 짧고 가벼운 기계음 | 최소재생간격0.08초, 모든 탄환 소리를 강제 재생하지 않음 |
| 탄코 발사/착탄 | 낮은 발사음/짧은 넓은 폭발 | 같은 순간 폭발 합쳐 최대2겹 |
| 로코 발사/파쇄 | 공기 분출/금속 갈라짐 | 날아가는 반복음은 짧고 작게 |
| 누수 | 짧은 경고 | 0.25초 내 여러 누수는1회+피해합 표시 |
| 카드·영입·승급 | 선택/등장/상승을 구분 | 카드 화면 뒤 보류 알림 연속 소음 방지 |
| 궁극기·보스 | 짧고 명확한 강조 | 일반 사격보다 우선 |

BGM은 탐색형 기본 루프1개+보스 변형1개로 시작. 보스 전환은 짧은 페이드, 카드/정지는 BGM 음량을 낮추고 사격음 중단. SFX 동시음 초기상한12, 우선순위는 누수·궁극기·UI→보스→일반공격. 마스터/BGM/SFX 개별 음량·음소거 저장.
오디오 재생 허용 전에는 첫 사용자 입력 뒤 시작하고 자동재생 실패가 게임 진행을 막지 않는다. 실제 음원 제작·라이선스 확인은 별도 작업이다.

## 8. 범위와 미결정
이 문서는 화면 구조와 자산 요구명세다. 완성된 이미지·음원·UI 코드가 제공된 것으로 보고하지 않는다.
기존 자산 재사용 가능성, 색 대비 실측, 모바일 실제 터치, 오디오 믹싱은 실행 검수 필요. 미결정인 영구 수집·상점·광고 화면은 시험판에 추가하지 않는다.
