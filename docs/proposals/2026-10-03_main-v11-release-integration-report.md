## 승인과 반영 범위

사용자가 승인한 기존 6승급 갈래의 공격 시각 구별과 그 검수·통합·배포 범위를 완료했다. 새 갈래나 밸런스 기능은 추가하지 않았다.

- v0.11은 기존 3영웅·6승급 갈래를 실제 공격 사건에 맞춰 구별하는 화면 표현 변경이다. 비비 집중은 좁은 연속 탄선과 표적 모서리 표시, 난사는 실제 명중 끝점을 향한 분절 탄선을 쓴다. 탄코 폭발은 실제 반경 안의 방사형 충격 표시, 화염은 불꽃형 탄과 실제 화염장·잔불 틱을 쓴다. 로코 유도는 실제 추적 위치를 따르는 날개형 로켓, 관통은 실제 방향·구간을 따르는 좁은 창과 관통선 화살 표식을 쓴다.
- 런타임 변경은 `scripts/SquareScreen.gd` 하나이며 v0.10의 나머지 115개 런타임 항목은 동일하다. 가짜 표적·곡선 궤도·확장 반경·추가 피해를 만들지 않는다. 공유 폭발 링의 선·전장 자르기는 승급 전 탄코에도 적용되지만 승급 전 투사체는 보존한다. 공격 효과 수명은 기존 시뮬레이션 시간 기준이며 새 표시 타이머·반복 재생을 넣지 않았다.
- 모델·RNG·저장·음향·HP·속도·영입·경제·카드 수치는 바꾸지 않았다. 기존 220ms 처치 잔상과 HP·장갑 전면 표시를 유지한다. 고배속의 효과가 모든 프레임에 보이거나 실제 휴대폰에서 구별된다는 보장은 아니다.

비비 집중의 표적 모서리는 집중점을, 난사의 분절 탄선은 실제 발사·명중 방향들을 나타낸다. 탄코 폭발 충격선은 확장 중인 실제 반경 안에 두며 화염장·공유 폭발 링은 전장에 맞춰 자른다. 로코 유도는 모델의 현재 추적 위치를 사용하고 별도 곡선을 만들지 않는다. 관통선은 실제 완료된 구간에만 화살 표식을 두며 10배속 가시성을 위한 최소 알파를 적용하되 수명은 늘리지 않는다.

네이티브 창 제목은 동결한 프로젝트 설정의 v0.9를 유지한다. 전달물과 배포 wrapper 식별은 v0.11이다. 새 저장 schema·호환 경계를 추가하지 않았다. 첫 영입부터 3영웅 각각 1/3, 첫 중복의 갈래 선택·승급, 이후 중복 성장, 1·2·3·5·10배속, 기존 런의 시간 규칙을 보존한다.
