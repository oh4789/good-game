## 실행 검증

Godot 4.6.3, Linux headless, Android feature=false. Android와 같은 4개 창 배율 속성을 명시한 시험 fixture이며 실제 Android 시작 분기를 실행한 것은 아니다. 입력은 엔진 dispatcher를 거치고, 입력 행동을 검증하기 위해 버튼 신호를 직접 emit하지 않는다. 초기 상태 설정/중단 notification은 시험 코드에서 호출한다.

| 물리 창 | 관측 논리 크기 | 취소·설정·키보드 | 배치·재열기·중단 |
|---|---|---:|---:|
|720×1600|390×866|69/69|67/67|
|1600×720|866×390|69/69|67/67|

최종 **272/272 단언 통과**, 4개 프로세스 exit 0, 실패 0. 각 suite의 1개 단언은 실제 논리 짧은 변390과 1.8보다 큰 stretch가 적용됐는지 확인한다. 272개의 독립 사용자 세션이라는 뜻은 아니다.

- 취소된 영입/XP/승급/새 원정은 무변경이며 새 정상 입력은 한 번 반영.
- 취소된 소리/QA 토글과 음량 제스처는 설정 저장 횟수·바이트·값 보존. 정상 클릭과 키보드 복구 통과.
- 배치는 정상 같은 칸 release만 반영. 취소·다른 칸·영역 밖·단독 release는 무변경. 눌렀을 때 선택한 영웅 보존.
- 같은 모달을 닫고 재열거나 gate가 바뀐 뒤의 오래된 release 차단.
- 포커스 이탈/앱 중단·멀티터치 뒤 정상 입력 복구 통과.

초기 실행은 기존 268단언이 모두 통과했다. 이후 배율이 실제 적용됐다는 관측과 4개 전제 단언을 보강해 최종 272단언을 확인했다. 초기 결과는 최종 수에 더하지 않았다. 게임 코드 수정은 없었다.

재현: 묶음의 prepare.py에 정확한 SOURCE ZIP을 전달하고 Godot headless import 후 run_checks.py를 실행한다. README에 전체 명령과 격리 XDG 경로가 있다.

## 문제점·한계

이번 범위에서 신규 회귀 결함을 발견하지 못했다. DV2-P02의 취소 결함은 현 v0.15 통합 코드에서 재현되지 않았다. 이를 모든 입력 문제 해결이나 전체 1차 완성으로 확대하지 않는다.

현재 SOURCE는 예전 REPORT/CANCELED_INPUT_BACKPORT의 미배포 문구와 과거 버전 설명을 포함한다. 이번 식별은 정확한 ZIP 해시·Android manifest·최신 공개 v0.15 배포 보고를 우선했다. 과거 문서를 삭제/수정하지 않았다.

스크린샷·렌더링/잘림·실제 OS 회전·휴대폰 touch/Back·업데이트/Continue·브라우저 WASM/IndexedDB·주관적 음향 검증은 이번 실행 범위가 아니다. 두 고정 방향에서 검사했으며 누른 채 회전하는 도중은 검사하지 않았다. 새 APK/PCK도 검사하지 않았다.

## 개선 제안과 다른 팀 요청

- 두리: 다음 소스 패키징 때 루트에 최신 버전/해시 안내를 명확히 연결하면 과거 미배포 문구의 오독을 줄일 수 있다. 소규모 문서 작업, 낮은 위험, 패키징 담당 의존, 게임 규칙 충돌 없음. 현재 공유 파일 변경 요청/인계는 불필요하다.
- QA/두리: 실제 v0.15 휴대폰에서 설정 취소·정상 복구·배치·모달 재열기 증거를 기존 인수표에 연결해 달라. 기기/OS/빌드와 입력 순서가 필요하며 실제 기기 인수만 이에 의존한다. 이번 도구 DONE과 분리한다.
- 새 패치를 추가할 근거는 없다. 기존 134검사를 유지하고 배율 fixture를 보조 회귀 도구로 재사용하는 것을 제안한다. 통합 채택은 두리 담당이며 게임 수치/저장 변경 없음.
