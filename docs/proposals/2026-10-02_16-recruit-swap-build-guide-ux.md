## 3. 영입 결과 화면
영입 버튼: '영입 · 고철 {cost}'.
자원 부족: '고철 {missing}개가 더 필요합니다'.
출전 공간·대기석에 관계없이 결과 거래를 먼저1회 완료한 후 알림을 표시한다.

| 결과 | 제목 | 보조 문구 | 다음 행동 |
|---|---|---|---|
| 처음 획득 | '{name} 합류!' | 전투중:'다음 준비 시간에 배치할 수 있습니다' | 준비단계에영입대기목록표시 |
| 중복·미승급 | '{name} 승급 재료 +1' | '다음 승급 {current}/{needed}' | 본체추가없음 |
| 중복·승급 | '{name} {star}성 달성' | '전용 카드와 별개로 기본 성능이 강화됩니다' | 상세수치보기 |
| 최대성중복 | '{name} 최대 승급' | '고철 {refund}개를 돌려받았습니다' | 잔액갱신 |

알림 닫기나 건너뛰기는 자원·결과를 취소하지 않는다.
예정 카드 화면과 겹치면 카드만 입력을 받고 영입 알림은 뒤로 보류한다.
준비 중 새 영입이면 '배치할 영웅 선택'으로 이어질 수 있으나 빈칸에 자동으로 강제 배치하지 않는다.

## 4. 확장판 준비 화면과 교체 흐름
출전3칸·대기목록최대3명 표시. 미영입영웅은'대기석'에보여보유한것처럼표시하지않는다.
사용 흐름:
1. 대기영웅 선택.
2. 출전빈칸이있으면보드빈칸선택으로배치.
3. 출전3명이면교체할출전영웅선택.
4. 비교패널에서정보확인.
5. '교체하기'로확정하거나'돌아가기'로취소.

교체 확정은한처리로출전/대기위치를교환하고지원대상·사거리프리뷰를갱신한다.
새 영웅은 선택한 기존 영웅의 보드칸으로 들어간다. 기존영웅은대기목록으로간다.
빈칸선택이출전한도4번째영웅을생성하지않도록출전수와칸점유를함께검증한다.
같은영웅재선택은교체없음. 보드밖드롭은원위치. 연타는한교체만적용한다.

### 비교패널에 반드시 보일 정보
| 항목 | 현재 출전 영웅 | 새로 출전할 영웅 |
|---|---|---|
| 역할·이름 | 현재값 | 새영웅값 |
| 별·승급재료 | 유지될값 | 보유값 |
| 전용 강화 | 카드명·단계·갈래 | 그영웅의실제보유카드 |
| 궁극기 | 현재충전 | 최초출전0또는보존된충전 |
| 배치후범위 | 현재 공격/지원 구간 | 교체 후 실제 구간 |
| 다음 적 특성 | 준비정보공통 | 준비정보공통 |

고정 안내: '강화와 충전은 각 영웅에게 남습니다. 교체한 영웅에게 옮겨지지 않습니다.'
공용효과가있으면: '파티 공용 강화는 새 동료에게도 적용됩니다.'
종합전투력숫자로자동추천하지않는다. 사거리·지원·장갑역할을단일점수로평가하지않는다.
피해와주기가서로다른영웅의공격력숫자만초록/빨강으로비교해상위호환처럼보이지않게한다.

## 5. 유지·초기화 항목
- 보존: 영웅ID,별,중복재료,기초카드단계,핵심갈래,완성카드,궁극기충전.
- 새로운영웅에게이전하지않음: 떠난영웅전용카드·별·충전.
- 재계산: 지원인접관계,유효사거리,현재사용가능궁극기,다음카드풀.
- 준비진입때이미정리: 발사체·장판·파쇄·직접명중기록·일시궁극기·공격타이머.
- 대기석에서는 궁극기 충전 없음. 왕복배치로 충전0리셋이나100충전하지않음.
- 기본파쇄를지원한영웅이빠져도효과잔류로악용할수없도록준비진입정리규칙을유지.
- 이미열린카드선택중교체불가. 완료후준비로복귀한다.
후반영입에게무료전용카드를자동지급하는구제규칙은이번에추가하지않는다. 교체율실측뒤별도검토한다.

## 6. 빌드 안내 화면
영웅정보안에 '기초 강화 → 핵심 갈래 → 완성 효과'를표시한다.
첫단계에필요한것은해당영웅기초카드1회이며별승급조건은없다.
예시:
- 비비: 집중 조준 → 집중 난사 → 집중 추가탄.
- 핀: 출구 조준 → 출구 파수 → 처치 후 재사격 단축.
- 애쉬: 잔류 연료 → 화염 장벽 → 연속 노출 강화.
- 토리: 고속 구동 → 가속 정비 → 한 명 집중 지원.

표시 상태:
| 상태 | 문구 |
|---|---|
| 기초없음 | '이 영웅의 기초 카드를 선택하면 핵심 갈래가 열립니다' |
| 기초있음·핵심없음 | '핵심 갈래를 선택할 수 있습니다' |
| 핵심선택 | '{branch} 선택됨 · 이 런에서는 다른 갈래로 변경할 수 없습니다' |
| 완성미획득 | '완성 카드가 강화 선택에 등장할 수 있습니다' |
| 완성획득 | '빌드 완성 · 기초 카드와 공용 강화는 계속 선택할 수 있습니다' |
| 다른갈래잠금 | '이번 런에서 다른 갈래를 선택했습니다' |

15의대표1갈래시험에서는미활성갈래를획득가능한것처럼노출하지않는다.
완성우선슬롯이있어도여러영웅의완성후보중추첨하므로'다음레벨에반드시등장'이라고쓰지않는다.
대표경로는예시이며다른기초카드로도핵심해금가능. 사용자가제시된기초카드하나만필수라고오해하지않게한다.

## 7. 핵심 카드의 선택 문구
- CAN-K1: '포탄 피해 48→62 / 기본 공격 간격 1.5→1.8초'. 강해지는부분과느려지는부분을동등하게표시.
- ASH-K1: '기본 화염 지속 +1초 / 틱 피해 ×0.85'. 틱피해감소를숨기지않음.
- TOR-K3: '주변8칸 지원 / 기본 지원 공격속도 -5%p'. 이동공방이전투중이동이라는오해를막음.
- 핵심카드확정버튼: '이 갈래 선택'. 다른갈래잠금안내를카드상세에표시하고추가팝업은겹치지않음.
수치는실제데이터와같아야하며지원언어별문자열에별도고정값을복사하지않는다.

## 8. 개발·디자인·QA 인계

디자인: 초상·역할·별·갈래를서로다른표현으로표시,비교패널에서전장과지원범위를확인가능하게배치.

QA:
1. 출전3+대기1 상태에서빈칸드롭으로4명출전불가.
2. 2성·기초2회·핵심·충전60인핀교체후복귀시모두보존.
3. 신규핀최초출전은충전0,이후왕복은잔량보존.
4. 토리교체시기존지원해제와새지원표시일치.
5. 카드열린상태교체입력차단·입력관통없음.
6. 영입애니메이션닫기·카드중첩에도거래1회.
7. 대표1갈래시험과전체3갈래판의정보노출차이확인.
8. 갈래선택취소는잠금없음,확정은같은런다른갈래잠금.
9. 다음카드후보에는현재출전영웅만반영.
10. 소형화면에서교체버튼·취소·카드전후수치가잘리지않음.
