## 인수 완료 조건과 남은 일

정적 대조 완료: 최신 전달물 확인, 12카드/6갈래 및 계산·표시 경로 대응, 유지/수정/보충 판정, 최소 변경 문구 제공.

적용 후 담당자가 확인할 항목:
1. 신규 합류·첫 중복 선택 전·선택 확정 후·추가 중복 네 상태의 문구가 실제 rank 변화와 일치.
2. 공용 HP 카드가 제시되어도 선택 안내가 맞고, 전용 3회/공용 반복 표시는 유지.
3. 공격/승급 정보의 두 배율 라벨 모두 성장 배율로 통일. 문자열 변경 때문에 재화·카드·승급을 추가 적용하지 않음.
4. 소이 겹침·장전 틱·공용 사거리 설명을 상세에서 읽을 수 있고, 확정/닫기 버튼에 접근 가능.
5. 작은 세로/가로 화면과 큰 rank/count에서 제목·보충 설명·버튼 잘림 여부 확인.

현재 부족한 입력은 수정 채택/보류 기록, 실제 적용 소스/버전, 해당 화면 증거다. 현재 소스가 없다는 과거 차단은 종료한다. 실제 브라우저·휴대폰 인수는 중앙 기록의 접근/기기 증거 제한과 같은 이유로 미검증이다. 이번 정적 결과를 실제 배포 화면을 직접 보았다는 주장으로 바꾸지 않는다.
