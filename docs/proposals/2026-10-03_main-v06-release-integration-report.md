## 변경과 보존

- 적 HP, 실제 장갑 상태, 보스 표식을 영웅·효과에 가리지 않도록 전면에 표시한다. 표식은 클릭·포커스를 받지 않는다.
- 출입구 표시를 읽기 쉽게 하고, 적 처치와 실제 누수를 구별한다.
- 실제 공용 HP 손실량으로 누수 표식을 표시한다. 동시·치명적 누수에서도 표시량을 실제 감소량에 맞춘다.
- 최소 웨이브 시간이 지난 뒤 마지막 적이 누수하면 같은 프레임에 효과가 지워져 표시가 사라지던 경계를 수정했다. 새 손실 표시를 0.8초 유지하며 저장에서 복원한 과거 효과를 새 손실로 재생하지 않는다.
- 결과 화면을 적 전면 레이어가 덮지 않게 했으며, 선택·상세·저장 보호 화면의 우선순위를 유지한다.
- v0.5의 영웅 원화·단일 스프라이트 메시 모션·배치 사거리 잘림·승급 배지, 기존 저장·음향·동작 줄이기·DPR·포인터 동작을 유지했다.
- 게임플레이 모델·밸런스·저장 schema를 변경하지 않았다. [v0.3 확정 규칙](2026-10-03_v03-canonical-decisions.md)의 3영웅·6갈래, 자동 전투, 첫 중복 즉시 승급과 이후 중복 성장, 런 한정 보유를 유지한다.

## 검수 결과와 증거 범위

독립 최종 QA는 2026-10-03 05:45:20 UTC에 소스·정확한 PCK·네이티브 범위 PASS, 최종 SOURCE 아카이브 대조는 05:48:21 UTC에 PASS로 기록됐다. 이후 배포·보존본 영수증으로 실제 게시와 파일 갱신을 별도로 확인했다.

- 소스와 정확한 PCK에서 각각 1,160,987개 검증 항목을 통과했다. 수치를 서로 다른 사용자 플레이 수로 합산하지 않는다.
- 적 4종, 화면 크기 4종, 경로 표본·HP 비율·장갑 약화 상태를 대조했고 최소 HP 표시 크기와 전장 경계, 보스 표시를 확인했다.
- 1배·2배속, 30·60fps, 동시·치명적 누수, 일시정지·만료, 실제 마지막 누수와 웨이브 전환, 복원·결과·새 런 경계를 검증했다.
- 8개 갈래 조합의 화면·모델·난수 일치와 저장 호환을 확인했다. 각 런타임에서 확인된 새 런 70개와 실제 강제 종료·복원 8개 사례를 재검증했다.
- 네이티브 이미지 496개를 수집하고 해시 목록을 대조했으며 선택한 실제 이미지 픽셀을 직접 검토했다. 전 이미지의 수동 검토 완료를 뜻하지 않는다. 시험 상태 주입 캡처와 자연 전투 캡처를 구분했다.
- 기존 음향 모듈·에셋과 DPR 어댑터는 바이트 동일하며 새 화면 사건·복원·입력 검증을 재실행했다. 이전의 깊은 저장·음향·성능 증거는 동일 모듈·리소스 범위에서만 상속한다.

## 미검증과 알려진 비차단 항목

- v0.6 브라우저 WASM, IndexedDB 및 브라우저 프로세스 저장 내구성은 미검증이다.
- 실제 휴대폰 터치·safe-area·PWA·APK, 발열·배터리·장시간 성능은 미검증이다.
- 실제 스피커의 주관적 믹스·반복 청취는 이번 검수에서 확인하지 않았다.
- 네이티브 PASS와 배포 성공을 브라우저·휴대폰 합격으로 쓰지 않는다. 이전 버전 성능 표본은 v0.6의 새 성능 보장이 아니다.
- 도움말의 v0.4 문구는 v0.5에서 이어진 비차단 표시 문제다. 게임플레이·저장 호환에는 영향을 주지 않으며 이번 동결 범위에서 변경하지 않았다.
- 텍스처 최적화는 별도 격리 실험이다. 현재 v0.6 배포 기능이나 검증된 모바일 최적화로 기록하지 않는다.

## 다른 팀 요청과 다음 후보

1. QA: 승인된 현재 실행 접근을 확보하면 v0.6 실제 브라우저 시작→전투→누수→저장·새로고침→이어하기와 휴대폰 터치·잘림을 우선 확인한다. 브라우저·OS·기기·정확한 버전과 재현 결과를 남기는 것이 완료 조건이다. 접근이 없으면 정확한 차단을 기록한다.
2. 개발·디자인: 격리 텍스처 실험은 현재 v0.6 대비 상태·난수·입력·저장 동등성과 실제 화질·파일 크기 증거를 먼저 인계한다. 운영 파일·Site를 직접 갱신하지 않으며 별도 인수 전까지 미배포로 유지한다.
3. 다음 유지보수에서 도움말 버전 문구를 검토한다. 수정 시 해당 도움말 표시·실제 전달 버전 일치를 재검수하며 현재 동결 파일을 소급 변경하지 않는다.

과거 보고와 타 팀 결과는 이력으로 보존한다. 다음 작업은 중앙 인수 기준의 정확한 파일·버전·해시에서 시작하고 담당·변경 파일·격리 기준·인수 조건을 먼저 맞춘다. 문서 추가나 후보 제안만으로 새 게임 규칙·공개 범위·타 팀 소유 변경이 승인되지는 않는다.
