## 계산식과 범위
k=승급 단계, a=해당 영웅 피해 카드 횟수, A=공용 피해 카드 횟수, s=전용 간격 카드 횟수.
- 피해의 성장 계수는 1 + 0.18k + 0.08a + 0.04A. 갈래·집중·장갑 계산은 별도다.
- k=2, a=2, A=1이면 1.56배. 기존 12종 제안식의 1.6864배와 다르다.
- 공격 간격은 갈래 기준 간격 × 0.94의 s제곱. 3회면 0.830584배, 이론상 발사 빈도 약 +20.397%. 실전 DPS 증가율로 단정하지 않는다.
- 사거리는 비비173, 탄코180, 로코192에 전용 사거리 횟수당 +8(비비·탄코만), 공용 횟수당 +4.
- 소이는 발사 시 성장 계수를 직접 피해·화염 피해에 각각 한 번 반영한다. 기존 화염 틱은 0.5초로 공속 카드와 분리된다.
- 탄코 사거리 카드는 폭발·화염 반경을 늘리지 않는다.
- **로코 관통은 사거리 끝에서 +180까지 길이가 정해진다. 따라서 공용 사거리 카드가 관통 길이도 늘린다.** 기존 제안의 “관통 길이는 불변”을 현행 설명으로 사용하면 안 된다.
- 새 런 초기화와 선택 단계·세션 검사 처리는 소스에서 확인했다. 연타·브라우저 실행 회귀 통과를 이번 검수로 주장하지 않는다.

## 후보 부족 판단 정정
현행은 전용과 공용을 한 풀에서 균등 추첨하지 않는다.
1. 첫 보상은 조건을 만족하는 비비 전용 3종을 우선 제시한다.
2. 이후 활성 영웅의 상한 미만 전용 카드에서 중복 없이 추첨한다.
3. 3장 미만이면 공용 피해 → HP → 사거리 순으로 빈칸을 보충한다.
4. 공용 3종은 반복 가능하므로 전용 풀이 비어도 서로 다른 3종이 남는다.

전용 후보가 2개면 공용 피해만, 1개면 피해·HP, 0개면 세 공용이 나온다. 따라서 공용 카드의 낮은 선택 횟수를 곧바로 낮은 선호도로 해석할 수 없다. 먼저 실제 노출 횟수가 필요하다.

기존 “최초 4번째/13번째 선택에서 후보 부족 가능”은 유한 상한을 둔 제안 모델 결과다. 현재 구현의 재현된 결함이 아니며 현재 풀 교체의 근거로 쓰지 않는다.

## 문제점
1. 제안과 구현의 같은 효과 이름 아래 수치·상한·연산이 다름: 위 표로 재현 가능. 잘못 통합하면 의도하지 않은 화력 상향·카드 부족이 생길 수 있다. 현재 규칙 변경 필요 없이 문서 대응으로 해소 가능.
2. 공용 사거리의 관통 길이 영향이 기존 제안 설명과 다름: 소스의 사거리 기반 길이 계산으로 확인. 코드 결함으로 확정하지 않고 의도 확인이 필요하다.
3. 최신 시작 안내의 v0.3 기준과 개발1의 v0.3.1 배포 보고가 병존한다. 최신 통합 소스 동일성은 이번 ZIP으로 확인 불가.
