## 실제 확인 결과
GitHub 연결로 main의 재귀 파일 트리(truncated=false), 브랜치 목록 및 열린 PR 목록을 확인했다. 당시 main 하나와 열린 PR 0개였으며 README.md 및 docs/proposals의 Markdown 문서만 있었다. 게임 소스, 프로젝트 실행 설정, 이미지·음원 파일, AGENTS.md는 해당 트리에 없었다. 로컬 작업 공간에도 기준 소스가 없었다. Git clone은 실행 환경의 프록시 연결 실패로 실패했으나 저장소 내용은 GitHub 연결을 통해 확인했다.

## 소스 인수 후 수정 계획 [제안]
실제 경로를 확인한 뒤 UI 전용 파일의 정확한 목록을 먼저 보고한다. 파일명을 지금 만들어 기존 경로처럼 제시하지 않는다.
1. 기준 커밋과 실행 방법을 고정하고 메뉴→준비→전투→선택→결과를 실행한다.
2. 가림: HUD/알림/설명이 경로와 조작 버튼을 덮는 위치를 기록하고 UI 영역·레이어·입력 처리를 조정한다.
3. 잘림: 원본 이미지 잘림, 아틀라스 프레임 경계, 부모 마스크, 화면 바깥 배치를 따로 확인한다. 원본에서 이미 잘린 그림은 레이아웃 수정으로 해결했다고 보고하지 않는다.
4. 모바일: 안전영역·뷰포트 변화·가로 배치·모달 스크롤·버튼 접근을 수정한다. 표시 배율 변경이 전투 좌표나 사거리 판정을 변경하지 않도록 확인한다.
5. 표현: 기존 발사/피격/결과 이벤트를 소비한다. 애니메이션 종료나 오디오 재생 성공을 피해 판정 조건으로 추가하지 않는다.

공용 HTML/렌더러/입력 라우터/상태 관리에 UI와 전투가 섞여 있으면 해당 파일·변경 구간·필요 인터페이스를 제시하고 조율 후 수정한다. 전투 좌표, 공격 주기, 피해, RNG, 성장 적용, 승패 전이는 1팀 소유로 유지한다.
