## 제작
기존 비비·탄코·로코 시트를 직접 열고 각6표정을 내장 이미지 편집으로 별도 생성했다. 종이 배경·이름·장식을 제거하고 실제 알파 배경을 요청했다. 이는 원본 픽셀을 그대로 자른 파일이 아니므로 선·고개 각도·세부 형태 차이가 있다.
비비는 사용자 선택인 흰 머리·토끼귀·붉은 의상 유지. 탄코는 곱슬 갈색머리·남색 모자, 로코는 흰 포니테일·검은 리본·사람 귀 유지.
각 캐릭터 neutral/happy/confident/angry/surprised/embarrassed, 총18개1254×1254 RGBA PNG. 생성19회 중 로코 기본 첫 버전은 주요 머리카락이 우측 경계에 닿아 여백 보완본으로 교체했다. 최종 묶음에는18개만 포함한다.

## 검증과 발견한 문제 수정
- 파일 수18,파일명18개 고유,해시18개 고유,RGBA 확인.
- Pillow 읽기 전용 검사로 알파0/알파>127 경계와 SHA256 기록. 이미지 픽셀을 스크립트로 수정하지 않았다.
- 최종18장의 주요 본체(alpha>127)는 캔버스 내부. 로코 기본 주요 경계는(134,192,1139,1052)로 개선.
- 낮은 알파 잔여가 캔버스 끝에 닿는10개 파일이 있어 완전한 알파 정리 통과는 아니다. 자세한 파일 목록은 QA.json에 있다. 본체 여백 역시 균일하지 않다.
- Godot4.6.3 네이티브 UI에서18개 전부128px 어두운/밝은 배경과64px 어두운 배경으로 렌더하고 실제 스크린샷을 열었다.
- 첫 축소는 세부선이 거칠고 크기가 달랐다. PNG를 보존하면서 표시 영역 정규화와 linear+mipmap 필터를 적용해 다시 렌더·열람했다.
- 표시 방법:manifest의 body_bbox(alpha>127,좌상단포함/우하단제외)를2px 확장,컨테이너에서8px를 뺀 영역에 비율 유지 fit,중앙 정렬. 원본 알파 외곽의 잔여를 화면상 줄이는 검토 설정이며 원본 파일 정리 완료와 다르다.
- 128px에서 표정 비교 가능. 64px에서는 비비 기본/자신감/분노와 로코 기본/분노의 구분이 약하다. 탄코의 큰 입 변화는 상대적으로 분명하다. 이 판단은 디자인 육안 검토이며 사용자 식별률 시험은 아니다.

## 남은 문제와 개선 제안
알파 외곽 잔여와 낮은 해상도의 약한 감정 구분 때문에 최종 제작 에셋 인수는 보류한다. 128px 이상의 초상화와 감정 의미를 설명하는 텍스트를 병행하는 UI 사용을 제안한다. 정확한 픽셀 마스크로 외곽을 보정하면 확대 표시 품질을 개선할 수 있으나 원본 레이어/정밀 편집 방식이 필요하며 흰 머리 끝 손실 위험이 있다. 작업량 중간,현재 게임 규칙 충돌 없음.
실제 UI 크기 확정,폰 실기,브라우저,게임 연결,얼굴 위치의 픽셀 정합,사용자 접근성 검증은 미완료다. 18개 제작 완료를 게임 반영 완료로 표현하지 않는다.
