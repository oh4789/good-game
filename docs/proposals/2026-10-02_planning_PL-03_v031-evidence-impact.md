## 4. 약 7분 목표의 해석 보완

400.2~414.0초는 산술상 약 6분40.2초~6분54.0초다. 404.3167초는 약 6분44.3초다. 이는 보고된 전투 시간의 단위 변환일 뿐 실제 사용자 한 판의 소요 시간을 측정한 결과가 아니다.

브라우저 보고는 2배속 사용을 명시하지만 전투 시간 필드가 시뮬레이션 누적값인지 실제 경과값인지 정의하지 않는다. 따라서 404.3167초를 임의로 절반으로 나누거나, 준비·카드·갈래 고민 시간을 임의로 더해 7분 달성으로 판정하지 않는다.

PL-02 시간 기록에 다음 최소 정보만 보완한다.

- 전투 시간 필드의 정의와 단위, 배속 변경 시각.
- 실제 시작~종료 경과시간.
- 서로 겹치지 않는 전투·준비·카드 선택·갈래 선택 구간.
- 일시정지·앱 숨김 구간과 총시간 포함 여부.

기존 약 7분 설계 목표는 유지한다. 측정 정의가 확인되고 실제 선택 시간이 있는 기록을 받은 뒤 목표와 비교한다.

## 5. 문제점과 개선 제안

### 문제점

1. **버전별 증거가 분산됨.** 현재 결정 §5와 새 통합 보고의 브라우저·저장 상태를 대조하면 차이가 보인다. 문서 작성 시점 차이가 원인이며 게임 결함으로 판정하지 않는다. 옛 미검증 상태의 반복 보고 또는 새 증거의 과도한 일반화 위험이 있다.
2. **집계값만으로 조합 평가 불가.** 통합 보고의 32런 요약에는 행별 조합·시드·HP·누수·성장 입력이 없다. 입력 불일치나 특정 갈래 우세 여부는 미확인이다.
3. **시간과 횟수의 의미 불명확.** 2배속 전투 시간과 12카드 관측을 일반 플레이 시간·최대 선택 횟수로 오인할 수 있다. 실제 시간 정의와 카드 풀·레벨별 XP 조건은 미인수다.

### 개선 제안 — 모두 제안 상태

| ID | 제안 / 이유·효과 | 작업량·위험 | 의존성 / 규칙 충돌 |
|---|---|---|---|
| PL-03-I1 | 버전·조건·공통 조합ID를 원시 결과와 함께 인계해 기존 PL-02에 연결 | 기존 출력에 메타데이터 보완 정도; 잘못된 ID 매핑 위험 | 개발1·두리의 실제 로그와 입력 정책. 규칙 변경 없음 |
| PL-03-I2 | 보고 시간의 시계 정의와 배속 이력을 명시해 7분 목표 오판 방지 | 필드 설명은 소규모, 누락된 실제 경과시간은 추가 계측 필요 | 실행 담당의 로그 정의. 규칙 변경 없음 |

현재 근거만으로 적 HP·영입비·승급 계수를 조정하지 않는다. 통합 담당의 32런 승리 보고는 난도 상향의 단독 근거가 아니다.

## 7. 검증과 완료 지점

- 최신 시작 안내·협업 규약·기획 지시서·기준 문서·통합 보고·PL-02를 대조했다.
- 8개 공통 ID와 P 별칭이 일대일이며, 2×2×2의 모든 갈래 조합을 포함하는지 확인했다.
- 각 실행 수치의 출처를 통합 보고로 한정하고, 신규 HP·누수·조합별 성능값을 추정하지 않았다.
- 시간 변환은 산술로만 제시하고 실제 소요 시간과 분리했다.
- 원시 로그 미인수와 직접 실행 0회를 명시했다. 게임 기능 합격이나 일반 사용자 재미 검증을 새로 선언하지 않았다.
- 본 문서의 상대 링크 대상 존재 여부를 저장 전 확인한다. 저장 후 원문 재조회로 내용 일치를 확인한다.
- 마지막 완료 지점: PL-03 기획 영향·식별자 연결·후속 입력 요청 정리. 저장·재조회 결과는 최종 보고에 남긴다.
- 남은 일: 실제 조합별 평가·실제 소요 시간 판정은 자료 인수 후 별도 작업. PL-03 문서 작업의 차단은 없음.

## 8. 다음 작업 후보

- 의존성·차단: 실제 카드 ID·효과식·상한·제시 조건·XP 조건이 필요. 미인수 상태에서는 판정할 수 없다. 사용자 시작 승인과 자료 인수 후 진행.
- 추가 독립 후보: 현재는 없음. 동일한 준비표를 반복 제작하지 않는다.
