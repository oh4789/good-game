## 현재 기능과 역사적 기록의 구분

- v0.8의 새 런은 1~9웨이브 스폰 구간을 28초에서 32초로 늘리고 10웨이브는 28초를 유지한다. 기존 런은 남은 런 전체에서 이전 28초 타이밍을 유지한다. 전투 중·선택창 복원과 백업 복구에도 같은 런 규칙을 적용한다.
- 적 수·HP·경제·영웅·카드 수치는 그대로다. 기존 표준 정책 시뮬레이션의 빈 대기 중앙값 약 89→57초는 제한된 관측이며, 적 조기 소멸 문제나 사람의 재미·난이도를 해결했다는 뜻은 아니다.
- v0.7은 3영웅 텍스처의 import 크기 제한과 축별 UV 보정을 통합했다. 원본 PNG·메시·메타데이터·발/총구 기준점은 보존했으며 런타임 소스 변경은 4개 파일에 한정된다.
- v0.7 당시 PCK는 v0.6 대비 4,007,088 bytes, 38.46% 작아졌다. 세 영웅의 디코딩된 mip 이미지 할당량은 25,154,992 → 3,959,012 bytes로 84.26% 감소했다. 전체 GPU·프로세스 메모리 절감률, FPS 개선률 또는 휴대폰 성능 보장이 아니다.
- v0.6의 적 HP·장갑·보스 전면 표시, 출입구 가독성, 실제 HP 손실량 기반 누수 피드백과 마지막 적 누수 뒤 웨이브 전환 보호를 유지한다.
- v0.5의 비비·탄코·로코 원화, 발사 사건 기반 단일 스프라이트 메시 모션, 전장 안으로 자른 배치 사거리와 전면 승급 배지를 유지한다. 완전한 관절 리그는 아니다.
- v0.4의 같은 런 이어하기·저장 schema·백업 복구·손상 보존·새 런 확인/취소 보호를 유지한다. 기존 런을 강제로 초기화하지 않는다.
- 효과음·BGM, 반응형·터치·동작 줄이기, DPR·포인터 대응을 보존한다. 신규 음향 설정 기본값은 OFF다.
- v0.1·v0.2·v0.3·v0.3.1·v0.4·v0.5·v0.6·v0.7의 여덟 런타임 버전과 기존 저장 브리지를 보존했다. 엔진과 저장 경로는 바꾸지 않았다.
- [v0.3 게임 규칙](proposals/2026-10-03_v03-canonical-decisions.md)의 영웅·중복·갈래·카드·경제 방향을 유지한다. 이번 변경은 새 런의 스폰 타이밍에 한정된다. 과거 보고의 미배포·계획 문구는 당시 상태이며, 현재 구현은 이 문서와 [v0.8 보고](proposals/2026-10-03_main-v08-release-integration-report.md)를 따른다.

## 이어하기와 이전 버전 주의

새 v0.8 런은 현재 v0.8에서 이어한다. 기존 런은 기존 타이밍으로 이어진다. v0.7을 단순히 여는 것은 읽기 전용이며 저장을 변경하지 않는다. 다만 새 런 전환이 중단되어 새 저장과 이전 호환 저장이 함께 남으면 v0.7의 복구는 더 이른 진행을 제시할 수 있다. 이를 명시적으로 이어하면 활성 저장이 옛 진행으로 교체될 수 있고, 먼저 보존된 새 저장 바이트가 자동으로 돌아오지는 않는다. 정상 완료된 새 v0.8 런은 v0.7에서 이어하기가 비활성화된다.

## 검수 경계와 다음 인수

소스와 정확한 PCK에서 기존 타이밍 8개 자연 완료 런을 실제 v0.7과 비교하고, 새 규칙 8갈래 런의 연속/복원 상태를 비교했다. PacingCompatibility 1,523개 항목, ResumeUI·LegacyResumeUI 각각 224개 항목과 저장·음향·화면 회귀가 통과했다. 독립 호환 검수 24,173개 항목은 스케줄 분리용 적 제거를 사용했으므로 자연 전투 밸런스 증거로 집계하지 않는다.

정확한 최종 PCK를 네이티브로 열어 제목·도움말 v0.8, 기존 런 이어하기, 일시정지, 새 런 취소/명시적 확인을 확인했다. 로드된 PCK의 장면·모델 스모크 126개 항목도 통과했다. 과거 검수는 바이트 동일 범위의 이력으로 보존하며 모두 이번에 재실행했다고 쓰지 않는다.

**v0.8 브라우저 WASM·IndexedDB·실제 휴대폰·주관적 믹스는 미검증이다.** 실제 브라우저·휴대폰 검수는 승인된 실행 접근·기기 증거가 없어 차단 상태다. 배포 서비스 성공·네이티브 PASS·백업 바이트 일치를 웹/휴대폰 합격으로 바꾸어 쓰지 않는다. Android APK·PWA·safe-area·발열·배터리·장시간 성능도 미검증이다.
