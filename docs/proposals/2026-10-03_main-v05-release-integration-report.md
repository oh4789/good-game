## 이번 변경과 보존 범위

- 비비·탄코·로코의 깨끗한 원화를 적용했다.
- 실제 발사 사건에 맞춰 단일 스프라이트의 상체 메시를 움직인다. 독립된 팔다리의 완전한 관절 리그나 새 8방향 원화 전체를 구현한 것으로 표현하지 않는다.
- 배치 사거리 표시는 전장 영역 안으로 잘랐고 승급 배지는 영웅 앞에 표시한다.
- 게임 규칙과 밸런스 수치는 바꾸지 않았다.
- v0.4의 같은 런 이어하기, 저장 schema, 손상 복구, 정상 새 런 정책, 음향과 설정, DPR·포인터 대응을 보존했다. v0.4 런을 강제로 초기화하지 않고 이어갈 수 있다.
- v0.1·v0.2·v0.3·v0.3.1·v0.4의 다섯 런타임 버전을 보존했다.

[v0.3 게임 규칙](2026-10-03_v03-canonical-decisions.md)과 [v0.4 저장·음향 구현](2026-10-03_main-v04-release-integration-report.md)은 이어진다. 이전 문서의 “v0.5 아트 후보 미배포”는 당시 상태이며 이번 배포로 갱신된다.

## 검수 결과

- 독립 소스 실행과 정확한 PCK 실행에서 각각 354,273개 검증 항목을 통과했다.
- 8개 갈래 조합, 저장 호환, 직접 실행·복원 실행의 1,016개 상태·난수 체크포인트를 확인했다.
- 각 런타임에서 실제 프로세스 강제 종료·재시작 8개 사례를 확인했다.
- 실제 네이티브 픽셀로 영웅, 사거리 잘림, 승급 배지와 다양한 화면 크기의 표시를 확인했다.
- 소스·PCK의 반복 검증 수를 서로 다른 사용자 플레이 수로 합산하지 않는다. 시험용 상태 주입과 자연 전투 캡처도 구분했다.

같은 프로세스·전투 상태에서 60FPS 상한을 둔 네이티브 ABBA 비교 표본의 평균 프레임은 v0.4 16.91ms, v0.5 16.78ms였다. Screen 갱신 CPU 평균은 0.446ms에서 1.009ms로 약 0.56ms 늘었다. 이 표본에서 평균 프레임 악화는 관찰되지 않았지만 실제 휴대폰 성능·메모리·발열 보장은 아니다.

## 미검증과 다음 후보

- v0.5의 브라우저 WASM, IndexedDB, 실제 휴대폰은 독립 검증하지 못했다.
- 실제 스피커의 주관적 믹스·반복 청취, 물리 기기의 발열·배터리도 미검증이다.
- 이전 버전의 브라우저 통과 기록과 이번 네이티브 결과를 v0.5 웹·휴대폰 합격으로 대체하지 않는다.
- Android APK·실기 완료 상태는 아니다.
- v0.6의 적 상태 전면 표시와 구별되는 누수 피드백은 두리 소유의 별도 작업 후보다. 현재 v0.5 완료 기능으로 기록하지 않는다. 추가 게임플레이 확장 승인도 뜻하지 않는다.

새 검수·후속 인수는 중앙 문서의 최신 SOURCE 이름·버전·해시를 확인한다. 과거의 완료 결과는 버전 이력으로 보존하며, 운영 파일과 최종 배포는 기존 담당·인계 절차를 따른다.
