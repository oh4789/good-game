## 3. 기획 의도 [제안]
전용 카드는 특정 영웅의 공격 방식과 특기를 키운다.
공용 카드는 파티 화력·생존·궁극기·협동 중 운영 방향을 고르게 한다.
공용 카드를 선택해도 별도 영입 버튼, 영입 비용, 카드 선택 횟수는 변하지 않는다.
새로운 공용 카드 메뉴나 별도 재화를 만들지 않고 기존 레벨업3택1에 포함한다.

## 4. 공용 카드 상세표 [시험값]

| ID | 이름 | 회당 효과 / 단계값 | 상한 | 선택 조건 |
|---|---|---|---:|---|
| G01 | 정밀 공구 | 파티 공격력 +5%p/회: 5/10/15/20% | 4 | 항상, 상한 미도달 |
| G02 | 비상 수리 | 최대 공용HP +2 및 현재HP +2 | 4 | 항상, 상한 미도달 |
| G03 | 충전 축전기 | 궁극기 충전속도 +10%p/회: 10/20/30/40% | 4 | 항상, 상한 미도달 |
| G04 | 교차 사격 | 최근2초 안에 다른 아군의 직접 공격을 받은 적에게 피해 +10% / +15% | 2 | 현재 출전한 서로 다른 영웅2명 이상, 상한 미도달 |

모든 수치는 시험 제안이다. 공용 효과는 런 단위로 보유하며 이후 영입·출전한 영웅에도 적용한다.
같은 카드의 새 단계는 표의 누적값으로 대체한다. G04 2단계는10+15=25%가 아니다.
동일 카드ID를 한 선택 화면에 두 번 보여주지 않는다.

### G01 피해 계산
기존 전투06의 공격력 항목에 더한다.
최종 피해 = 기본피해 × (1+승급공격력+G01) × (1+집중+R02+G04) × (1-유효장갑).
G04를 별도 곱해 중복 증폭하지 않는다. 해당 공격에 적용되지 않는 집중 등은0.
발사체 공격은 발사 때 승급/G01/집중을 고정하고 적중 때 장갑/R02/G04를 평가한다.
즉시 명중 공격은 같은 사건 안에서 발사·적중 순서를 처리한다.
과잉피해를 제외한 실제 피해만 결과에 집계한다.

### G02 생존 처리
선택 순간 maxHP+=2, HP=min(기존HP+2,새maxHP).
예: HP7/20 →9/22, HP20/20 →22/22.
최대HP 증가는 런 종료까지 유지한다. 완충 상태에서도 선택 가치가 있다.
패배 판정 이후 카드로 부활하지 않는다. HP0과 레벨업이 겹치면 기존 패배 우선 처리.
보스 완주 즉시 실패 시험안을 채택한 빌드에서는 최대HP가20보다 높아도 보스 완주 실패를 막지 못한다. 해당 보스 규칙은 사용자 확정과 구분한다.

### G03 충전 처리
기본 충전속도4 × (1+0.1×단계).
0~4단계에서 충전100에 필요한 활성 충전 시간은25/22.73/20.83/19.23/17.86초.
출전·적존재·전투활성 조건과 발동중 충전정지는 전투06을 유지한다.
획득 순간 이미 쌓인 충전량은 유지하며 앞으로의 속도만 바꾼다. 즉시 충전을 지급하지 않는다.

## 5. G04 교차 사격의 정확한 처리 [제안]

### 발동 정의
각 적에 영웅ID별 '마지막 유효 직접 명중 시각'을 기록한다.
현재 피해의 영웅ID와 다른 ID의 기록이 있고, 현재 전투시각-기록시각 <2.0초면 G04 보너스를 적용한다.
정확히2.0초면 만료다. 다른 영웅이 여러 명이어도 한 번만 적용한다.
보너스는 추가 탄환/피해 사건/표식을 생성하지 않는다.

처리 순서:
1. 적 생존·명중 유효성 확인.
2. 현재 타격을 기록하기 전 기존 기록으로 G04 조건 평가.
3. 장갑·다른 보너스와 함께 피해 계산.
4. 피해 정산, 사망이면 보상1회.
5. 생존한 적에게 유효 직접 명중이라면 해당 영웅 시각 기록 갱신.
사망한 적의 기록은 삭제한다. 각종 정지 중2초가 흐르지 않으며 웨이브 종료 시 모두 삭제한다.

### 직접 명중과 추가타
| 공격 종류 | G04 피해 보너스 적용 가능 | 명중 기록 생성/갱신 |
|---|---|---|
| 비비 기본 주 표적 타격 / 궁극기 중 기본 사격 | 예 | 예 |
| 탄코 기본 포탄 폭발의 각 명중 적 | 예 | 예 |
| 로코 기본 로켓 | 예 | 예 |
| 탄코·로코 궁극기 직접 타격 | 예 | 예 |
| 비비 B03 관통 보조타 | 예 | 아니오 |
| 탄코 C02 지연 소폭발 | 예 | 아니오 |
| 경로 완주 누수·장식 효과 | 아니오 | 아니오 |

피해가0인 사건은 기록을 갱신하지 않는다. 같은 영웅의 여러 탄환은 서로 다른 아군으로 취급하지 않는다.
추가타의 보너스는 추가타가 명중하는 적의 기록으로 판정한다. 주 표적의 G04 보너스를 최종피해로 복사한 뒤 다시 적용하지 않는다.
궁극기 탄코의 세 포격도 모두 같은 영웅ID다. 혼자서 교차 사격을 활성화할 수 없다.
G04를 아직 보유하지 않은 동안에도 최근 직접 명중 기록을 유지하는 안을 제안한다. 획득 이후 첫 피해부터 기존 최근2초 기록을 사용할 수 있다.

### 예시
장갑0, 승급/G01/집중/R02 없음:
- t=0 비비가 적에게8: 선행 아군 기록이 없으므로8.
- t=0.5 로코가 같은 적에게66: 비비 기록이 있어1단계72.6.
- t=0.8 비비가 같은 생존 적에게8: 로코 기록이 있어8.8.
- 이후 비비 혼자 계속 공격하더라도 마지막 로코 명중에서2초가 지나면 비비의G04 보너스는 끝난다.
로코 파쇄가 있는 실전에서는 별도의 장갑/R02 처리까지 포함해야 하며 위 예시는 G04만 분리한 계산이다.

### 배치 의미
사거리 구간이 겹치거나 적 이동상 두 공격 구간의 간격이2초 미만일 때 활용하기 쉽다.
코너 몰아놓기를 정답으로 고정하지 않는다. 협동 보너스를 얻는 대신 출구 커버리지를 잃는지 비교한다.
UI에는 '함께 공격하면 피해 증가'와 정확한2초·현재 단계값을 표시한다. 모든 적에게 큰 연결선을 상시 그리지 않는다.

## 6. 카드 등장·추첨 알고리즘 [제안]
카드 화면을 열 때 현재 출전 영웅을 기준으로 아래를 수행한다.

1. P=출전 영웅 전용 카드 중 조건 충족·상한 미도달 ID.
2. G=공용 카드 중 조건 충족·상한 미도달 ID.
3. P에서 서로 다른2개, G에서 서로 다른1개를 균등 비복원 추첨한다. 후보가 부족하면 가능한 수만 뽑는다.
4. 3장이 안 되면 아직 제시하지 않은 반대쪽 풀에서 균등 비복원 추첨해 채운다.
5. 최종3장을 동일한 크기로 표시하며 전용은 영웅명, 공용은 '파티 공용'으로 구별한다.
6. 후보와 카드RNG 상태는 화면 생성 시 저장한다. 정지/재개로 재추첨하지 않는다.
7. 연속 레벨업은 앞선 선택을 적용한 다음 새 후보를 계산한다.

예: P가1종이면 전용1+공용2, G가0종이면 전용3.
G04는 두 번째 영웅이 실제 출전한 뒤 생성되는 카드 화면부터 후보가 된다. 영입 대기만으로는 조건을 충족하지 않는다.
현재 카드 화면 중 배치가 금지되므로 화면 생성 후 출전 인원 변경을 소급 반영할 필요가 없다.
영입RNG와 카드RNG는 분리한다. 카드 풀 변경으로 영입 결과까지 바뀌지 않게 한다.
선택지 순서는 전용→공용으로 고정해도 되지만 카드별 버튼 위치가 항상 같은 것은 아니다. 권장값은 전용을 앞에, 공용을 뒤에 표시하고 부족분 구성은 실제 카드 라벨로 설명한다.

## 7. 후보 부족 검산과 한계
정상 시험안은 총241처치·XP241로 최대9회 카드 선택이다.
이 작업에서9회까지 가능한 획득 상태를 탐색했다.
- 비비 단독, 전용상한[2,2,1], 공용상한[4,4,4], G04 제외: 제시 시점의 최소 유효 카드ID3개,3개 미만 상태0.
- 기본3인 출전, 전용상한[2,2,1,2,1,2,2,2,2], 공용상한[4,4,4,2]: 최소 유효ID8개,3개 미만 상태0.
탐색은 후보로 등장 가능한 모든 카드의 획득 분기를 확인한 것이며 등장확률이나 실제 플레이 성공률을 측정한 것이 아니다.
초기 비비를 유지하며 영웅만 추가하는 기본3종 시험에서는 추가 영웅이 전용 후보를 늘린다. 영웅 교체·삭제·무한모드·카드 봉인에는 별도 검증이 필요하다.
비정상 상태에서3개 미만이면 있는 후보만 보여 복구할 수 있지만 정상 시험판의 QA 합격 처리로 사용하지 않는다.

- 파쇄·집중·G04 중복시 합산항과 최종피해가 공식과 일치.
- 새 런에서 카드와 명중기록 초기화,설정 보존.

## 9. 밸런스 비교 계획과 미결정
공용을 항상 노출하면 전용 투자 횟수가 줄어든다. 기존 전용 카드 중심9회와 공격 방식 완성 속도가 달라지므로 단순 상향으로 보지 않는다.
기존20런 방식의 영입2순서×배치2종×시드5개를 참고하되,후보 생성 규칙이 달라 동일시드가 같은 카드 화면을 보장하지는 않는다.
규칙별 각20런을 동일한 선택 원칙(예: 생존 위기에는 수리,그외 전용 우선)으로 비교하고, 선택 원칙과 실제 후보도 함께 남기는 후속안을 제안한다. 기존20런이 아직 실행되지 않았다면 새 규칙 시험20런부터 진행해도 되며 구규칙과 비교했다고 보고하지 않는다.
관측: 전용 카드 수,공용 선택률,궁극기 사용횟수,누수,완주시간,G04 적용 피해사건 비율.
G04의 이론 추가분과 실제 순이익은 다르다. 과잉피해·다른 공격 기회 손실을 고려하지 않은 추정치를 실전 기여로 표시하지 않는다.
10/15%·2초·4/4/4/2상한·2+1비율은 시험값이며 최종 밸런스 미확정이다.
경제 공용 카드·마무리 분담·진영별 공용 변형은 보류한다.
