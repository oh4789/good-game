# 합성 실험 v0.2 기능·v0.3 밸런스 후보 검증

- 상태: **동결 소스/PCK 검증 완료, 미게시 후보**. v0.3 APK 제작·서명·배포 완료가 아니다.
- 현재 사용자 배포는 안정 Web/Android v0.15와 별도 실험 v0.1 그대로다. 후보 기능을 현재 다운로드 파일에 들어간 것으로 안내하지 않는다.
- 사용자 승인 후 v0.2 기능 후보를 완료하고 같은 격리 흐름에서 v0.3 압박 조정을 검증했다.3성은 잠긴 후속 방향이며 실제3성 전투/합성을 구현하지 않았다.

## 승인된 v0.2 기능과 경계

-4×4의16칸 개별 배치,빈칸으로 즉시 무작위 영입,전투 중 이동/교환·관리와 수동3→2성 합성. 선택한 유닛/칸을 유지한다.
-1성/2성별 유료 상점과 잠긴3성 탭. 결제된 서로 다른 후보3개는 닫기·복원·전투/합성으로 명단이 변해도 재추첨/추가 결제하지 않는다.1성 전용 기록은 미래1성에 남지만2성에 적용하지 않고 공용 효과는 유지한다.
-첫 두 웨이브는 수동 시작,3웨이브부터 실제 시간8초 자동 준비. 배속으로 준비 시간을 줄이지 않는다. 일시정지/포커스/모달/미결정 구매에서 멈추고 남은 시간을 저장하며 오프라인 시간을 더하지 않는다. 즉시 시작은 대기를 건너뛴다.
-비비2성 화염방사기/저격수는 실제 공격 방식 변경이다. 화염은 짧은 원뿔의 제한된 tick,저격은 한 표적 조준 뒤 발사하며 표적 사망/범위 이탈 때 취소한다. 비비1성과 탄코/로코 핵심 공격은 유지한다.
-이동/교환은 잠정 재이동 제한과 공격 회복 시간을 적용한다. 합성·이동이 이미 발사된 공격의 원점/피해를 다시 쓰거나 즉시 공격 초기화를 주지 않는다.
-이전 실험 v0.1 저장을 새 갈래 의미로 자동 해석하지 않는다. v0.2는 별도 저장 계약을 사용하고 이전 바이트를 보존한다.

v0.2 소스/PCK는 각각13suite·47,222단언,13개 구조화 보고 동일성을 확인했다.16칸/상점/자동 준비/비비 공격을 포함한23개 네이티브 화면을 검토했다. 실제 Android 화면·터치·스피커 검증은 아니다.

## v0.3의 작은 변경

일반 적 HP는1웨이브 그대로,이후 배율1+(웨이브−1)/6으로10웨이브 최대2.5배다. 보스HP만3000→4500으로 변경했다. 가격·수입·영웅 수치·희귀도·웨이브 일정·8초 준비는 유지한다. 초기 탐색의 과도한 배율은 채택하지 않았다.

영입 키 입력과 드래그 종료가 겹칠 때 포인터의 눌림 상태가 남는 문제도 수정했다. 수정 전 부정 대조에서 새 회귀7개가 실패하고 수정 후 통과했다. v0.3은 별도 프로필로 v0.2와 안정판 진행을 이관/덮어쓰지 않는다.

## 결과와 해석

튜닝에 쓰지 않은 일반16시드·에픽 제거16시드에서6개 정책을 비교했다.

에픽 제거의6명 정책1패는 보스를 처치했으나10웨이브 일반 적이 누적된 결과다. 에픽이 없으면 보스를 못 넘는다는 근거가 아니다. 초기1명 대조군은 모두5웨이브에서 패배했다. 에픽 제거는 시험 catalog에서만 수행했고 실제 희귀도 확률은 바꾸지 않았다. 모든 실행에서3성은 사용하지 않았다.

동일 시드 전후 비교에서5개 성장 정책의 빈 길 시간 평균은 약204–223초에서148–164초로 줄고 처치 지연은 늘었다. 공격 역할/광역·단일 표적 차이는 관측되지만 배치·영입·정책에 의존한다. 초기 합성 정책은 능력 구매 없이 영입을 우선하므로 그 결과만으로 능력이 불필요하다고 결론내리지 않는다.

자동 준비를 모두 기다린1배속 시간은 대개7분44초,최장 에픽 제거 실행은 약8분28초다. 사람의 선택 시간과 첫 두 수동 시작 대기는 제외한다. 즉시 시작은 대기를 줄인다. 엄격한7분 완주나 초보자 난이도·재미·최종 밸런스를 보장하지 않는다.
