## 1. 결론

현행 공용 카드는 전용 후보가 부족할 때만 나타난다. 등장 순서도 공방 탄약 → 방벽 보강 → 공방 조준기로 고정이다. **공용 카드 선택 0건만으로 낮은 선호나 불필요한 기능이라고 판단할 수 없다.** 먼저 노출 여부와 노출된 뒤의 선택 이유를 분리해야 한다.

권장 비교는 **세 번째 XP 카드 선택에서만, 기존 전용 카드 한 자리를 기존 공용 카드 한 장으로 교체**하는 것이다. 첫 두 번의 선택과 나머지 두 후보는 유지한다. 공용 3종의 수치·상한·설명·영입·경제는 바꾸지 않는다. 매 선택마다 전용 2장+공용 1장을 보장하는 정책이나 새 지원형 영웅을 도입하는 안이 아니다.

우선 같은 상태의 선택 장면을 비교하는 작은 이해도 시험으로 사용한다. 여기서 선택됐다는 이유만으로 장기 밸런스나 재미가 좋아졌다고 결론 내리지 않는다. 운영 도입 여부는 이번 승인에 포함되지 않는다.

## 3. 현재 노출 구조와 해석 한계

전용 카드는 영웅별 3종, 각 3회 상한이다. 출전 중인 영웅의 상한 미달 카드만 전용 후보가 된다. 영입됐어도 배치 대기·벤치 상태이면 그 영웅의 전용 후보는 늘지 않는다. 첫 보상에서는 가능한 비비 3종을 우선하며, 이후에는 유효 전용 후보에서 중복 없이 최대 3장을 뽑는다. 부족한 자리만 아래 순서로 채운다.

| 유효 전용 후보 수 N | 현재 3장에 들어가는 공용 카드 |
|---|---|
| N ≥ 3 | 없음 |
| N = 2 | 공방 탄약 |
| N = 1 | 공방 탄약, 방벽 보강 |
| N = 0 | 공방 탄약, 방벽 보강, 공방 조준기 |

| 실제 ID / 이름 | 유지할 효과 | 해석 주의 |
|---|---|---|
| common_power / 공방 탄약 | 전원 피해 +4%p, 이후 합류 영웅 포함, 반복 상한 없음 | 현재 피해의 4% 곱셈이 아님. 전용 피해 +8%p와 공용 범위의 절충 |
| common_hp / 방벽 보강 | 공유 현재·최대 HP 각각 +2, 반복 상한 없음 | 20/20에서도 22/22. 만HP라는 이유로 무효 카드 처리 금지 |
| common_range / 공방 조준기 | 전원 사거리 +4, 이후 합류 영웅 포함, 반복 상한 없음 | 로코 관통 길이도 늘지만 폭발·화염 반경과 관통 폭을 늘리지 않음 |

출전 인원 A가 고정되고 해당 영웅의 전용 카드가 모두 0회에서 시작한다는 단순 조건에서는, 공용 등장에 필요한 최소 전용 선택 수가 다음과 같다.

| 고정 출전 인원 | 공방 탄약이 가능해지는 최소 전용 선택 수 | 방벽 보강 | 공방 조준기 |
|---|---:|---:|---:|
| 1 | 3 | 6 | 9 |
| 2 | 12 | 15 | 18 |
| 3 | 21 | 24 | 27 |

계산: 전용 종류 3A 중 각각 3A−2, 3A−1, 3A종이 상한에 도달해야 한다. 한 종류를 상한까지 올리려면 3회 선택이 필요하다. 표는 **다음 후보 생성이 가능해지는 카드 수 상태의 하한**이다. 실제 런에서 그 횟수·웨이브에 반드시 등장한다는 예측이 아니다. 무작위 후보, 공용을 고른 횟수, 영입·벤치·재배치에 따라 달라진다.

독립 산술 검증으로 각 전용 카드의 횟수 0~3을 열거했다. 출전 1/2/3명에 대해 64/4,096/262,144개 수 상태에서 위 최소값과 일치했다. 이는 게임을 실행한 횟수도, 모든 상태가 정상 플레이로 도달 가능하다는 증명도 아니다.

**영입이 빨라 출전 영웅이 늘수록 미강화 전용 후보도 늘 수 있다.** 따라서 영입 횟수·보유 인원만 기록하면 노출 원인을 놓친다. 출전 인원과 실제 후보 목록을 함께 기록한다. 특히 공방 조준기의 적은 선택 수는 고정 보충 순서의 영향부터 구분해야 한다.

## 4. 비교안 PL09-E01

질문은 “초반에 기존 공용 카드 한 장을 보여주면, 플레이어가 그 효과를 이해하고 현재 전용 카드와 비교해 선택할 수 있는가?”다. 모든 카드의 인기 순위, 승률 개선, 매번 공용 보장 정책은 이 시험의 질문이 아니다.

### A/B에서 바꾸는 한 가지

| 항목 | A: 현재 규칙 | B: 한 번의 공용 노출 |
|---|---|---|
| 대상 시점 | 완료한 XP 카드 선택이 2회인 다음 선택창 | 같은 시점, 같은 기초 상태 |
| 첫 두 선택 | 기존 결과 보존 | A와 동일 |
| 세 번째 후보 | 현행 규칙으로 만든 3장 | 그 3장 중 지정한 한 자리만 기존 공용 카드로 교체 |
| 나머지 두 후보·순서 | 원래 목록 | 정확히 동일 |
| 효과·문구·레이아웃 | 인수한 동일 버전 | A와 동일 |
| 이후 정책 | 현행 | 이후 진행 시험이 별도로 승인되면 현행으로 복귀. 추가 보장 없음 |

세 번째는 첫 비비 소개와 한 번의 추가 선택을 유지하면서 초반 기회 한 번을 볼 수 있는 **시험 시점**이다. 최적 시점이라고 검증된 것은 아니다. 현재 영입 규칙에서 이 시점의 출전 인원·HP 분포가 실제로 어떤지는 기록으로 확인한다. 3명 출전을 강제하기 위해 영입이나 XP를 조정하지 않는다.

대상은 신규 v0.10 런에서 정상 생성된 세 번째 선택 상태를 우선한다. 기존 운영 저장의 열린 후보를 교체하지 않는다. A 원본 후보 3장과 선택 직전 전체 상태를 격리 사본으로 고정한 뒤 A/B를 만든다. `reward_history` 길이 2, 유효한 선택 단계·epoch, 3장 모두 유효·서로 다름을 확인한다. 두 집단의 차이는 지정된 후보 ID 하나뿐이어야 한다.

원본에 이미 공용 카드가 있거나 출전 영웅이 없거나 카드 수 상태가 맞지 않으면 교체하지 않는다. 사유와 건수를 별도 기록하고 다음 정상 상태를 사용한다. 자연 발생 사례와 인위적 경계 사례를 섞지 않는다. 정상 신규 런에서 두 번 선택만으로 전용 카드가 3회 상한에 도달할 수는 없으므로, 출전 영웅이 있는 정상 세 번째 선택의 전용 후보는 적어도 3종이다.

### RNG·저장 경계

현재 후보 선택과 영입은 같은 모델 RNG를 사용한다. 시험 배정용 RNG가 이미 분리돼 있다고 가정하지 않는다. 동일한 원본 후보를 한 번 확보해 복제하고, 교체 전후 게임 RNG 상태가 그대로인지 확인해야 한다.

B에서 다른 카드를 선택하면 다음 전용 후보 수와 전투 결과가 달라질 수 있다. 이후 RNG 소비 경로까지 달라질 수 있으므로 **같은 초기 시드만으로 이후 영입·후보·전투가 같다고 주장하지 않는다.** 첫 시험의 비교 구간은 이 선택 장면까지다. 뒤의 전투를 기록하더라도 탐색용 별도 결과로 두고 이 장면의 인과 비교에 합치지 않는다.

격리 도구를 운영 저장에 연결하지 않는다. 선택 확정·재표시·복원을 다룰 경우 시험 배정과 확정 후보가 유지되고 재추첨·중복 적용되지 않아야 한다. 운영 저장 형식 변경이나 기존 열린 후보 마이그레이션이 필요해지는 구현은 본 작은 시험의 범위를 벗어나므로 두리에게 별도 인수를 요청한다.

| 후보 | A 원본 3개 ID·순서, 실제 제시 3개 ID·순서, 교체한 전용 ID, 배정 공용 ID·위치, 후보 유효성, RNG 보존 여부 |
| 노출·결정 | 표시 성공 여부, 실제 선택 ID·위치, 확정 성공 여부, 선택 취소/중단/기술 오류, 활성 선택 시간, 전체 대기 시간 |
| 이해 | 선택 후 설명한 적용 대상·효과, 선택 이유, 오해 내용, 기존 상세 설명 열람 여부 |
| 제외·반복 | 제외 사유, 누락 필드, 재시도 여부와 원본 연결, 이전 같은 상태 노출 여부 |

정상 노출은 실제로 3장 모두 표시되고 선택 가능한 경우다. 로그 생성만으로 노출 완료 처리하지 않는다. 활성 선택 시간은 창 표시 후 확정까지의 실제 시간에서 포커스 이탈·외부 중단 시간을 분리한 값이며, 전투 시뮬레이션 시간과 나눈다. 재시도·복원은 독립 노출로 중복 집계하지 않는다. 이름·연락처 등 개인정보는 필요 없다.

### 사람의 선택 절차와 분모

우선 9쌍, A 9회/B 9회의 작은 탐색 묶음을 제안한다. 사람 시험에서는 같은 참여자가 같은 원본의 두 버전을 연속 보지 않게 한다. 첫 판단 묶음은 참여자당 한 장면을 권장한다. 18명의 독립 참여를 확보하지 못하면 실제 참여 수·반복 수를 그대로 보고하고, QA의 자동 선택으로 부족한 사람 데이터를 채우지 않는다. 이는 통계적 검정력을 확보한 표본 설계가 아니다.

선택 전에는 공용 카드를 권하거나 의도를 설명하지 않는다. 기존 상세 보기 사용은 허용하고 기록한다. 선택 후 A/B 모두 같은 질문으로 선택한 카드의 적용 대상과 효과, 선택 이유를 묻는다. B에는 공용 카드의 대상·효과를 이해했는지도 별도 확인한다. 답변 후에만 필요한 정답 설명을 제공한다.

- **노출률:** 실제 해당 공용이 표시된 선택 장면 수 / 유효한 대상 선택 장면 수. 종류별로 기록.
- **조건부 선택률:** 해당 공용 선택 수 / 해당 공용 실제 노출 수. 중단은 분모에서 숨기지 않고 별도 건수도 적음. 0/0은 0%가 아니라 미관측.
- **이해한 선택:** 효과와 적용 대상을 맞게 설명한 유효 확정 수 / 유효 확정 수. A/B 공통 항목. 답변 없음은 정답으로 계산하지 않고 별도 표기.
- **공용 이해도:** B에서 공용 적용 대상·효과를 맞게 설명한 수 / 질문에 응답한 B 참여 수. 질문 미응답 수 병기.
- **부담:** 활성 선택 시간의 중앙값·범위, 상세 열람·중단 수. 소표본 차이를 전체 사용자 성능으로 일반화하지 않음.

A는 대상 선택에서 공용을 제시하지 않으므로 공용 선택 수가 0인 것이 구조적으로 당연하다. “B가 A보다 공용 선택률이 높다”를 성공 지표로 삼지 않는다. B에서 실제 대안과 비교해 고른 이유, A/B의 이해와 선택 부담을 판단 자료로 쓴다. 출전 인원·HP·교체된 카드가 다른 기록을 종류별 선호 순위로 단순 합산하지 않는다.

## 6. 개발·QA 인수 조건

다음은 **실행 요청 제안**이다. 담당 수락이나 작업 배정·구현 완료가 아니다.

| 개발1 | 원본 선택 상태와 A/B 후보 차이 기록, 출전·횟수 경계 자료 | 게임 RNG 추가 소비 없이 한 후보만 교체. 효과·경제 변경 없음 |
| 개발2 | 실제 3장 표시·조작·선택 기록, 동일 문구·레이아웃 증거 | PL-08의 공용 대상 혼동 여부를 분리. 운영 UI 파일 수정 권한은 별도 인수 |

격리 기능 확인표:

1. 정상 세 번째 선택: 첫 두 결과·나머지 두 후보·순서·선택 직전 전투 상태 유지. 공용 종류×위치 9개 배정 모두 한 자리만 교체되고 3장 유효·고유.
2. 첫/두 번째 및 네 번째 이후 선택: 교체 없음. 대기 XP가 여러 개여도 완료 선택 수로 구분하고 한 번만 대상이 됨.
3. 출전 인원 1/2/3 및 배치 대기·벤치 차이: 후보 자격을 잘못 넓히지 않음. 인위 상태이면 기능 증거로만 표시.
4. HP 카드: 20/20→22/22와 3/20→5/22. 확정 패배에서 선택으로 부활시키지 않음. 피해·사거리 카드도 기존 효과 경로를 재사용하고 새 중첩식을 만들지 않음.
5. 원본 공용 포함·상태 불일치: 교체 없이 사유 기록. 비정상 입력을 정상 노출로 집계하지 않음.
6. RNG·반복: 제시를 위한 추가 게임 RNG 소비 없음. 잘못된 epoch·이중 입력은 중복 적용 안 됨. 재표시·복원 시 배정과 확정 후보 유지.
7. 실제 화면: 선택한 지원 해상도에서 세 카드·확정 동작 접근 가능. 표시 증거 없이 모델 로그만으로 화면 검수 통과 처리하지 않음.

확인표는 이번 실행 결과가 아니다. 기존 선택·복원 회귀를 재사용하고, 변경된 후보 교체와 기록 경로를 추가 검수하는 범위다. 새 40런·전체 8갈래 조합 재시험을 자동 의무화하지 않는다.
