## 연결 제안
### 관통·유도
- 유도/일반 로켓: 실제 유효 명중 사건당 sfx_rocket_impact 후보 1개. 표적 소실로 무효 종료하면 0개.
- 관통: 각 접촉의 sfx_rocket_impact는 모두 억제한다. 경로 끝의 별도 폭발도 v0.3에서 확인되지 않았으므로 종결 폭발음을 새로 만들지 않는다.
- 관통의 기존 발사음은 유지한다. 접촉 피드백은 AU-04의 생존 피격 및 기존 처치음 제한을 따른다.
- 필터는 쿨다운보다 먼저 적용한다. 쿨다운이 우연히 다중 폭발을 한 번으로 줄이는 것을 올바른 관통 분류로 취급하지 않는다.
- 런·투사체 사건·공격 종류를 구분할 근거가 필요하다. 실제 API 명칭은 두리가 확인한다. 좌표가 같거나 같은 프레임이라는 이유로 다른 투사체를 하나로 합치지 않는다.
- 종류 식별을 못 하면 공통 표시 전체를 무음 처리하는 임시 변경도 하지 않는다. 현재 조건을 보고하고 연결 보완을 보류한다.

### 장갑 약화
기존 sfx_armor_break는 후보로만 유지한다. 현재 v03 음원 패키지에는 없으므로 경로를 존재한다고 가정해 참조하지 않는다. 두리가 채택·실제 파일 인수를 확인한 뒤 연결한다.
- 유효 명중 전 장갑 양수, 약화 비활성 → 명중 후 살아 있고 약화 활성일 때만 1회 후보.
- 약화가 이미 활성인 상태에서 지속시간 갱신: 0회.
- 만료 뒤 새 명중으로 재적용: 새 후보 1회.
- 장갑 없는 적, 피해로 죽은 적, 누수, 무효 명중: 0회.
- 같은 갱신 안에 이어서 죽거나 누수하면 생존 피격 정책처럼 약화 후보도 취소한다.
- 다중 관통으로 여러 적에게 최초 적용될 때 sound ID 전체 250 ms 간격·최대 1 voice를 적용한다. 초과 후보는 버리고 지연 재생하지 않는다.
- 기본 시험 gain -8 dB, 우선순위 50, loop false. 청취 전 확정값으로 취급하지 않는다. 누수·결과음 우선권을 유지한다.
- 장갑 수치, 약화 지속시간, 적용 순서는 변경하지 않는다. 표현 연결만 제안한다.
