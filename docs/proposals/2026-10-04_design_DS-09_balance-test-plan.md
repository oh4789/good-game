# DS-09 부록 B — 중앙 4칸·첫 강화·1성 물량/2성 집중 시험 계획

- 상태: **TEST PLAN ONLY / 실제 실행·결과 NOT RUN**
- 수치는 모두 `[가설]`이며 결과로 해석하지 않는다.

## 1. 중앙 4칸 사거리 시험

### 목적
R0의 `코앞만 공격` 정체성을 유지하면서 중앙 4칸이 완전 함정이 되는지 확인한다.

### 입력
- 실제 4×4 배치점 16개 좌표.
- 외곽 사각 경로 중심선 또는 표본점.
- 6계열 R0~R3 사거리와 원형/원뿔/직선/경로 길이.

### 기하 검사
16칸 × 4단계 × 6계열 = **384 도달 마스크**를 기록한다.

| 필드 | 의미 |
|---|---|
| `family, cell, tier` | 계열·배치 칸·사거리 단계 |
| `reachable_segments` | 도달 가능한 경로 구간 수 |
| `first_contact_distance` | 가장 가까운 경로점 거리 |
| `expected_idle_sec` | 스폰 이후 첫 공격 예상 대기 |
| `unreachable` | 전투 중 공격 가능 구간 0 여부 |

### 비교 정책

- **A 외곽 시작:** 첫 영웅은 외곽 12칸만 배치, 첫 사거리 강화 또는 R2 이후 중앙 허용.
- **B 중앙 최소 도달:** 모든 칸 허용, 중앙에서 최소 한 변을 맞히도록 R0를 올림.
- **C 중앙 역할 부여:** R0는 짧게 유지하되 중앙에 다른 장점 부여. 새 규칙이므로 후순위.

**우선 시험안:** A. 약점을 숨기지 않고 UI 설명이 쉬우며 R2 성장 체감도 보존한다. 채택은 사용자 결정이다.

### 실패 조건 `[가설]`

- 시작 영웅이 중앙에 놓여 8초 이상 공격하지 못함.
- 중앙 4칸 중 4칸 모두 R2에서도 경로 구간 0.
- R3가 사실상 전맵 상시 타격이 되어 배치 의미가 사라짐.
- 실제 사거리 표시와 공격 획득 판정이 다름.

## 2. 시작 영웅별 첫 강화 시점

### 기록 항목

1. 첫 영웅/배치 칸/RNG 시드.
2. 첫 공격·첫 처치·첫 고철 획득 시각.
3. 첫 영입 가능·첫 능력 구매 가능·실제 구매 시각.
4. 구매 전 누수 수와 HP 손실.
5. 30/60/90초 누적 처치·고철·공격 불가 시간.

### 실행표

- 각 6계열 × 외곽 대표 2칸 × 최소 20시드 = **240런**.
- 중앙은 사거리 기하 확인 후 별도 20시드.
- 상점 가격과 스폰은 현재 실험값을 고정하고 영웅만 바꾼다.
- 자동 구매 정책은 `첫 유효 1성 능력`으로 통일하고 후보 RNG는 기록한다.

### 가설 목표 — 결과 아님

- 첫 공격: 스폰 후 8초 이내.
- 20시드 중 19개 이상에서 원정 종료 전 첫 강화 가능.
- 첫 강화 가능 시각 중앙값 45~60초, 최악 90초 이내.
- 일부 초기 누수는 허용하되 0고철 패배 시드는 0개 목표.

실제 데이터 전에는 가격·HP·사거리를 확정하지 않는다.

## 3. 1성 물량과 2성 집중 비교

| 정책 | 고철 사용 |
|---|---|
| S1 1성 물량 | 영입과 1성 전용 능력 우선. 합성 가능한 3개가 생겨도 정해진 지연 시점까지 유지 |
| S2 2성 집중 | 같은 영웅 3개 확보를 우선하고 즉시 A/B 합성 |
| H 혼합 | 3~4개의 1성으로 커버 후 주력 하나만 2성 |

### 공정 조건

- 같은 총 고철 예산·적 시드·배치 후보·결정 시각.
- 1차는 고정 영입 순서, 2차는 실제 무작위 영입.
- A/B 갈래를 별도 기록.
- 합성 시 1성 전용 능력 손실과 2성 능력 구매 비용을 포함.

### 지표

- 30/60/120초 경로 커버율, 총/유효/과잉 피해.
- 누수·HP, 첫 2성 시각, 첫 능력 구매 시각.
- 영웅별 공격 불가 시간, 보스/정예 처치 시간.
- 1성 전용 투자 손실 고철, 2성 갈래 체감 변화.

### 가설 경고선 — 결과 아님

- 한 정책이 모든 계열·시드에서 승률과 시간 모두 우세하면 선택 구조 실패 가능성.
- S1이 합성 후 능력 손실 때문에 항상 함정이면 1성 올인 설계 실패.
- S2가 경로 공백 없이 항상 최적이면 배치 수량 전략이 의미 없음.
- A/B가 피해 숫자만 다르고 위치 선택이 같으면 승급 체감 실패.

## 4. 수동 플레이 관찰표

자동 정책과 별개로 실제 플레이어가 아래를 이해했는지 기록한다.

- 현재 공격 가능한 길이 보였는가?
- 중앙 칸이 당장 공격 불가임을 배치 전에 알았는가?
- 사거리와 발사 간격을 서로 다른 선택으로 이해했는가?
- 합성 시 사라질 1성 전용 효과를 이해했는가?
- 2성 A/B가 배치와 표적 선택을 바꾼다고 느꼈는가?

기기·사람 시험을 하지 않은 상태에서 `재미있다`, `균형이 맞다`, `가독성 통과`라고 기록하지 않는다.
